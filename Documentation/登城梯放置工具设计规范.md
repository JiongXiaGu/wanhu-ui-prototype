# 登城梯放置工具设计规范

`CityWallAccessStairTool` 是城墙四套独立业务 ToolOverlay 中的第三套，第一版只负责 **自由放置独立登城梯**。

## 1. 第一版目标

本阶段不提前实现自动化连接逻辑。

明确不做：

- 城墙吸附；
- 墙顶 Anchor；
- 自动高度；
- 自动长度；
- 目标坡度；
- 地形反推；
- 自动调整城内 / 城外侧。

登城梯先作为一个独立世界构件存在。

## 2. 玩家参数

左侧参数面板只保留三个玩家直接指定的尺寸：

```text
楼梯尺寸
楼梯宽度
楼梯高度
楼梯长度
```

推荐范围：

- Width：2–12 m；
- Height：2–20 m；
- Length：4–36 m。

坡度由 Height / Length 自然决定，但第一版不作为可编辑参数，也不常驻显示。

## 3. 放置方式

第一版只有一种 Free Placement，没有 Mode Selector。

操作：

- 鼠标移动：调整位置；
- 左转 / 右转：调整整体朝向；
- 交换上下端：改变 High / Low 方向；
- 完成 / 取消。

Bottom Action Bar：

```text
[左转] [右转] [交换上下端]
          │
      [完成] [取消]
```

## 4. World Preview

Web 必须表达一个真正有体积和踏步的 Stair Ghost：

- 低端 LOW；
- 高端 HIGH；
- 明显阶梯级数；
- 宽度；
- 高度；
- 长度；
- 楼梯净空。

三个 Slider 调整时，Ghost 的几何比例同步改变。

正式 Unity 由 `CityWallAccessStairWorldRenderer` 绘制，不由 UI Toolkit 绘制真实楼梯。

## 5. Context Utility

第一版只保留：

- 网格吸附；
- 网格显示；
- 楼梯净空；
- Undo；
- Redo。

不新增“墙顶挂点”“城墙吸附”等未启用功能。

## 6. 数据边界

第一版世界数据：

```text
CityWallAccessStair
├ Width
├ Height
├ Length
├ Position
├ Rotation
└ Reversed
```

内部可以计算坡度、踏步数量等，但这些不属于第一版放置 UI。

## 7. 后续扩展原则

只有实际游戏验证证明需要时，才考虑增加：

- 墙顶吸附；
- 自动 Height；
- 自动 Length；
- Target Slope；
- Wall / Terrain Query。

这些以后作为增强，不影响当前基础数据。

## 8. Visual Review

至少检查：

- Workspace 的“登城梯”Card 能进入 `city-wall-access-stair`；
- 左侧只有 Width / Height / Length；
- 不出现自动高度 / 目标坡度 / 城墙连接；
- Bottom Action Bar 没有 Mode 按钮；
- 左转 / 右转 / 交换上下端均存在；
- World Preview 有明确踏步、High / Low 和三个尺寸表达；
- Utility 只有 Grid / Clearance / History；
- Rotate + Reverse 能改变状态；
- 完成后返回城墙 Workspace。
