# 配色工具：表面模式设计规范

`material-palette` 是从 Gameplay 右下 World Utility 的“配色工具”进入的独立 Tool Space。

第一阶段只实现 **表面模式**。中下三模式入口固定为：

```text
[表面模式] [灯光模式] [色板模式]
```

当前：

- 表面模式可用；
- 灯光模式禁用；
- 色板模式禁用。

未实现模式不得打开空页面。

## 1. 数据依据

Surface Panel 直接按 Unity Runtime 的 `MaterialSlotValue` 与 `MaterialSlotFlags` 语义组织，不复制一套不同含义的数据。

第一阶段实际暴露：

```text
BaseColor
EmissionColor
NightEmissionColor
SpecularColor

Metallic
Smoothness
Occlusion
AlphaClipThreshold

Flags.AlphaClip
Flags.SpecularHighlightsOff
Flags.SpecularSetup

TextureTiling
TextureBlendSharpness
```

暂不为以下字段设计复杂 UI：

```text
TextureSetDefinition
TextureMappingSpace
TextureOffset
TextureRotationRadians
```

当前产品方向允许后续从 Runtime 结构中进一步裁掉这些复杂贴图映射字段，因此 Web Prototype 不为它们制造迁移负担。

## 2. 左侧结构

```text
表面
当前材质槽

方案
  墙面 · 素灰墙  >
  点击 → 材质方案库

颜色
  ┌────────────────────────────────────┐
  │ 主色 | 高光 | 发光 HDR | 夜间发光 HDR │
  │ 色块 | 色块 | 色块     | 色块          │
  └────────────────────────────────────┘

材质属性
  金属度（仅 Metallic）
  光滑度
  环境遮蔽

  铺贴倍率
  混合锐度

工作流
  ● 金属    ○ 高光

Footer
  恢复默认 / 复制参数 / 粘贴参数
```

Surface 首页不显示 HEX；HEX 只属于 Color Editor 精确编辑页。

`高光反射 / Alpha 裁剪 / AlphaClipThreshold` 已退出第一阶段 Surface UI。

当前 Surface 的核心视觉规则是减少容器数量：方案是行式导航；四个颜色共享一个 Color Strip；PBR / Texture 合并为一个材质属性区；Workflow 不拥有完整 Track。

## 2.1 材质方案栏 / Preset Library

Surface 顶部固定显示单行材质方案选择器：

```text
[墙面]  素灰墙  >
[木头]  深胡桃  >
[自定义]  未保存  >
```

规则：

- 不显示“当前方案”提示行；
- 不使用类型 / 名称上下三行堆叠；
- 不在方案栏重复显示四色缩略；
- 方案入口进一步弱化为行式导航：方案 / 类型 · 名称 / 箭头；
- 默认无完整边框与卡片底，只在 Hover / Focus 时轻提亮；
- 类型与方案名同一行，不再使用 Tag Pill；
- 整体约 34px 高。

点击方案卡进入同一 Left Context Host 内的 `PresetLibraryPage`。

第一阶段内置：

- 木头 · 深胡桃；
- 瓦片 · 青灰瓦；
- 墙面 · 素灰墙。

方案库支持：

- 全部 / 木头 / 瓦片 / 墙面 / 自定义筛选；
- 应用系统预设；
- 保存当前参数为自定义方案；
- 删除自定义方案。

任何手动参数修改都会把当前方案状态切换成：

```text
自定义
未保存
```

包括：

- Color Editor 调色；
- RGB / HSV / HEX；
- HDR Intensity；
- Metallic / Smoothness / Occlusion；
- TextureTiling / TextureBlendSharpness；
- Workflow；
- Paste。

重新应用系统预设或已保存自定义方案后，顶部方案栏恢复对应类型与名称。

Web 自定义方案只保存在当前 Tool Session；正式 Unity 应由 MaterialPresetLibrary / 玩家存档持久化。

## 3. Color

四个颜色全部属于 Surface Mode：

- `BaseColor` → 主色；
- `EmissionColor` → 发光颜色；
- `NightEmissionColor` → 夜间发光颜色；
- `SpecularColor` → 高光颜色。

Web 使用原生 Color Input 作为交互占位；正式 Unity 使用项目自己的 Color Picker / HDR Color Picker。

`EmissionColor` 在 Unity 是 HDR Color。Web 第一阶段只验证颜色字段和 UI 架构，不把浏览器 Color Input 当作最终 HDR 编辑实现。

`SpecularColor` 始终占据 Color Strip 第二列；Metallic Workflow 下保持可见但不可编辑，切到 Specular Workflow 后启用。

Web 的 Specular 初始深灰只用于预览占位；正式 Unity 继续读取 Runtime 的 `MaterialSlotGpuDefaults.DielectricSpecularColor`。

### Color Editor 二级页

Surface 首页不直接展开调色器。四个颜色行都是进入共享二级页的入口：

```text
Surface Page
  ├ BaseColor           → Standard Color Editor + Alpha
  ├ EmissionColor       → HDR Color Editor + Intensity
  ├ NightEmissionColor  → HDR Color Editor + Intensity
  └ SpecularColor       → Standard Color Editor
```

交互：

- 点击颜色行后，Surface Content 向左淡出；
- Color Editor 从右侧轻移进入；
- 返回时方向相反；
- 只使用约 12px Translate + Opacity，不做 Width / Height / Scale 动画；
- Header 显示当前字段名称，并出现 Back；
- Back 返回 Surface；
- 右上 Close 仍退出整个 Material Tool；
- Material Bottom Action Bar / Undo / Redo 在二级页保持不变。

共享 Color Editor：

```text
Saturation / Value Field
Hue
HEX
数值模式 [RGB | HSV]

RGB:
  R 0–255
  G 0–255
  B 0–255

HSV:
  H 0–360°
  S 0–100%
  V 0–100%

Standard Variant:
  Alpha（仅 BaseColor）

HDR Variant:
  Intensity

Footer:
  恢复默认 / 复制颜色 / 粘贴颜色
```

HEX 始终显示；RGB / HSV 共用同一个精确数值区域，不同时堆叠六条 Slider。

HDR 强度是 UI Adapter：

```text
Base RGB × Intensity
        ↓
HDR Color
        ↓
MaterialSlotValue.EmissionColor / NightEmissionColor
```

不为 Intensity 增加新的 Runtime 持久字段。

`EmissionColor` 与 `NightEmissionColor` 在产品交互上都属于 HDR。Unity Runtime / Inspector 元数据后续应让两者保持同样的 HDR 编辑语义。

## 4. Workflow

### SpecularSetup

UI：

```text
工作流
[金属] [高光]
```

映射：

```text
金属 → Flags.SpecularSetup = false
高光 → Flags.SpecularSetup = true
```

切换工作流不会清空另一工作流的旧参数。

字段可见性：

- Metallic Workflow：显示 Metallic；高光颜色卡保留位置但不可编辑；
- Specular Workflow：隐藏 Metallic；高光颜色卡启用；
- 隐藏只影响 UI，不清空 Draft 中另一工作流的旧值。

Workflow Row 固定放在 Surface Body 最底部、材质属性之后。

工作流控件改为 Inline Radio-like Choice：

- 与 NumericSliderField 共用同一 Label / Field Column；
- 外层不再拥有完整 Track / Border / Fill；
- 金属 / 高光用小圆点表达状态：Active 为熟铜实点，Inactive 为空心点；
- Hover 只做局部中性提亮；
- 不使用大面积金色 Fill、Glow、下划线或完整分段容器。

## 5. PBR 参数

- Metallic：0–1，仅 Metallic Workflow 显示；切到 Specular 后隐藏但保留值；
- Smoothness：0–1；
- Occlusion：0–1。

统一使用共享 `RuntimeParameterRow / NumericSliderField`。

## 6. 材质属性

Surface 不再把 PBR / Texture 拆成两个强 Section，而是在一个“材质属性”区里通过间距分组。

第一阶段保留：

- Metallic；
- Smoothness；
- Occlusion；
- `TextureTiling`；
- `TextureBlendSharpness`。

暂时不显示：

- Texture Set；
- Mapping Space；
- Offset；
- Rotation。

这不是因为 Runtime 当前没有这些字段，而是产品方向已经准备简化，Web 不提前固化可能被删除的编辑流程。


### Surface / Color Clipboard

Surface Footer：

```text
恢复默认 | 复制参数 | 粘贴参数
```

- 恢复默认恢复 `MaterialSlotValue.Default` 对应的编辑状态；
- 复制参数复制完整 Surface Draft，包括当前隐藏的另一工作流参数与 HDR Adapter 状态；
- 粘贴参数恢复完整 Draft，Workflow 可以随 Clipboard 一起切换；
- Copy 不产生 Undo，Reset / Paste 各视为一个 Command。

Color Footer：

```text
恢复默认 | 复制颜色 | 粘贴颜色
```

Color Clipboard 是结构化 Payload：

```text
Hex
Alpha?
HDR
Intensity?
```

跨类型粘贴规则：

- Standard → HDR：粘贴基础 RGB，保留目标当前 Intensity；
- HDR → Standard：粘贴基础 RGB，忽略 Intensity；
- BaseColor Alpha 只有来源包含 Alpha 时才覆盖；
- HDR → HDR 同时复制 RGB + Intensity。

Web 只实现 Tool Session 内部 Clipboard；正式 Unity 由 MaterialPaletteController 持有 Clipboard，不依赖浏览器 Clipboard API。

## 7. Bottom Action Bar

```text
[表面] [灯光 disabled] [色板 disabled]
                  │
             [完成] [取消]
```

表面模式当前是唯一可操作模式。

## 8. Context Utility

第一阶段刻意最小化：

- Undo；
- Redo。

材质吸取、应用范围、复制材质等功能等 Surface 基础面板稳定后再设计。

## 9. Operation Hints

第一阶段不显示 Gameplay Operation Hints，避免在“左参数 + 中模式 + 右 Utility”之外再增加一块文字 UI。

## 10. Unity UI Toolkit 映射

```text
MaterialPaletteController
├ CurrentMode
└ MaterialSlotValue Draft

MaterialPaletteSurface.uxml
├ Color Section
├ Surface Section
└ Texture Section

MaterialPaletteActionBar.uxml
└ Surface / Lighting / Palette

UtilityToolbarHost
└ Material Palette History
```

React Local Draft 只用于 Web Prototype；正式 Unity 的状态所有者是 `MaterialPaletteController`，直接读写 `MaterialSlotValue`。

## 11. Visual Review

必须检查：

- 从右下“配色工具”真实进入 Tool；
- 顶部方案入口是无完整边框的行式导航：方案 / 类型·名称 / 箭头；不得回退成卡片、Tag Pill、三行文案或四色缩略；
- 方案卡能进入预设库；
- 预设库包含木头 / 瓦片 / 墙面以及自定义筛选；
- 内置方案可应用；
- 当前参数可保存成自定义方案，自定义方案可删除；
- 手动调整数值后顶部方案必须变为“自定义 · 未保存”；
- 颜色区是一个共享 Color Strip，内部四列依次为主色 / 高光 / 发光 / 夜间发光；四列不拥有独立完整边框；
- Surface 首页不显示 HEX；
- Emission / NightEmission 两张卡显示 HDR；
- Metallic 下高光颜色卡可见但不可编辑；Specular 下启用；
- Metallic 只在 Metallic Workflow 显示；Specular Workflow 下隐藏但保留值；
- 高光反射 / Alpha 裁剪 / Threshold 不得回归 Surface；
- PBR + Texture 合并为一个“材质属性” Section；
- Workflow 位于材质属性之后，并使用无外框的 Radio-like Choice；
- Color Editor 支持 SV / Hue / HEX / RGB / HSV；
- Emission / NightEmission 使用 HDR + Intensity；
- Surface / Color Footer 均有恢复默认 / 复制 / 粘贴；
- Material Utility 只有 Undo / Redo；
- 完成后返回正常 Gameplay。
