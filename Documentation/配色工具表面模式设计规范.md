# 配色工具：表面模式设计规范

`material-palette` 是从 Gameplay 右下 World Utility 的“配色工具”进入的独立 Tool Space。

第一阶段只实现 **表面模式**。中下三模式入口固定为：

```text
[表面模式] [灯光模式] [色板模式]
```

当前：

- 表面模式可用；
- 灯光模式禁用；
- 色板模式禁用。

未实现模式不得打开空页面。

## 1. 数据依据

Surface Panel 直接按 Unity Runtime 的 `MaterialSlotValue` 与 `MaterialSlotFlags` 语义组织，不复制一套不同含义的数据。

第一阶段实际暴露：

```text
BaseColor
EmissionColor
NightEmissionColor
SpecularColor

Metallic
Smoothness
Occlusion
AlphaClipThreshold

Flags.AlphaClip
Flags.SpecularHighlightsOff
Flags.SpecularSetup

TextureTiling
TextureBlendSharpness
```

暂不为以下字段设计复杂 UI：

```text
TextureSetDefinition
TextureMappingSpace
TextureOffset
TextureRotationRadians
```

当前产品方向允许后续从 Runtime 结构中进一步裁掉这些复杂贴图映射字段，因此 Web Prototype 不为它们制造迁移负担。

## 2. 左侧结构


不增加“当前材质详情”“GPU 状态”“Flags 数字值”等只读信息块。

## 3. Color

四个颜色全部属于 Surface Mode：

- `BaseColor` → 主色；
- `EmissionColor` → 发光颜色；
- `NightEmissionColor` → 夜间发光颜色；
- `SpecularColor` → 高光颜色。

Web 使用原生 Color Input 作为交互占位；正式 Unity 使用项目自己的 Color Picker / HDR Color Picker。

`EmissionColor` 在 Unity 是 HDR Color。Web 第一阶段只验证颜色字段和 UI 架构，不把浏览器 Color Input 当作最终 HDR 编辑实现。

`SpecularColor` 在 Metallic Workflow 中保持可见但禁用，切到 Specular Workflow 后启用，避免面板布局跳动。

Web 的 Specular 初始深灰只用于预览占位；正式 Unity 继续读取 Runtime 的 `MaterialSlotGpuDefaults.DielectricSpecularColor`。

## 4. Workflow / Flags

### SpecularSetup

UI：

```text
工作流
[金属] [高光]
```

映射：

```text
金属 → Flags.SpecularSetup = false
高光 → Flags.SpecularSetup = true
```

切换工作流不会清空另一工作流的旧参数。

工作流控件采用专用的 **Compact Neutral Selector**，不使用共享 Filled SegmentedControl：

- 外层高度约 28px，但总宽度必须吃满与 NumericSliderField 相同的 Field Column；
- Workflow Row 与 RuntimeParameterRow 使用同一 Label Column / Field Column 几何，左边界与下面 Slider 完全对齐；
- Track 使用和颜色输入框相近的弱中性背景、细边与 8px 圆角；
- 金属 / 高光各占 50%，按钮数量只决定内部等分，不决定控件总宽度；
- 中间只有极弱 1px 中性分隔；
- Active 主要通过 Paper White 文字 + 4px 熟铜状态点表达；
- Active 只允许约 2–3% 的极弱熟铜 Tint，不允许大面积金色 Fill、金色描边、Glow 或下划线 Tab；
- 两个选项都持有真实 SelectionIndicator 元素，方便直接映射 Unity UI Toolkit VisualElement；
- Hover 只做中性提亮；
- 工作流行与下方 Metallic 参数保持普通参数行间距，不再表现成独立导航区域。

这套样式只属于 Material Workflow，不修改项目里其他 SegmentedControl。

### SpecularHighlightsOff

底层是负语义：

```text
Flags.SpecularHighlightsOff
```

玩家 UI 使用正语义：

```text
高光反射 [On / Off]
```

映射：

```text
UI On  → SpecularHighlightsOff = false
UI Off → SpecularHighlightsOff = true
```

### AlphaClip

UI：

```text
Alpha 裁剪 [Off]
```

关闭时隐藏 Threshold。

开启后：

```text
Alpha 裁剪 [On]
裁剪阈值 0.00–1.00
```

映射：

```text
Toggle → Flags.AlphaClip
Slider → AlphaClipThreshold
```

## 5. PBR 参数

- Metallic：0–1，Specular Workflow 下禁用但保留值；
- Smoothness：0–1；
- Occlusion：0–1。

统一使用共享 `RuntimeParameterRow / NumericSliderField`。

## 6. 贴图参数

第一阶段只保留：

- `TextureTiling`；
- `TextureBlendSharpness`。

暂时不显示：

- Texture Set；
- Mapping Space；
- Offset；
- Rotation。

这不是因为 Runtime 当前没有这些字段，而是产品方向已经准备简化，Web 不提前固化可能被删除的编辑流程。

## 7. Bottom Action Bar

```text
[表面] [灯光 disabled] [色板 disabled]
                  │
             [完成] [取消]
```

表面模式当前是唯一可操作模式。

## 8. Context Utility

第一阶段刻意最小化：

- Undo；
- Redo。

材质吸取、应用范围、复制材质等功能等 Surface 基础面板稳定后再设计。

## 9. Operation Hints

第一阶段不显示 Gameplay Operation Hints，避免在“左参数 + 中模式 + 右 Utility”之外再增加一块文字 UI。

## 10. Unity UI Toolkit 映射

```text
MaterialPaletteController
├ CurrentMode
└ MaterialSlotValue Draft

MaterialPaletteSurface.uxml
├ Color Section
├ Surface Section
└ Texture Section

MaterialPaletteActionBar.uxml
└ Surface / Lighting / Palette

UtilityToolbarHost
└ Material Palette History
```

React Local Draft 只用于 Web Prototype；正式 Unity 的状态所有者是 `MaterialPaletteController`，直接读写 `MaterialSlotValue`。

## 11. Visual Review

必须检查：

- 从右下“配色工具”真实进入 Tool；
- Surface / Lighting / Palette 三模式都存在；
- Lighting / Palette 未实现时保持 disabled；
- 四个颜色字段存在；
- Emission 标记 HDR；
- Metallic / Smoothness / Occlusion 存在；
- Workflow 使用 Full-width Field Selector + 小熟铜状态点；总宽度与 NumericSliderField 一致，按钮只在内部等分，不出现大面积选中 Fill 或下划线 Tab；
- SpecularColor 在 Metallic 下可见但禁用；
- 切 Specular 后 SpecularColor 启用，Metallic 禁用；
- 高光反射正确反向映射 SpecularHighlightsOff；
- AlphaClip Off 时隐藏 Threshold，On 时显示；
- 只显示 TextureTiling / TextureBlendSharpness；
- 不显示 TextureSet / MappingSpace / Offset / Rotation；
- Material Utility 只有 Undo / Redo；
- 不显示 Gameplay Operation Hints；
- 完成后返回正常 Gameplay。
