# 常驻 UI 信息最小化

## 决策

常驻 UI 只显示玩家完成当前任务必须知道的信息。

解释性副文案、重复 Summary、装饰编号、无意义英文眉题和为了填空间出现的 Preview 不常驻。

## 承载规则

- 控件本身能表达含义：不增加说明；
- 低频解释：Hover Tooltip；
- 复杂机制：Help / 详情；
- 错误、冲突、危险结果等会直接影响当前决定的信息：允许临时常驻。

## 已应用案例

- Pause 删除 `01/02/03/04` 与右箭头；
- Pause 菜单删除每项副说明；
- Main Menu 仅“继续游戏”保留当前城市信息；
- Settings 删除右侧无决策意义 Preview；
- Settings 参数说明移出常驻区；
- Camera / Weather 删除英文眉题与重复 Summary；
- BuildingPlacement 删除重复参数组说明；
- GameplayOperationHints 收敛为 Shortcut Rail；
- New Game 删除步骤编号与英文眉题。

## 视觉补偿

信息最小化不等于把界面做成纯文字。

减掉信息后，使用以下方式建立丰富度：

- 明暗 Tone；
- 极弱材质；
- 真实游戏截图和缩略图；
- 排版节奏；
- Selected / Focus 暖金微染；
- 轻量动效。

禁止因为“看起来太空”重新增加无意义文字、边框或卡片。
