# 固定 1920×1080 虚拟画布

## 决策

UI Prototype 使用固定 `1920 × 1080` 逻辑画布，再根据浏览器窗口整体等比缩放。

## 原因

这个项目的目标是验证游戏 UI 空间关系，而不是制作普通响应式网页。

固定画布可以稳定验证：

- HUD 与世界画面的关系；
- ToolOverlay、Workspace、Dock、Flyout 的绝对空间占用；
- 1080p 下字号、间距和信息密度；
- 后续映射到 Unity UI Toolkit 的布局关系；
- Playwright Visual Review 的截图一致性。

## 约束

- 不以手机 / 平板响应式为目标；
- 不因为浏览器窗口变化重新排版主要 UI；
- 小窗口只整体缩放；
- 4K 适配应在最终 Unity 项目中通过 UI Scale、分辨率策略和实际运行环境继续验证。
