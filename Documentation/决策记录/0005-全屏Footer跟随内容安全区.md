# 全屏 Footer 跟随内容安全区

## 决策

Settings、Load、Save 等全屏管理页面的 Footer 背景可以横跨整个固定 1920×1080 逻辑画布，但 Footer 中的实际操作按钮不得锚定画布左右边缘。

操作按钮必须限制在与当前页面主体内容相匹配的居中 Action Safe Area 内。

当前基准宽度：

- Settings：960 px
- Save：1040 px
- Load：1520 px

这些宽度允许比实际内容主体略宽，以保留少量水平呼吸空间。

## 语义

- 左侧：当前页面或当前对象的管理动作。
- 右侧：返回、下一步等导航/流程动作。
- 中间保持空白，不为了对称增加无意义按钮。

## 原因

如果按钮直接锚定 1920 逻辑画布边缘，在超宽显示环境中会产生过大的视线和鼠标移动距离，也会削弱按钮与当前内容之间的关系。

让动作跟随页面内容区域可以：

- 保持不同显示比例下的视觉聚合；
- 维持管理动作与当前内容的空间关联；
- 避免 Settings / Save / Load 的 Footer 因页面主体宽度不同而机械统一到屏幕边缘；
- 更自然地映射到 Unity UI Toolkit 中的居中 Content Container + Fullscreen Footer 结构。

## 约束

- Footer 背景仍可铺满全屏；
- 不使用 viewport 响应式重排改变 Action Safe Area 语义；
- Action Safe Area 基于固定 1920×1080 虚拟画布定义；
- 页面主体宽度发生明确设计变更时，应同步审查对应 Footer Action Safe Area；
- 新的全屏页面默认遵循本规则，除非其交互模型有明确理由例外。
