# 世界对象选中系统

World Selection 是 Gameplay 内的轻量对象上下文，不是新的 Tool / Workspace / Management。统一状态只保存 kind + entityId；V1 只实现 Building，经营数据由 Selection Presenter / ViewModel 提供。

## Building Selection V1

世界层提供三个 Web Hit Area 验证点击、Hover、切换与清空。Hover 使用中性纸灰，Selected 使用弱熟铜轮廓与名称，不把建筑整体染金。Unity 正式实现用 World Picking + Selection Renderer 替换矩形 Hit Area。

左下 BuildingSelectionInspector 复用 LeftContextPanel，显示建筑名、类别 / 地区，以及经营、人员、供应、建筑等数据驱动 Section；Header 不重复 Close。

中下 SelectionActionBar 固定为移动 / 配色 / 关闭。移动进入 Building Placement 的 `move` Intent；配色是 Selection 内的 Toggle，不进入顶层 Color Tool，直接打开/关闭共享 BuildingSchemeWorkspace。建筑对象仍不提供单独“编辑”入口。

右下 Context Utility Host 的 building-selection Definition 为：聚焦、Undo / Redo、移除。配色从右下移到中下主操作。移除属于危险对象操作，必须先进入共享确认 Dialog；确认后删除对象并清 Selection，取消保持当前 Selection。

## 状态与互斥

ToolOrigin 增加 selection。Selection → Move → EXIT_TOOL 后恢复原 entityId。建筑单独配色不是 Tool，不消费 ToolOrigin；buildingSchemeOpen 只控制 Selection 内的方案 Workspace。Camera / Weather / Management / Workspace 清 Selection 与方案 Workspace；Pause 保留身份。Main Dock 和普通 Operation Hints 在 Selection 存在时收起，Top Shell / Control Tray 保留。

点击另一建筑直接 Rebind 同一 Inspector；点击空地、Esc、中下关闭统一 CLEAR_SELECTION。

## Unity 映射

Pointer / Input System → World Picking → Building Entity/Id → Selection Controller → Selection ViewModel → UI Toolkit。建筑 Hover / Selected / Footprint 属于 World Renderer；Inspector / ActionBar / Utility 属于 UI Toolkit。

Road / CityWall 后续只新增 Selection Definition / Presenter / Renderer，不再建立第二套 Selection Shell。

## Building Placement 边界

Building Placement 回答“建筑在哪里”：New 创建 Draft，Move 基于原建筑保存 Original + Draft；确认时 New 创建实体，Move 更新原实体的位置数据，取消 Move 丢弃 Draft 而不是销毁 / 重建建筑。Web Demo 目前只验证 UI Session 语义，正式 Original / Draft 与碰撞、地形、道路校验由 Unity Controller 持有。


## Building Appearance

Building Selection 左侧 Inspector 直接显示当前建筑实例的外观参数：

```text
配色方案   当前方案名 >
做旧程度   0–100%
```

“配色方案”行与中下“配色”按钮指向同一个 BuildingSchemeWorkspace。中下按钮是 Toggle：打开时保持 Selected / aria-pressed，再次点击关闭；Esc 优先关闭方案 Workspace，不清除建筑 Selection。

Web Demo 的 schemeId / weathering 是建筑实例 Fixture，正式 Unity 由 BuildingAppearance 数据拥有。Scheme 卡片继续使用既有文字目录，不增加缩略图。

## Remove Building

Selection 右下提供“移除建筑”。点击只发起危险确认 Dialog；确认后才执行 Remove Command，并清除 Selection。Web Prototype 用移除 Hit Area 验证流程；正式 Unity 不从 UI 直接 Destroy Entity，而由建筑生命周期 / Command 系统处理居民、岗位、库存、生产和引用清理。
