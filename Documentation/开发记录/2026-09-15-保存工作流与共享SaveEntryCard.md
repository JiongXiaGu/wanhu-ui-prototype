# 2026-09-15 保存工作流与共享 SaveEntryCard

## 本轮目标

解决保存页高频保存不方便、顶部新建入口割裂，以及 Load / Save 各自维护一套存档 Card 导致视觉漂移的问题。

## 完成内容

### 1. SaveEntryCard 共享组件

新增 `src/archive/SaveEntryCard.tsx`。

读取页和保存页现在共享同一套 Card 视觉结构：

- 缩略图
- 名称 / 内联重命名
- 游戏日期
- 现实保存时间
- 存档类型
- 兼容状态
- 版本
- Action Slot
- Confirmation Slot

Card 不决定读取、覆盖或删除等页面工作流，只提供显示和交互容器。

### 2. 保存页类型筛选

保存页新增与读取页一致的：

- 全部
- 自动存档
- 手动存档
- 快速存档
- 隐藏过时存档

页面不提供搜索和排序，固定按现实保存时间倒序。

### 3. 删除顶部新建存档入口

旧的 `+ 新建存档` / 内联创建区域已移除。

保存动作全部集中到 Footer 中部：

- 快速保存
- 保存存档

### 4. 快速保存

点击后直接创建 `快速存档.xxx`：

- 不弹窗；
- 当前游戏日期；
- 当前现实保存时间；
- 当前版本；
- 创建后进入列表顶部；
- Toast 短提示；
- 原型最多保留最近 10 个快速存档，超过后淘汰最旧项。

### 5. 保存存档

点击后打开轻量命名弹窗。

- 默认名称 `手动存档.xxx`；
- 玩家可改名；
- Enter / 保存：创建；
- Esc / 取消：关闭；
- 成功后进入列表顶部并显示 Toast。

### 6. 保存页 Card 权限

手动存档：

- 重命名
- 覆盖
- 删除

快速存档 / 自动存档：

- 不允许重命名；
- 不允许覆盖；
- 允许删除。

手动存档覆盖后升级为当前版本并移动到顶部。

## 自动验证

新增 `scripts/capture-save-interactions.mjs`，并加入 Visual Review Workflow。

自动验证：

- 保存页四类类型筛选；
- 隐藏过时 Toggle；
- 旧顶部新建入口不存在；
- Footer 快速保存 / 保存存档存在；
- 快速保存直接生成快速存档；
- 保存弹窗默认自动名称；
- 自定义名称确认后创建新手动存档；
- Save / Load 共享同一套 `.archive-save-card` 结构。

## 架构结论

继续保持：

- `LoadGameSpace`：读取工作流；
- `SaveGameSpace`：保存工作流；
- `SaveEntryCard`：共享视觉组件。

禁止重新合并为单一 `ArchivePanel(mode)` 页面。
