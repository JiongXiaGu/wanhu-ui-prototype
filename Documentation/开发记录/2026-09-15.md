# 2026-09-15

## Visual Cleanup Pass 2

在第一轮“文字减法”完成后，开始处理容器、边界、Typography 与视觉聚合。

目标不是继续删除功能，而是减少网页 / SaaS 感，同时避免界面因为过度极简而失去设计层级。

### Settings

- 减少逐行分隔线；
- Select / 数值不再使用重输入框；
- Toggle 只保留开关本体；
- Slider 减少框套框；
- 提高核心参数字号和对比度；
- 保留全屏空间，但避免把控件摊到屏幕两端。

审图结论：方向正确，但后续不能继续单纯删框，需要增加 Tone、材质和空间聚合。

### Building Workspace

- 保留一个主 Workspace Surface；
- 减弱侧栏、筛选条和内容项的盒子感；
- 建筑条目从“网页 Card”转向“游戏内容目录”；
- 提升建筑名与核心属性可读性；
- 暂时用不同线性图标区分建筑，后续应替换为真实建筑缩略图 / RenderTexture。

### BuildingPlacement

- 减少内部摘要 Card；
- Parameter Value 不再逐项套框；
- Segmented Control 减少完整外框；
- 通过对齐、留白和状态色组织层级。

### GameplayOperationHints

进一步收敛为 Shortcut Rail：

- 当前模式；
- 当前主要输入；
- 旋转 / 反转；
- 撤销 / 重做 / Esc 等次级快捷键。

不承担教程说明。

## 当前美术判断

经过减法后，项目已从“信息过密”进入新的阶段：部分界面出现“过于简约、略显单调”的风险。

下一阶段原则：

**信息继续做减法，视觉层级开始做加法。**

优先增加：

- 2%～5% 的明暗 Tone 层级；
- 极弱材质、渐变、内高光；
- Selected / Focus 暖金氛围；
- 真实游戏内容图像；
- 更丰富但克制的排版节奏；
- Hover / Tab / Flyout / Preview 的轻动效。

明确不回退到：

- 说明小字；
- 框套框；
- 装饰编号；
- 大量金边；
- 云纹、卷轴、木纹等仿古装饰。

## 下一步视觉任务

- 不在正式设计文档中添加文档状态、评审状态、核验时间等机器式元数据。
