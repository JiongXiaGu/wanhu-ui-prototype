# 2026-09-15 读档界面重构

## 目标

统一 Settings / Archive 的全屏页面动作栏语言，并把读档流程从旧三栏档案浏览改成更直接的“游戏组 → 组内存档 → Card 操作”。

## 主要改动

- Archive Header 删除左上返回；
- 旧 `Game Group → Save Timeline → Preview` 三栏改成两栏主从结构；
- 左侧游戏组 Card 改为紧凑横向短卡；
- 右侧单个存档改成横向 Save Card；
- 移除固定 Preview / Summary 第三栏；
- Save Card 增加图标动作：重命名 / 读取 / 删除；
- Save Card 操作只在 Hover / Focus / Selected 时出现；
- 重命名改为 Card 内联编辑；
- 单个存档删除使用 Card 局部确认；
- 游戏组重命名 / 删除留在 Footer 左侧；
- 返回固定在 Footer 最右侧；
- Settings Footer 同步改成左侧“恢复当前分类默认值”、最右“返回”。

## 设计原因

单个存档的读取 / 重命名 / 删除与当前 Card 强关联，把这些动作放到底部会增加鼠标移动和视觉查找成本。游戏组则是当前页面的高层容器对象，因此其重命名 / 删除更适合稳定放在页面级 Footer。
