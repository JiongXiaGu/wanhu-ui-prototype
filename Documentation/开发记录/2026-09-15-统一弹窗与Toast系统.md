# 2026-09-15 统一弹窗与 Toast 系统

## 本轮目标

把此前散落在 Settings、Load、Save、主菜单和 Pause 中的确认、输入与提示 UI 收敛成统一框架，避免继续出现页面私有弹窗风格和 Card 内联确认条。

## 新增基础设施

新增：

- `src/ui/dialog/DialogSystem.tsx`
- `src/ui/dialog/dialog.css`

核心组件：

- `DialogProvider`
- `DialogHost`
- `NotificationHost`
- Confirm Dialog
- Input Dialog
- Timed Dialog API
- Toast

`App` 在固定 1920×1080 游戏画布内挂载全局 `DialogHost / NotificationHost`，保证弹窗层级、Focus 和 Esc 优先级统一。

## 已迁移场景

### 主菜单 / Gameplay

- 退出游戏确认；
- 返回主菜单确认。

### SaveGameSpace

- 保存新存档命名；
- 更改存档组名称；
- 重命名单个手动存档；
- 覆盖存档确认；
- 删除单个存档确认；
- 快速保存 / 手动保存 / 覆盖 / 删除结果 Toast。

### LoadGameSpace

- 重命名单个存档；
- 删除单个存档；
- 重命名存档组；
- 删除存档组；
- 删除结果 Toast。

`SaveEntryCard` 已删除旧的内联 TextField 与局部确认区域，只保留视觉结构与 Action Slot。

## Settings

Settings 的 15 秒显示安全确认仍使用原有安全回滚状态机，以避免本轮重构同时改动已经稳定的显示恢复逻辑。

其 Surface、Backdrop、按钮、间距和动画已经调整为与统一 DialogFrame 相同的视觉语言。

后续 Unity UI Toolkit 正式实现时，安全显示确认也应位于全局 Modal Layer。

## 统一交互规则

- Esc：取消 / 恢复，不执行危险确认；
- Enter：执行可用的主确认动作；
- Danger Dialog 默认焦点在取消；
- Input Dialog 打开后聚焦并全选初始值；
- 空名称禁止确认；
- 主动作固定在右侧；
- 永久删除使用低饱和危险色；
- Toast 不抢 Focus、不阻断操作并自动消失。

## 视觉规则

- 深墨绿高不透明 Surface；
- 弱灰绿 1 px 描边；
- 极弱暖金顶部高光；
- 背景压暗 + Blur；
- 小圆角；
- 动画约 150 ms；
- 不使用粗金框、卷轴、英文 Eyebrow 或大面积红色。
