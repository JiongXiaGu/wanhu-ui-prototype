# 2026-09-16 Top Shell 图标导航

## 背景

Gameplay 顶部在上一阶段已经统一为双层 Top Shell，但第二层仍使用“图标 + 文字”的一级管理导航，视觉上仍偏重、接近网页 Tab。用户确认新的目标是：保留双层一体化 Top Shell，但第二层只显示图标，通过 Hover Tooltip 与 Selected 状态表达语义。

## 本次调整

- Persistent Status Row 保留资源、人口、天气、时间、相机、速度与菜单。
- Management Navigation Row 改为纯图标入口：概况、户籍、财政、政策、商贸、治理、军务、图层。
- 导航条收窄并居中挂在状态栏下方，形成上下两层连成一个整体的视觉结构。
- Selected 使用弱暖金 Tone + 底部细金线，不再常驻显示文字标签。
- Hover Tooltip 负责补充中文功能名；ARIA Label 继续保留无障碍与自动化测试语义。
- Information Views 仍由图层图标打开顶部 Palette。
- Bottom Dock / Utility Toolbar 本轮不改，留到下一阶段统一。

## Review 要点

- 1920×1080 下 Top Shell 居中且不裁切。
- 第二层必须没有常驻文字节点。
- 第二层宽度小于第一层，形成明确的附属导航层级。
- Finance / Policy Management Space 中仍可通过顶部图标直接切换系统。
- Workspace / Tool 继续只保留第一层 Persistent Status Row。
