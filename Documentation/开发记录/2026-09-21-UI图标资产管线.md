# 2026-09-21 UI 图标资产管线审查

## 背景

Unity UI Toolkit 正式迁移前，需要把 Web Prototype 当前的 `lucide-react → inline SVG` 图标方式收敛成可以直接复用的资产管线。

用户确认的新目标不是：

```text
Web 使用 SVG
Unity 再单独转换 PNG
```

而是：

```text
SVG Source Master
        ↓
统一 PNG Runtime Asset
      ↙          ↘
Web             Unity
```

## 审查结果

当前仓库：

- Runtime 图标主要来自 `lucide-react`；
- 仓库此前没有正式 UI Icon `.svg` 文件；
- 现有 PNG 主要是背景与 Noise，不是功能图标资产；
- 多个 Shared / Config API 直接暴露 `LucideIcon`；
- CSS 存在多种 SVG `stroke-width`，约 1.55～2.0；
- 因此不能安全一次性 Rasterize + 全项目替换。

重点受影响边界：

- `LeftContextPanel`；
- `PlacementContextPanel`；
- `CommandBar`；
- `ContextUtilityToolbar`；
- `GameplayHUD`；
- `DesignWorkspaceDefinition`；
- Dialog / Select / Archive / Settings 中的直接 Lucide Component。

## 决策

普通单色 UI Icon：

```text
SVG Source
→ 64×64 white RGBA PNG
→ UiIconId / Manifest
→ Web PNG Mask / Unity Sprite Tint
```

稳定规则：

- SVG = Source Master；
- PNG = Web + Unity Runtime；
- 64×64 单一资产尺寸；
- 状态色不烘焙；
- Web 用 PNG Alpha Mask + currentColor；
- Unity 用同一 PNG Sprite + Tint；
- Shared / Business API 最终只持有 `UiIconId`；
- 当前 Standard Stroke Pilot = 1.7；
- 结构性线、点、Pager、Toggle、Slider 不 PNG 化。

## 执行结果

审查后的资产方案已经实际落地，不再停留于设计阶段。

### Asset

已生成并提交：

- 104 个 SVG Source；
- 104 个 64×64 PNG Runtime；
- `icon-manifest.json`；
- `icon-manifest.generated.ts`；
- `runtime-icons.generated.tsx`；
- Lucide License。

固定版本：

```text
lucide-react 1.47.0
sharp        0.35.4
stroke       1.7
```

### PNG Pilot

代表场景：

- ColorToolDock；
- LeftContextPanel；
- Material Workspace Header / Rail；
- Select / Dialog Chevron / Check。

Pilot Build 与 UI Review 成功，Artifact 已实际下载检查。

人工审查确认 12～20px 显示尺寸没有明显糊边或线宽异常，因此 stroke 1.7 正式冻结。

### Runtime Migration

`src/` 已不再直接 import `lucide-react`。

原有命名 Icon JSX 由：

```text
runtime-icons.generated.tsx
→ createUiIconComponent
→ UiIcon
→ committed PNG mask
```

兼容，不再生成 inline SVG。

历史 `LucideIcon` 类型名也已迁出，Shared Runtime 使用本地 `UiIconId / UiIconComponent / UiIconSource` Contract。

### CI

新增：

```bash
npm run icons:build
npm run icons:check
```

Build Gate：

```text
icons:check
→ audit:unity
→ build
```

Audit 已升级：

- `src/` 直接 import `lucide-react` → Failure；
- `src/` 出现 `LucideIcon` → Failure。

`icons:check` 校验：

- 104 个 Source / Runtime Asset；
- 64×64；
- Alpha；
- Manifest；
- Generated Adapter；
- Source Version / Stroke；
- License。

### 当前阶段

Phase I～V 与 CI Freeze 已完成。

Unity 不需要再做 SVG → PNG 转换，下一阶段直接复制 `public/assets/ui/icons/*.png` 建立 Sprite / Sprite Atlas / Icon Library。

历史 SVG CSS Selector Cleanup 继续按实际命中关系安全推进，不作为 Unity 迁移的阻塞项。
