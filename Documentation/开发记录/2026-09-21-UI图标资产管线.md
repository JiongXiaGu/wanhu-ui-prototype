# 2026-09-21 UI 图标资产管线审查

## 背景

Unity UI Toolkit 正式迁移前，需要把 Web Prototype 当前的 `lucide-react → inline SVG` 图标方式收敛成可以直接复用的资产管线。

用户确认的新目标不是：

```text
Web 使用 SVG
Unity 再单独转换 PNG
```

而是：

```text
SVG Source Master
        ↓
统一 PNG Runtime Asset
      ↙          ↘
Web             Unity
```

## 审查结果

当前仓库：

- Runtime 图标主要来自 `lucide-react`；
- 仓库此前没有正式 UI Icon `.svg` 文件；
- 现有 PNG 主要是背景与 Noise，不是功能图标资产；
- 多个 Shared / Config API 直接暴露 `LucideIcon`；
- CSS 存在多种 SVG `stroke-width`，约 1.55～2.0；
- 因此不能安全一次性 Rasterize + 全项目替换。

重点受影响边界：

- `LeftContextPanel`；
- `PlacementContextPanel`；
- `CommandBar`；
- `ContextUtilityToolbar`；
- `GameplayHUD`；
- `DesignWorkspaceDefinition`；
- Dialog / Select / Archive / Settings 中的直接 Lucide Component。

## 决策

普通单色 UI Icon：

```text
SVG Source
→ 64×64 white RGBA PNG
→ UiIconId / Manifest
→ Web PNG Mask / Unity Sprite Tint
```

稳定规则：

- SVG = Source Master；
- PNG = Web + Unity Runtime；
- 64×64 单一资产尺寸；
- 状态色不烘焙；
- Web 用 PNG Alpha Mask + currentColor；
- Unity 用同一 PNG Sprite + Tint；
- Shared / Business API 最终只持有 `UiIconId`；
- 当前 Standard Stroke Pilot = 1.7；
- 结构性线、点、Pager、Toggle、Slider 不 PNG 化。

## 执行阶段

1. Icon Contract；
2. Asset Generator；
3. PNG Pilot；
4. Shared Contract；
5. Runtime Migration；
6. CSS Cleanup；
7. CI Freeze；
8. Unity Handoff。

PNG Pilot 必须至少覆盖：

- ColorToolDock；
- LeftContextPanel；
- Workspace；
- Select / Dialog Chevron。
