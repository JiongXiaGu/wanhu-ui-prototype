# 2026-09-16 Main Dock 模式重构

## 背景

普通 Gameplay 的 Main Dock 原先只有一套固定分类，并把 `全部` 当作默认 Selected。这会把“没有进行任何建造选择”和“玩家主动选择全部”混成同一个状态，也无法表达后续设计 / 蓝图两套不同内容域。

## 本次调整

Main Dock 改为：

`模式选择器 + 当前模式分类带`

左侧固定两个 Exclusive Selector：

- 设计
- 蓝图

设计分类：

`道路 / 桥梁 / 建筑 / 台基 / 城墙 / 围墙 / 装饰 / 树木`

蓝图分类：

`全部 / 民居 / 商业 / 工坊 / 管理 / 科学 / 信仰 / 军事 / 宫殿`

其中“台基”表示宫殿、大型建筑的高台基 / 台地建造系统。

## 状态语义

`GameplayUiState` 不再使用模糊的 `activeCategory: string`，改为：

- `dockMode: 'design' | 'blueprint'`
- `dockCategory: DockCategory | null`

`dockCategory = null` 是正常且重要的正式状态，表示玩家当前没有选择任何 Main Dock 分类。

规则：

- 初始 Gameplay：设计模式，但没有选中分类；
- 切换设计 / 蓝图：清空当前分类；
- 不分别记住两个模式上一次分类；
- 只有玩家显式点击分类后才出现 Selected；
- 再次点击当前分类会清空选择；
- Building Workspace 关闭、Esc 退出或再次点击“建筑”时，“建筑”同步恢复未选中；
- Building Placement 完成 / 取消返回 Building Workspace 时，重新进入 `设计 / 建筑` 显式上下文。

Selected 表示当前明确上下文，而不是默认推荐或历史记忆。

## 当前功能映射

目前只有：

`设计 → 建筑 → Building Workspace`

正式接通。

其它设计分类后续接对应 Workspace / Tool。蓝图九个分类以后进入同一个 Blueprint Workspace，通过分类筛选内容，不复制九套 Workspace。

## 视觉调整

Main Dock 外框仍保持约 `940 × 76px`。

内部调整：

- 左侧模式区约 `96px`；
- 右侧分类根据 8 / 9 项自动等宽；
- 分类 Icon 提升到约 `21px`；
- 标签约 `10px`；
- 默认分类不画 Card；
- Hover 只轻提背景；
- Selected 使用暖金 Icon / 文本 + 短金线；
- 模式 Selected 使用独立左侧短金线，和分类层级区分。

## Review

`capture-management-review.mjs` 新增：

- 设计模式固定 8 项；
- 蓝图模式固定 9 项；
- 初始没有分类 Selected；
- 模式切换清空分类；
- 切回模式不会恢复历史分类；
- 建筑 Workspace 关闭后分类回到未选中；
- 蓝图模式额外生成一张 Review 截图用于人工比较。
