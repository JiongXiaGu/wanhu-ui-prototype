# 2026-09-16 Top Shell 信息架构重构

## 目标

在顶部双层 HUD 比例稳定后，重新整理信息与控制职责，并缩短外围 HUD 到屏幕边缘的距离。

## 修改

- Gameplay 外围左 / 右 / 下 Safe Margin 从 `24px` 收到 `16px`；
- Top Status Row 改为固定三段：左侧天气 / 时间，中间资源，右侧场景入口；
- 资源使用固定左右槽保证几何中心不因场景按钮变化而偏移；
- 天气按钮不再打开旧 Weather Adjustment Flyout；
- 第二层改为 `观察 / 管理 / 时间` 三组：
  - 左：Information Views；
  - 中：城市 / 经济 / 政策 / 军事 / 宫殿；
  - 右：暂停 / ×1 / ×2 / ×4；
- 一级管理从旧的概况 / 户籍 / 财政 / 政策 / 商贸 / 治理 / 军务收束为五个大类；
- 当前内容暂时复用已有 Management View，后续再重构五个一级域内部的信息架构；
- `Speed` 增加 `0`，暂停时间成为真实状态而不是装饰按钮。

## Review

Visual Review 新增 / 调整约束：

- 第一层资源几何中心必须落在 1920 画布中心；
- 第二层必须保持 `图层 → 五个管理域 → 时间控制` 顺序；
- 五个一级管理域保持纯图标；
- 天气按钮不得打开旧 Weather Adjustment Flyout；
- 暂停时间必须切换到 `speed = 0`；
- World Utility / Operation Hints 改为统一 `16px` 右侧安全边距。
