# P1-C 历史皮肤收束

## 目标

把已经稳定的黛墨 / 纸白 / 熟铜视觉从历史“Pass 叠 Pass”结构中拆出，回收到长期可维护的正式 Owner。重构目标是尽量保持现有视觉不变，同时让后续改皮肤不再依赖 CSS import 顺序。

## 本轮完成

- 删除 `src/ui/wanhu-contrast-identity.css`。
- 删除 `src/ui/wanhu-tonal-material.css`。
- `wanhu-theme-tokens.css` 继续作为统一颜色、文字、材质与 Surface Recipe 的权威入口，并保留少量兼容别名供尚未迁移的组件使用。
- `wanhu-surface-system.css` 正式拥有：
  - Environment / Camera 等 Context Surface；
  - Design Workspace Work Surface；
  - Top Status / Control Tray / Main Dock / World Utility / Operation Hint / System Menu。
- Workspace 的文字层级、Rail、Filter、Search、Asset Card 和 Pager 状态回到 `workspace-world-first-glass.css`。
- Environment 的 Preset、Parameter、Slider、Footer 与模式切换状态回到 `weather-mist-glass.css`。
- Compass 的正式视觉回到 `gameplay-corner-hud.css`。
- Building ToolOverlay 的正式视觉回到 `tool-overlay.css`。
- `wanhu-character.css` 只保留真正具有结构语义的状态标记与动效，不再承担通用配色和控件皮肤。
- Visual Review 明确禁止六个已退休历史样式表重新进入 Runtime：
  - `wanhu-workspace-integration.css`
  - `wanhu-tonal-texture.css`
  - `wanhu-hud-glass.css`
  - `wanhu-tonal-hud-roles.css`
  - `wanhu-contrast-identity.css`
  - `wanhu-tonal-material.css`

## 当前正式所有权

```text
Theme Tokens
    ↓
Surface System
    ↓
Control / Component Skin
    ↓
Component Geometry
```

规则：

- 全局色板、Paper 层级、Brass、Surface Recipe 只在 Theme Tokens 定义。
- 面板背景、Blur、Noise、Edge、Shadow 由 Surface System 负责。
- 控件状态与组件内部前景层级由对应 Control / Component CSS 负责。
- Geometry 继续由组件文件负责，不为了 Web Prototype 的 CSS 收束改变最终 Unity UI Toolkit 的职责边界。

## 验证

- `npm run build` 通过。
- 完整 Visual Review 通过。
- 人工复核 Gameplay、Workspace、Environment、Camera、Building ToolOverlay 以及夜景；未发现需要回退历史 Pass 的视觉回归。
- 与 P1-B 基线相比，核心 Gameplay 几乎无像素变化；Workspace / Environment / ToolOverlay 差异很小，Camera 的材质实现迁移后仍保持同一视觉方向。
