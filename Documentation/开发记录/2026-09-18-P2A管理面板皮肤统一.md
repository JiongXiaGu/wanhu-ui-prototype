# P2-A 管理面板皮肤统一

## 目标

把仍然保留旧绿黑实体面板 / 金色 Icon Chip / 盒状控件语言的管理与相机界面，接入 P1 已确立的 Graphite / Paper / Brass 正式视觉系统。

本轮优先统一皮肤与视觉所有权，不改变城市、财政、库存、政策、军事等管理数据结构，也不改变顶部快捷入口与主导航的既有交互规则。

## 管理面板

新增 `src/gameplay/management-panel-skin.css`，作为 Management Space 的正式组件皮肤：

- 城市、经济、库存、政策、军事以及其它 ManagementView 共用同一套标题、指标、Section、列表与数据状态语言；
- 标题栏改为裸图标 + Paper 标题，不再使用方形金色 Icon Chip；
- 标题栏高度统一为约 64px，关闭按钮保持低强调；
- 指标区以 Paper 主数值、Muted 标签和少量 Brass 状态建立层级；
- Section / List 主要使用间距、弱 Rule 和 Hover，而不是层层卡片；
- 财政图表保留 Brass 作为收入 / 重点状态，支出改为中性 Graphite / Slate，不使用绿色分类色；
- 库存页签、KPI、选中仓库与资源进度继续复用同一套 Brass 状态语法。

Management Space 的外层材质由 `wanhu-surface-system.css` 正式拥有，组件皮肤不再自己发明另一套 Surface。

## 相机面板

新增 `src/gameplay/camera-context-skin.css`。

相机继续属于 Context Panel，不建立独立 Surface：

- 外层直接复用 Surface System 的 Context Surface；
- 内部分区直接浮在父玻璃上，用弱 Rule 分隔；
- 视图模式改为开放式 Segmented Control，不再使用旧盒状外框；
- 参数行与 Environment 使用相同的轻量 Stepper / 透明 Value / 细 Slider 语言；
- Brass 只用于当前模式和 Focus，不作为常驻装饰色。

## 所有权

```text
Theme Tokens
    ↓
Surface System
    ├ Context Surface → Camera / Environment
    └ Management Surface → City / Finance / Inventory / Policy / Military / ...
    ↓
Component Skin
    ├ camera-context-skin.css
    └ management-panel-skin.css
    ↓
Geometry / Data Layout
```

- 人工复核城市、经济、库存、军事和相机截图；管理窗口已从旧绿黑应用窗口转为统一 Graphite / Paper / Brass 工作面板，相机内部控件也与 Environment 属于同一视觉家族。
