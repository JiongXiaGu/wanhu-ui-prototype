# 2026-09-15 Settings 安全显示确认

## 本轮目标

将 Settings 从传统 `取消 / 应用` 表单模式调整为更现代的游戏设置交互：普通设置即时生效并保存，高风险显示设置使用临时应用 + 可回滚安全确认。

## 主要修改

- 删除 Settings Footer 常驻 `取消 / 应用`；
- Footer 仅保留 `恢复当前分类默认值`；
- `界面缩放` 从 Slider 改为离散 Select：`80% / 90% / 100% / 110% / 125% / 150%`；
- 普通 Slider / Toggle / Select 修改后立即写入当前原型状态；
- 按键重绑定继续即时生效；
- 以下设置改为安全显示设置：
  - 显示模式；
  - 显示器；
  - 分辨率；
  - 刷新率；
  - HDR；
  - UI Scale；
- 安全显示设置修改后立即临时应用并打开 `Safe Confirmation Layer`；
- 默认倒计时 15 秒；
- `保留设置` 提交临时值；
- `恢复原设置`、Esc 或超时均回滚到 Previous Safe Snapshot；
- 恢复“显示”分类默认值时，如果影响任何安全显示设置，同样必须经过 Safe Confirmation；
- Safe Confirmation Layer 单独使用系统安全层视觉，不属于正在测试的 UI Scale；
- Pause → Settings 中修正 Esc 优先级：子层已处理并 `preventDefault` 的 Esc 不再被 PauseLayer 继续消费。

- Disabled、双键位、Dropdown、Restore 等原回归继续保留。

## Unity UI Toolkit 对应

最终 Unity 推荐由设置系统统一管理：

```text
普通设置
Change → Apply Runtime → Persist

安全显示设置
Change → PreviousSafeSnapshot → Temporary Apply
       → SafeSystemOverlay
       → Commit / Rollback
```

`SafeSystemOverlay` 必须独立于玩家当前 UI Scale，保证任何异常缩放或显示设置下都能恢复。

正式长期规则见 `Documentation/设置界面规范.md`。
