# 2026-09-16 Gameplay 顶部整合

本轮目标是减少 Normal Gameplay 中“左侧管理 Rail / 中间资源 HUD / 右上 Quick Controls”三块彼此分离的 UI 岛。

## 结果

Gameplay 顶部改为统一 `Gameplay Top Shell`：

- 第一层 Persistent Status Row：钱粮、人口、木材、石料、天气、季节 / 时间、相机、速度、菜单；
- 第二层 Management Navigation Row：概况、户籍、财政、政策、商贸、治理、军务、图层。

天气状态本身同时承担 Weather Flyout 入口；Camera、速度与菜单不再使用独立右上浮块。

原左侧 City Management Rail 的一级管理入口移动到 Top Shell 第二层。Information Views 的入口也移动到第二层，并在顶部导航下方展开轻量 Palette。

## Management Space

Management Space 保留中央大型阻挡式面板，但删除内部重复的一级管理 Tab。

切换：

`概况 / 户籍 / 财政 / 政策 / 商贸 / 治理 / 军务`

统一通过 Gameplay Top Shell 第二层完成。

Management Space 中 Top Shell 保持可见，Main Dock / Utility Toolbar / OperationHints 继续隐藏。

## Workspace / Tool

- Workspace：保留 Top Shell 第一层，隐藏第二层管理导航；
- Building Placement：保留 Top Shell 第一层，隐藏第二层管理导航；
- 底部 Main Dock / Utility Toolbar / Tool Dock 本轮不重构，留到下一阶段统一。

## 下一阶段

底部目标是建立单一操作槽位：Normal Gameplay 常驻工具条和 Building Placement 等 Tool 专用工具条使用同一位置，Tool 状态临时替换普通工具，以获得更大的按钮和更清晰的任务反馈。

## Review

对应 Review 需要持续检查：

- Normal Gameplay 双层 Top Shell 是否居中且没有裁切；
- Finance / Policy Management Space 是否通过顶部导航切换，且内部无重复一级 Tab；
- Information Views 是否从顶部图层入口打开；
- Workspace / Building Placement 是否仅保留 Top Shell 第一层；
- Camera / Weather Right Edge Flyout 与新 Top Shell 是否发生空间冲突。
