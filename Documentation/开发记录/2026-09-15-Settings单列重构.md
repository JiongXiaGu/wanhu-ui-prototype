# 2026-09-15 Settings 单列重构

设置界面从“双栏功能卡”重构为常见 PC / 主机游戏的单列设置列表。

## 修改原因

原设置页把两个功能组并排放在中央 Surface 中：

- 更像网页 Dashboard / Inspector；
- 两栏同时争抢视线；
- 每个 Group 的暖金左边线让普通分组看起来像 Selected 状态；
- 设置内容扩充后，两栏结构不利于长期维护和滚动浏览。

## 新结构

`Header → Category Tabs → Single-column Scroll View → Footer`

当前 Category：

`显示 / 图形 / 音频 / 操作 / 游戏`

中间列表使用约 900 px 的单列内容宽度。

## 美术调整

- 删除双栏 Group Card；
- 删除普通 Section 左侧暖金线；
- 删除 Active Tab 的大面积暖金背景；
- Section 使用中性标题 + 弱分隔线；
- 每个参数默认透明，只在 Hover 出现弱 Tone；
- 暖金只用于 Tab Active、Slider Fill、Toggle On、Focus 与 Primary Action；
- Select 改成轻量值 + 下拉箭头 + 弱底线；
- Slider、Toggle、Binding 都保持横向单行布局。

## 配置扩充

参考用户提供的 `SettingsWorkspace.uxml`，保留并扩充：

- 显示模式、分辨率、刷新率、VSync、帧率限制、UI 缩放；
- 主音量、音乐、音效、环境声、后台播放行为；
- 自动存档、语言、教程、二次确认；
- 鼠标 / 滚轮灵敏度、反转、边缘滚动、镜头速度、按键绑定。

同时增加适合《万户天工》的图形配置原型：

- 渲染比例、超分辨率、帧生成、低延迟；
- 建筑 / 居民 / 植被显示距离；
- 阴影、地形、水体、反射、云层、体积雾等。

这些新增项只是信息架构与美术原型。最终 Unity 中必须和真实渲染能力对应，不保留不存在的功能。

## UI Toolkit 约束

这轮 CSS 重构主动采用 Flex Column / Flex Row 思路，避免继续依赖 Grid 作为主要结构。

Unity 目标结构：

```text
SettingsRoot
├ Header
├ CategoryTabs
├ ScrollView
│  └ SettingsList
│     └ Section → SettingRows
└ Footer
```

背景 Blur 最终使用统一 URP 全屏 Blur Pass，而不是为 Settings 单独实现。
