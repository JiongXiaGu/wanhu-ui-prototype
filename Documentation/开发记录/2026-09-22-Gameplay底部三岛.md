# Gameplay 底部三岛

上一版把 World Utility 做成两行后，1080p 下会向上侵占 Design Workspace 与 Operation Hints 空间。本轮不删除功能，而是重新分配空间职责。

```text
Left World Dock
相机 / 环境 │ 解锁 / 区域 / 地形 / 配色

Center Main Dock
设计 / 蓝图 + 建设分类

Right Utility
网格 / 范围复制移动 │ Undo / Redo │ 批量摧毁
```

Camera / Weather 从顶部 Control Tray 移除，顶部第二层只保留城市管理主域与 Information Views。World Dock 只在 Normal Gameplay 挂载；Camera / Weather 打开后 Dock 保持，Context Surface 上移到 Dock 上方。Workspace、Selection、Tool、Management、Map Panel、Pause 隐藏 World Dock。

批量摧毁的 worldDemolitionMode、Danger Tone、Operation Hints 和 Selection 互斥继续保留；只恢复右下单行布局。
