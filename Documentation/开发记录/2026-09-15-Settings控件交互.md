# 2026-09-15 Settings 控件交互

## 目的

把 Settings 从“静态美术参考”升级为真实可操作的交互原型，让网页能够直接验证按钮按下、Slider 拖动、Dropdown 展开、Toggle 状态变化、Disabled 和 Dirty Footer 的实际观感。

最终产品仍由 Unity UI Toolkit 实现；本轮 Web 行为用于确定最终运行时控件应保留的交互语义和视觉状态。

## 状态模型

Settings 从静态 Definition Value 改为：

```text
SettingDefinition
AppliedSettings
SettingsDraft
```

- 所有控件编辑 Draft；
- Draft 与 Applied 不同则进入 Dirty；
- Dirty 后“应用”按钮激活；
- 未修改时“应用” Disabled；
- 取消 / 返回丢弃 Draft；
- 恢复当前分类默认值只修改当前分类 Draft；
- 如果恢复后与 Applied 完全一致，Dirty 自动清除。

按键绑定也参与 Dirty 判断。

## Slider

已实现：

- 点击 Track 跳转；
- Pointer Capture 连续拖动；
- 实时数值刷新；
- Step 量化；
- 方向键微调；
- Shift + 方向键大步调整；
- Home / End；
- Hover / Focus / Dragging 状态；
- 视觉轨道保持细，但实际 Pointer Hit Area 扩大。

设置页纵向滚动，因此没有把滚轮绑定成 Slider 默认调节输入。

## Select

已实现自定义 Dropdown：

- 点击展开 / 收起；
- 当前值 Selected；
- Hover / Highlight；
- `↑ / ↓` 导航；
- Enter / Space 确认；
- Esc 关闭；
- 点击外部关闭；
- 靠近底部时允许向上展开；
- Open 时 Chevron 翻转；
- Menu 使用不透底深墨 Surface，避免底层设置文字穿透。

没有使用浏览器原生 Select 视觉。

## Toggle

已实现：

- 点击切换真实 Draft Value；
- `aria-pressed`；
- On / Off 配色；
- Hover；
- Pressed；
- Focus；
- Disabled。

暖金只用于 On / Focus 等高价值状态。

## Disabled 依赖

Prototype 当前用于验证的依赖：

- 超分辨率不是 DLSS 时，帧生成 Disabled；
- 关闭屏幕边缘滚动后，边缘滚动速度 Disabled。

Disabled 行仍然显示，但整体降低对比度且控件真正不可操作。

## UI Toolkit 对应

最终 Unity 不照搬 React 状态实现，但保持以下语义：

- Slider / SliderInt：Pointer + Keyboard；
- ChoicePickerField / Dropdown：Open / Focus / Selected；
- Toggle：On / Off / Focus / Disabled；
- InputBindingField：主绑定 / 备用绑定 / Rebinding；
- Presenter / Settings Controller：Draft / Applied / Restore / Dependency；
- USS Class：Hover / Focus / Open / Dragging / On / Disabled / Dirty。

显示模式、分辨率、刷新率、HDR 等设置最终还需要加入“确认保留 / 超时自动恢复”流程；本轮未实现这部分正式系统逻辑。
