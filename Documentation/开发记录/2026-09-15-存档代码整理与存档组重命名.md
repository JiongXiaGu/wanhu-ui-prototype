# 2026-09-15 存档代码整理与存档组重命名

## 本次目标

在保存页左下角增加当前存档组名称修改入口，并清理此前为了兼容读档/保存而保留的混合页面结构。

## 保存页调整

- Footer 左侧新增 `更改存档组名称`。
- Footer 右侧继续保留 `返回`。
- 点击 `更改存档组名称` 后，顶部当前游戏名称原地进入编辑状态。
- Enter / 失焦提交；Esc 取消。
- 修改后的名称立即更新当前 Save Space 标题信息。

## 代码结构整理

此前 `ArchivePanel` 同时包含 Load / Save 两套状态与分支。保存页已经独立后，这些分支成为历史负担。

本次完成：

- 新建独立 `LoadGameSpace.tsx`，只保留读档流程需要的状态与操作。
- 保留独立 `SaveGameSpace.tsx`，只负责当前游戏的新建 / 覆盖 / 重命名 / 删除手动存档。
- 主菜单读档入口改用 `LoadGameSpace`。
- Pause 保存入口继续使用 `SaveGameSpace`。
- 删除旧 `ArchivePanel.tsx`。
- 删除 Visual Review 中用于兼容旧 Archive Save selector 的依赖，测试直接识别 `.save-game-space`。

正式设计原则保持：

- Load 与 Save 可以共享缩略图、图标按钮、确认层等小组件；
- 不共享页面级状态模型和页面流程；
- Unity UI Toolkit 最终对应两个独立 Workspace / UXML。
