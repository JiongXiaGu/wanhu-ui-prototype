# Gameplay 顶部比例重整

## 背景

Gameplay Top Shell 已完成“资源状态 + 管理入口”统一，但上一版第二层图标托盘宽度和高度仍偏大，形成“大 Surface + 小图标”的比例失衡；第一层信息密度也偏细，和底部 Main Dock 使用的控制尺度不一致。

## 本轮调整

- Persistent Status Row 收敛到约 `940 × 56`；
- Management Navigation Row 收敛到约 `590 × 40`；
- 第二层继续保持纯图标，不恢复常驻文字；
- 第二层图标提升到约 `18–20 px`，单个入口约 `68–72 px` 的视觉节奏；
- 第一层资源数值字号、资源图标和行高略提升，强化“状态主栏 / 导航附属托盘”的层级；
- 两层 Surface 不再使用同一明度：主状态栏略亮、导航托盘略暗，并保留克制暖金选中反馈；
- Management Space 继续从 Top Shell 下方开始，不改变现有空间职责；
- Bottom Dock 暂不调整，下一阶段再以这套顶部尺度作为 Gameplay UI 的比例参考。

## 目标

在 1920×1080 设计基准下，让顶部成为一个清晰的主次结构，而不是两个尺寸相近的黑色矩形叠加；同时让资源信息能在正常游玩距离下快速扫读。
