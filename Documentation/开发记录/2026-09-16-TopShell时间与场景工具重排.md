# 2026-09-16 Top Shell 时间与场景工具重排

## 背景

上一版 Top Shell 第二层同时承载管理入口和时间控制，视觉密度仍偏松；部分浏览器 / 缩放状态下两层之间还会出现一条亮白接缝。新的结构把“模拟时间”提升到第一层，把“相机 / 天气 / 菜单”放到第二层场景工具组。

## 本轮修改

- 第一层 Status Row：左侧天气 / 季节时间，中间资源，右侧模拟时间控制；
- 时间控制改为纯图标：暂停 / 正常 / 加速 / 高速，不再显示 `×1 / ×2 / ×4`；
- 第二层 Control Tray：`图层 │ 城市 / 经济 / 政策 / 军事 / 宫殿 │ 相机 / 天气 / 菜单`；
- 天气图标重新成为正式玩家入口，点击打开 Weather Right Edge Flyout；
- 左侧天气状态只显示当前天气，不承担控制；
- Control Tray 从约 650×42 收紧到约 480×38；
- Status Row 与 Control Tray 约重叠 2px，Control Tray 取消顶边框并增加连接覆盖，避免浏览器缩放 / DPR 差异产生亮白 seam；
- Management Space 顶部位置随更紧凑的 Top Shell 微调。
