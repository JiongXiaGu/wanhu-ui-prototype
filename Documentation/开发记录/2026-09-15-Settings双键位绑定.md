# 2026-09-15 Settings 双键位绑定

## 目的

操作设置原先只把一个或一组 Keycap 当作展示值，无法表达正式 PC 游戏需要的主绑定 / 备用绑定结构。

本轮将按键设置改为明确的双槽模型：

`操作名称 + 主要按键 + 次要按键 + 行级恢复`

该结构与原 Unity `SettingsWorkspace.uxml` 中 `InputBindingField` 的 `primary-binding-text / secondary-binding-text` 语义一致。

## 实现

- 操作页继续保留“鼠标与镜头”手感设置；
- 新增独立“按键绑定” Section；
- 按键绑定按以下功能域折叠：
  - 基础操作；
  - 营造与道路；
  - 时间控制；
  - 镜头操作；
  - 快捷栏；
- 默认展开基础操作；
- 每个操作具有主要按键和次要按键两个独立槽位；
- 次要按键为空时显示 `+ 添加`；
- 点击 Binding Cell 后进入 `按下新的按键…` 监听态；
- Esc 取消监听；
- Delete / Backspace 清除当前槽位；
- Web Prototype 做基础冲突检测，不静默覆盖其它绑定；
- 行级恢复按钮在 Hover / Focus 时出现；
- `settings-bindings.css` 单独维护双键位组件视觉，主 Settings CSS 不继续膨胀。

## UI Toolkit 对应

正式 Unity 实现应使用：

```text
InputBindingRow
├ Label
├ PrimaryBindingButton
├ SecondaryBindingButton
└ ResetButton
```

Web 的键盘监听只用于原型验证；正式实现必须接 Input System Rebinding，并支持鼠标、键盘、手柄等真实 Control Path。
