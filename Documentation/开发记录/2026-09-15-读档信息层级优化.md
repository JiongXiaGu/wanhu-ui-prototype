# 2026-09-15 读档信息层级优化

## 背景

上一版读档界面已经完成“游戏组 → 组内存档”的两层结构，但仍存在两个问题：

1. 游戏组 Card 同时展示年份、季节、兼容性摘要等信息，和具体存档信息发生职责重叠；
2. 存档 Card 右上使用循环箭头、闪电、书签等类型图标，首次进入页面的玩家难以直接理解。

## 本轮调整

### 游戏组 Card

只保留：

- 游戏组名称；
- 总游玩时间；
- 最后保存的现实时间；
- 最新存档使用的游戏版本。

删除：

- 游戏内年份；
- 季节 / 天气；
- “含旧版存档”；
- “含不兼容存档”。

兼容性属于具体存档，不再做游戏组级聚合提示。

### 存档类型

统一正式命名：

- 自动存档；
- 手动存档；
- 快速存档。

删除“玩家存档”说法。

默认名称示例：

- `自动存档.001`；
- `手动存档.025`；
- `快速存档.008`。

### 存档 Card

状态区改为文字优先：

```text
自动存档   v0.8.4
过时   手动存档   v0.8.3
不兼容   快速存档   v0.7.8
```

删除存档类型抽象图标。

操作按钮仍使用图标，因为重命名 / 读取 / 删除属于明确的动作语义，并有 Tooltip / Accessible Label。

### 时间信息

存档 Card 不再显示天气。

固定区分：

- 游戏时间：例如 `第12年 8月17日`；
- 保存时间：例如 `2026-09-15 16:58`。

现实保存时间不再使用“今天 / 昨天”这种相对表达。

## 保持不变

- 顶部没有搜索和排序；
- 默认最新存档在顶部；
- 类型筛选：全部 / 自动 / 手动 / 快速；
- `隐藏过时存档` 默认关闭；
- 不兼容存档读取按钮真正 Disabled；
- 左右列表继续使用大量压力测试数据；
- Footer 只管理游戏组，单个存档操作仍在 Card 内完成。

## Unity UI Toolkit 落地

最终建议：

```text
GameGroupCard
├ Thumbnail
├ GroupName
├ PlayTime + LastSavedAt
└ LatestVersion

SaveCard
├ Thumbnail
├ Name / RenameField
├ GameDate
├ RealSavedAt
├ TextStatus
│  ├ Compatibility（按需）
│  ├ SaveType
│  └ Version
└ Actions
   ├ Rename
   ├ Load
   └ Delete
```

本轮修改只改变信息职责与视觉表达，不改变“游戏组 → 具体存档”的核心数据层级。
