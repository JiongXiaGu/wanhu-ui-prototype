# 工具辨识与局部布局

本轮依据用户确认的范围执行：工具模式辨识、详情浮层避让、Settings 表单比例、顶部图标和右下工具分组。材质与建筑配色方案维持文字目录；库存、管理页及资源图标暂缓，没有加入缩略图目录、新建游戏预览或帮助系统。

## 变更职责

ToolActionBar 增加可选 icon-label 变体，短名称和完整提示分别持有。仅地形、树木、配色采用；其他调用点默认仍为纯图标。主要模式保持固定宽度与既有命中高度，Selected 与 Focus 独立。即时编辑完成按钮表示结束工具，配色不再显示本来就不具备回退能力的重复 Cancel；同步清理了无效回调属性。

五个地形专用图标经过同一 Source / PNG / Manifest / Adapter 管线，新增自定义来源标识。总量 109，原有 104 个通用图标保持。

Asset Inspector 的纯定位计算从 React 展示生命周期中拆出。先转换逻辑坐标，候选在完整 Workspace 外生成，再按当前目标、目录、HUD 保护区域与边界排序。Observer / Scroll / Resize 只处理展示几何，业务状态仍由原数据拥有者提供。

Settings 保持全屏页与现有设置流程，普通行使用稳定标签列、40px 间隔和字段列；键位表不改为普通字段。顶部四项仍是快捷入口，右下仍只有一个 Host，未增加重复导航或工具栏。

## 实际回归中发现的收尾

首轮基础 UI Review 与原有 Typography Review 通过。新增的工具 / 浮层 / 设置检查发现两个真实问题：

- fixed-canvas-guards.css 仍以 1100px / 420px 覆盖 Settings 已调整的内容 / 字段尺寸，造成右侧多余空白。移除这两条旧覆盖，由 settings-panel.css 唯一持有 820px / 380px 几何，并增加真实计算宽度检查。
- SelectControl 的 Esc 虽关闭自身下拉，但按键继续到 Settings 的全局监听，导致设置页也被关闭。Select 根节点在展开时捕获并消费 Esc，关闭菜单并将焦点交回 Trigger；测试覆盖 Trigger、Option 和暂停设置中的同一行为，不通过修改测试操作绕过问题。

新增纯几何单元测试首次通过 typescript 编译器 API 加载时，遇到当前依赖导出不兼容；改为 CI Node 22 的类型剥离加载方式。图标原校验与迁移审查在该轮已通过，此问题属于新测试的加载方式，不是以跳过检查代替修复。

## 验证约定

Build 包括图标、字号、迁移审查、纯几何 / 自定义 PNG / 范围检查及正式构建。UI Review 保留原有两套矩阵，并增加 capture-tool-usability-review.mjs；输出 tool-usability-report.json。

关键审图包括地形五种模式、树木刷子 / 单棵 / 禁用、配色三种模式、两排建筑条目 / 城墙悬停、设置各分类 / 下拉 / 数字弹窗 / 键位表 / 暂停入口、1440p / 4K 和真实夜景。正式结果以当前提交对应的 Actions、报告及实际截图为依据，不从代码写法推断已通过。

正式设计和接手入口同步更新了《工具辨识与局部布局》、AGENTS、工作交接和图标管线。阶段文件哈希保护只对应本轮范围，未来用户批准相关模块的任务时应同步调整；不是永久冻结模块。

本轮没有运行 Unity 6.6 Player，未宣称原生滤镜、Unity 字体、真实手柄导航和设备性能已完成验证。
