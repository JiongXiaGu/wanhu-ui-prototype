# 2026-09-14

## 原型架构收敛

将早期依赖 DOM 注入、MutationObserver 和补丁脚本的实现逐步收敛为正常 React 组件与集中状态模型。

主要结果：

- Gameplay 状态集中到 `src/app/ui-state.ts`；
- Review Bootstrap 集中到 `src/app/scenarios.ts`；
- Gameplay、Workspace、Tool、Pause 明确为不同 UI Space；
- Camera / Weather 统一为 Right Edge Flyout；
- BuildingPlacementOverlay、BuildingPlacementDock、GameplayOperationHints 变成独立组件；
- Pause Save / Settings 纳入 `pauseView`；
- Main Menu Settings 与 Pause Settings 共用 `SettingsPanel`；
- Load / Save 收敛为共享 Archive 系统。

## Building Placement

确定 Building Placement 使用模式驱动参数面板，而不是把所有参数同时展开。

地形关系：

- 平：平衡挖填；
- 填：只填方；
- 高：手动标高。

调整对象：

- 位：位置；
- 层：楼身体量；
- 顶：屋顶；
- 面：立面，当前 Disabled / 未完成。

底部 Dock 分为 Utility 与 Main 两层：

- Utility：网格吸附、网格显示、撤销、重做；
- Main：平/填/高、位/层/顶/面、完成、取消。

GameplayOperationHints 保留在右下，最终定位为轻量 Shortcut Rail。

## Pause

Pause 从普通菜单改为全局 Pause Space。

视觉与信息调整：

- 世界画面保留但压暗；
- 删除装饰编号；
- 删除右箭头；
- 删除无意义品牌尾标；
- Esc：Save / Settings 先返回 Pause Menu，Pause Menu 再恢复游戏。

## Archive

明确存档不是单层 Save 列表，而是：

`Game Group → Save Timeline → Preview`

Game Group 代表玩家的一整场游戏。Load 可以切换 Game Group；Pause Save 锁定当前 Game Group。

Archive 改为全屏 Global Space。

## Settings

Settings 改为全屏 Global Space，并由 Main Menu / Pause 共用。

分类：

- 显示
- 图形
- 音频
- 操作
- 游戏

删除原先无意义的右侧 Summary / Preview，并逐步将解释性文案迁移到 Tooltip。

## UI 信息减法

统一审查所有主要 UI：

- Main Menu
