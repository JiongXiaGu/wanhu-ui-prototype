# 2026-09-16 夜景背景联动

## 目标

给 Gameplay Web Prototype 增加一个最小的昼夜演示：天气面板底部的 `日内时间` 直接驱动场景背景切换，用于检查现有 UI 在夜景下的可读性与层级。

## 实现

- 夜景资源统一命名为 `public/assets/wanhu-gameplay-city-night.png`；
- `GameplayScreen` 持有一个轻量 `dayTime` 场景预览值，不进入 `GameplayUiState` reducer；
- Weather Context Panel 的 `日内时间` 直接编辑该值；
- `18:00–05:59` 使用夜景背景，`06:00–17:59` 使用原白天背景；
- 只做硬切，不增加渐变、过渡层或额外昼夜状态机；
- Top HUD 时间文本与同一个 `dayTime` 同步，避免背景与时间显示不一致；
- 清理 `backgrounds.css` 对 `.gameplay-screen` 的固定白天图 `!important` 覆盖；Gameplay 的活动场景图由 `GameplayScreen` 状态负责，CSS 只保留 cover / position / repeat 几何规则。

## Unity UI Toolkit 边界

这只是 Web Prototype 的视觉复核手段。正式 Unity 不应复制“背景图片切换”实现，而应把同一交互语义接到真实世界时间、URP 光照、天空与环境系统。UI 只消费世界时间状态。

## Visual Review

新增 `scripts/capture-night-review.mjs`：

- 从 Weather 面板把日内时间改到 `22:00`；
- 验证 Gameplay 切换到夜景资源；
- 验证 Top HUD 同步显示 `22:00`；
- 输出 `35-weather-night.png`；
- 关闭 Weather 面板后输出 `36-gameplay-night.png`，用于检查完整 HUD 在夜景下的表现；
- 再把时间改回 `14:30`，验证原白天背景恢复。

本轮 Build 与完整 Visual Review 均通过，并实际复核两张 1920×1080 夜景截图。

夜景结论：

- Top Shell、Weather Context Panel、Main Dock 与夜景背景之间仍有足够 Surface 分离度；
- 暖金 Active 状态在夜间灯火背景下仍然清晰，不需要单独的 Night UI Theme；
- 右下操作提示、World Utility 的非激活图标、左上指南针与右上菜单属于低强调信息，夜景下对比会进一步降低，但当前不影响原型主流程，不为此引入额外昼夜视觉分支；
- 当前保持同一套昼夜 UI Token，更符合后续 Unity UI Toolkit 的共享样式契约。
