# 可读性与 Unity 6.6 视觉基线

本轮由项目方批准：保持当前画面布局与烟墨熟铜方向，升级阅读舒适度、控件状态和材质稳定性，并将迁移目标更新为 Unity 6.6 + URP。

## 视觉调整

共享操作与正文档位调整为 12px，持续阅读内容使用 13px，分组 / 存档名称使用 14px；辅助标签与元信息 11px，Context / Workspace 标题维持 16 / 18px。不扩大逻辑画布，不移动现有 HUD、Workspace 和左下工具槽位。

提高浅纸灰与默认图标的清晰度；小字号熟铜文字与熟铜填色分开。Context、Workspace 和全屏阅读区提高中性 Tint 的稳定性，不用更大模糊半径补救对比。

Stepper 保持命中区、减弱默认框线；Slider 使用固定尺寸滑块，Hover 不再引发尺寸变化。Select 采用高实度菜单而非额外私有 Blur。Hover 中性、Selected / On 熟铜、Focus 独立轮廓，选中与键盘焦点可并存。Toggle 保持普通 Track / Thumb，不恢复中间凹槽。

Inventory 比较数据、Management 正文和 Archive 名称 / 时间按阅读角色分档。数字使用稳定宽度与对齐，不更改数据和业务逻辑。

## 样式职责收敛

修改落在原来的 Theme / Control / Feature 所有者中，没有新增末尾美化覆盖层。

Archive 将旧基础规则与文件后半部的覆盖合并。Management Skin 移除对 Inventory 内部样式的重复定义，库存自身持有布局、选中和阅读层级。此范围之外的历史 CSS 例外不宣称已经全部清理。

## 审图中发现并修复的问题

第一轮正式工具回归通过，扩展回归在相机页面等待已退役的裸 `.gameplay-context-panel` 时超时。改为当前具体面板类，关闭检查使用共享 `.gameplay-left-context-surface`；夜景流程显式进入“场景模拟”，再操作真实时间 Slider，不伪造 DOM 状态。

第一轮截图还发现：存档四字时间标签在 44px 列内因字号与字距增长换行；库存状态表头右对齐而状态内容左对齐。时间标签改为预留 56px 且保持单行，库存状态列统一左对齐。测试增加日期单行 / 溢出及状态列对齐检查，防止只看构建成功而漏掉布局问题。

## 文档与验证边界

更新 AGENTS、README、工作交接、Typography 与 UI Toolkit 落地规范，增加 Unity 6.6 视觉能力与回退规范。升级前完整交接原样保存在历史目录，当前入口不再以旧字号或旧引擎限制指导实现。

Unity 6.6 原生 backdrop-filter / drop-shadow 是迁移时优先验证的路径，旧共享 URP Blur 变为效果或性能不满足时的回退。Dialog / Pause 当前不增加额外 Blur，是已确认的美术与成本选择，不再声称 UI Toolkit 无法模糊 UI。

构建与回归以本轮提交关联的 GitHub Actions 为证：Build 包含 icons:check、audit:scale、audit:unity、build；基础 UI Review 加扩展阅读 / 状态 / 昼夜 / 4K 检查。正式交付还需下载 Artifact 并打开关键页面截图，而非仅看自动测试结果。

本仓库没有运行真正的 Unity 6.6 Player。字体离线资源与 Font Asset、原生滤镜、实际 PanelSettings、手柄导航和目标设备性能仍需在 Unity 工程中验证。建筑缩略图重制、不改布局以外的新信息架构及完整历史 CSS 清理不属于本轮完成范围。
