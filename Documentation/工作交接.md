# 工作交接

这是新对话、新 AI 或新开发者接手《万户天工》UI Prototype 时的首要入口。

## 项目定位

本仓库是《万户天工》的 **UI 美术、构图、信息架构与交互验证原型**。

最终运行时 UI 仍然由 **Unity UI Toolkit** 实现：

- UXML：稳定结构；
- USS：布局、视觉状态、Transition；
- C#：状态、事件、数据绑定、输入；
- Sprite / Texture / RenderTexture：视觉资产；
- Painter2D / Mesh：必要自定义绘制；
- URP：场景级视觉能力。

网页不是最终 Web 产品，不要为了浏览器实现方便而设计 Unity 难以维护的核心结构。

正式落地约束：`Documentation/UI Toolkit落地规范.md`

迁移审查：`Documentation/代码审查/2026-09-15-UI Toolkit迁移可行性审查.md`

## 项目入口

- GitHub：`JiongXiaGu/wanhu-ui-prototype`
- Vercel：`https://wanhu-ui-prototype.vercel.app/`
- 技术栈：Vite + React + TypeScript + Playwright + GitHub Actions + Vercel
- 设计基准：1920×1080
- 当前计划使用 URP 全屏 Blur Pass 处理 Pause / Settings / Archive / Management 等场景级背景弱化。

## 当前视觉原则

- 信息做减法，层级做加法；
- 世界画面优先；
- 黛墨 / 深青灰 Surface；
- 浅纸主文字；
- 暖金只用于 Selected / Focus / On / Primary；
- HUD 使用 `10 / 14 / 18px` 三档圆角家族；
- 解释性小字优先进入 Tooltip / Inspector；
- 如果界面单调，优先补真实内容、Tone、状态反馈与动效，不堆装饰。

## Gameplay 当前空间基准

正式规则：`Documentation/UI空间与状态架构.md`

最新交互审查：`Documentation/代码审查/2026-09-16-Gameplay UI交互逻辑审查.md`

Gameplay 主空间优先级：

`Pause > Tool > Workspace > Management > Gameplay`

屏幕稳定槽位：

- 左上：Navigation HUD；
- 顶部中央：Top Shell；
- 右上：System Menu + 未来 Notifications / Objectives；
- 左下：Context Surface；
- 中下：Main Dock / Workspace / Tool Dock；
- 右下：Operation Hints + World Utility Toolbar。

外围 HUD 默认使用 `16px` Safe Edge，同级 Surface 常用 `12px` 间距。

### Gameplay Top Shell

第一层 **Persistent Status Row**：

- 左：天气状态 + 季节 / 时间；
- 中：钱粮 / 人口 / 木材 / 石料，资源几何中心必须对齐屏幕中心；
- 右：纯图标模拟时间控制：暂停 / 正常 / 加速 / 高速。

天气状态只显示当前天气，不作为控制入口。`speed` 支持 `0 / 1 / 2 / 4`，其中 `0` 是模拟暂停，不等于 Pause Menu。

第二层紧凑 **Control Tray** 当前约 `400 × 38px`：

`Camera / Weather │ 城市 / 经济 / 政策 / 军事 / 宫殿 │ Information Views`

语义是：左侧场景观察，中间城市管理，右侧数据观察。Menu 已从 Top Shell 移除。

Top Shell 两层轻微重叠约 2px，第二层不单独绘制顶部亮边，避免浏览器缩放 / DPR 下出现白色接缝。

Control Tray 在 Normal Gameplay、Workspace、Management 中保留；Tool 中隐藏，只保留 Persistent Status Row。

### 左上 Navigation HUD

当前 Web Prototype 在左上提供低存在感城市缩略图 + 指南针 / 北向提示，用于验证以后“小地图 / 指南针”槽位。

规则：

- 16px 左 / 上 Safe Edge；
- Normal Gameplay / Workspace / Tool 中保留；
- Management / Pause 中隐藏；
- 正式 Unity 可替换成真实小地图 RenderTexture 或简化城市导航图；
- 不在这里堆复杂管理信息。

### 右上 System / Notification Zone

Pause Menu 使用一个独立低存在感 System Menu Button：

- 约 46×46；
- 16px 右 / 上 Safe Edge；
- 半透明深墨 Surface；
- 默认较弱，Hover 才明显提亮。

右上其它空间留给未来 Notification / Pending Event / Objective，不再给 Camera / Weather 占用。

### Context Surface

Camera / Weather 已从旧 Right Edge Flyout 迁移到左下共享 Context Surface。

当前几何：

- 左侧 16px；
- 底部位于 Main Dock 上方约 12px；
- Camera 宽约 360px；
- Weather 宽约 400px；
- 高度由内容决定，最大约 50vh。

交互：

- Camera / Weather 彼此互斥；
- 再次点击当前入口关闭；
- 打开 Camera / Weather 会关闭 Design Workspace，并清空 Main Dock 当前分类；
- 打开 Design Workspace 会关闭 Camera / Weather；
- Tool / Management / Pause 中关闭 Context Surface；
- Esc 优先关闭 Context Surface。

未来选中建筑 / 居民等对象时，左下同一位置将优先作为 Selection Inspector 的稳定落点。推荐“世界轻浮签 + 左下详细 Inspector”的双层表达；Selection Inspector 与 Workspace 是否共存 / 压缩，等对象选择系统实现时再验证，不机械继承 Camera / Weather 的互斥规则。

### Gameplay Launcher 统一规则

Gameplay 中“点一下打开、再点一下关闭”的 Surface Launcher 状态集中到 `GameplayUiState` / reducer。

当前 Surface Launcher 包括：

- 城市 / 经济 / 政策 / 军事 / 宫殿；
- Camera / Weather；
- Main Dock 设计模式八个分类；
- Information Views Palette。

规则：

- 同入口再次点击 → 关闭自己的 Surface；
- 同组其它入口 → 切换目标 Surface；
- 关闭按钮 / Esc / 再次点击入口最终修改同一份状态。

不要错误套到所有 Button：时间速度、Main Dock 设计 / 蓝图、Settings Tab、Building Placement 模式属于 Exclusive Selector；Grid Snap / Grid Visible 属于 Toggle；Design Asset Card、Undo / Redo、完成 / 取消属于 One-shot Action。

### Main Dock

Main Dock = **模式选择器 + 当前模式分类带**。

左侧模式：

`设计 / 蓝图`

设计模式：

`道路 / 桥梁 / 建筑 / 台基 / 城墙 / 围墙 / 装饰 / 树木`

蓝图模式：

`全部 / 民居 / 商业 / 工坊 / 管理 / 科学 / 信仰 / 军事 / 宫殿`

状态原则：

- `dockMode` 默认 `design`；
- `dockCategory` 默认 `null`，没有默认选中；
- 切换设计 / 蓝图清空 `dockCategory`；
- 不分别记住两个模式上一次分类；
- 只有玩家明确点击分类才 Selected；
- 设计八类全部进入同一个 Design Workspace；
- 再次点击当前设计分类、关闭按钮或 Esc 都关闭 Workspace 并清空分类；
- 已打开 Design Workspace 时点击另一个设计分类，只替换 Definition。

Blueprint Workspace 尚未实现，不复制空面板。

Main Dock 约 `940 × 76px`；普通 Gameplay / Workspace 保留，Tool / Management / Pause 隐藏。

### World Utility Toolbar

右下稳定 World Utility Toolbar 当前包含：

- 地图解锁；
- 区域编辑；
- 地形编辑；
- 配色工具；
- 网格吸附；
- 网格显示；
- 范围复制；
- 范围移动；
- 撤销；
- 重做。

规则：

- Normal Gameplay / Workspace / Tool 中保留；
- Management / Pause 中隐藏；
- 只放跨分类 / 跨工具的世界级能力；
- 不放完成 / 取消等当前任务流程动作；
- 不放道路 / 建筑等主建造分类；
- 网格吸附 / 网格显示属于全局状态，进入 Building Placement 不重置；
- Operation Hints 在其上方约 12px，结构独立。

### Management Space

复杂系统进入中央大型阻挡式 Management Space。

规则：

- 世界停止直接交互，但压暗 / 轻模糊后继续可见；
- Top Shell 两层保留；
- 顶部五个管理域切换当前 View；
- Management Surface 内不重复一级 Tab；
- 再次点击当前一级入口关闭；
- 隐藏 Navigation HUD、World Utility、Main Dock、Operation Hints、Context Surface；
- Esc / 关闭按钮回 Normal Gameplay。

### Information Views

属于观察城市，不是管理城市。

当前：

`默认 / 地价 / 人口 / 商业 / 道路 / 治安 / 水利`

入口位于 Control Tray 最右侧。Palette 从右侧图层按钮下方展开；再次点击入口收起；选中图层后自动收起。

`mapPanelOpen` 在 `GameplayUiState` 中，不由 GameplayHUD 自己维护局部状态。

### Design Workspace

正式规则：`Documentation/Design Workspace设计规范.md`

八个设计入口共享一个配置驱动 Design Workspace。

统一结构：

`Header + Primary Rail + Context Filter + Search + Content Grid + Pager`

Primary Rail：

- 约 146px；
- 第一个通用筛选统一显示 `所有`；
- 每组最多 7 项；
- 常规标签最多约 6 个汉字、不换行；
- 超出组容量后使用 Rail 分页 / 滚轮切组。

Content Grid / Card：

- 4×2 = 8项 / 页；
- Workspace 约 1240×370；
- Card 约 255×100；
- Preview 约 64×64，1:1；
- 名称约 14.2px / 600，最多两行；
- 属性约 10.5px；
- Card 是 Action Button，不是 Toggle，不使用 `aria-pressed`。

Asset Inspector：

- 跨系统共享；
- Children 决定自然尺寸，框架只限制 240–380 宽 / 90–320 高；
- 第一次 Hover 约 280ms，相邻 Item 已打开时立即换内容；
- Keyboard / Gamepad Focus 立即显示；
- `pointer-events:none`；
- 更深、更实的墨青 Surface + 清晰细边 + 较强阴影，视觉上高于 Workspace。

当前只有建筑 Asset 接 Building Placement；道路 / 桥梁 / 台基 / 城墙 / 围墙 / 装饰 / 树木先完成共享目录浏览。

### Tool / Building Placement

Tool 组成：

- Navigation HUD；
- Top Shell Persistent Status Row；
- ToolOverlay；
- 中央 Tool Dock；
- World Utility Toolbar；
- Operation Hints；
- 右上 System Menu。

进入 Tool 后隐藏 Control Tray / Main Dock / Workspace / Context Surface / Information Palette / Management。

Building Placement 中央主控：

`平 / 填 / 高 │ 位 / 层 / 顶 / 面 │ 完成 / 取消`

当前约 66px 高；模式按钮约 48×48；完成按钮约 90px+ 宽，视觉权重高于 World Utility。

Grid / Undo 不在 Tool 内复制。

完成 / 取消后返回 `设计 → 建筑` Design Workspace。

## Gameplay Esc 当前基准

Gameplay Surface 退栈集中在 `GameplayScreen`。

顺序：

1. Dialog / Safe Confirmation；
2. Camera / Weather Context Surface；
3. Information View Palette；
4. Tool；
5. Workspace；
6. Management；
7. 非默认 Map View；
8. 无局部 Surface时进入 Pause Menu。

Workspace Search 等更局部输入控件可先消费自己的第一次 Esc。

Pause 内：Pause Save / Settings → Pause Menu → 恢复游戏。

## Settings 当前正式基准

正式规则：`Documentation/设置界面规范.md`

布局：

- 全屏 Settings；
- 顶部分类 `显示 / 图形 / 音频 / 操作 / 游戏`；
- 中间单列 ScrollView；
- 不使用双栏 Settings Card；
- Footer 只保留“恢复当前分类默认值”。

保存策略：

- 普通设置：即时生效 + 即时保存；
- 显示模式 / 显示器 / 分辨率 / 刷新率 / HDR / UI Scale：Temporary Apply + 15秒 Safe Confirmation；
- UI Scale 是 Select：`80 / 90 / 100 / 110 / 125 / 150%`。

Binding：

- 操作 + 主要按键 + 次要按键 + 恢复；
- 支持 Listening、Esc 取消、Delete 清除、冲突提示；
- 最终 Unity 使用 New Input System Rebinding。

- Management 隐藏 Navigation HUD / Context Surface / Main Dock / World Utility；
