# 工作交接

这是新对话、新 AI 或新开发者接手《万户天工》UI Prototype 时的首要入口。

## 项目定位

本仓库是《万户天工》的 **UI 美术、构图、信息架构与交互验证原型**。

最终运行时 UI 仍然由 **Unity UI Toolkit** 实现：

- UXML：稳定结构；
- USS：布局、视觉状态、Transition；
- C#：状态、事件、数据绑定、输入；
- Sprite / Texture / RenderTexture：视觉资产；
- Painter2D / Mesh：必要自定义绘制；
- URP：场景级视觉能力。

网页不是最终 Web 产品，不要为了浏览器实现方便而设计 Unity 难以维护的核心结构。

正式落地约束：`Documentation/UI Toolkit落地规范.md`

迁移审查：`Documentation/代码审查/2026-09-15-UI Toolkit迁移可行性审查.md`

## 项目入口

- GitHub：`JiongXiaGu/wanhu-ui-prototype`
- Vercel：`https://wanhu-ui-prototype.vercel.app/`
- 技术栈：Vite + React + TypeScript + Playwright + GitHub Actions + Vercel
- 设计基准：1920×1080
- 当前计划使用 URP 全屏 Blur Pass 处理 Pause / Settings / Archive / Management 等场景级背景弱化。

## 当前视觉原则

- 信息做减法，层级做加法；
- 世界画面优先；
- 黛墨 / 深青灰 Surface；
- 浅纸主文字；
- 暖金只用于 Selected / Focus / On / Primary；
- HUD 统一使用 `10 / 14 / 18px` 三档圆角家族，避免模块之间继续出现方角 / 圆角混用；
- 解释性小字默认进入 Tooltip；
- 如果界面单调，优先补真实内容、Tone、状态反馈与动效，不堆装饰。

## Gameplay 当前空间基准

正式规则：`Documentation/UI空间与状态架构.md`

最新交互审查：`Documentation/代码审查/2026-09-16-Gameplay UI交互逻辑审查.md`

Gameplay 内部空间优先级：

`Pause > Tool > Workspace > Management > Gameplay`

### Gameplay Top Shell

顶部已经统一成一个控制系统，不再使用“左侧管理 Rail + 中间 HUD + 右上 Quick Controls”三块分散布局。

第一层 **Persistent Status Row** 按三段固定：

- 左：天气状态 + 季节 / 时间；
- 中：钱粮 / 人口 / 木材 / 石料，资源几何中心必须对齐屏幕中心；
- 右：纯图标模拟时间控制：暂停 / 正常 / 加速 / 高速。

天气状态只显示当前天气，不作为控制入口。`speed` 支持 `0 / 1 / 2 / 4`，其中 `0` 是模拟暂停，不等于打开 Pause Menu。

第二层是紧凑 **Control Tray**：

`信息视图 │ 城市 / 经济 / 政策 / 军事 / 宫殿 │ 相机 / 天气 / 菜单`

语义是：左边观察城市，中间管理城市，右边是场景 / 系统入口。

一级管理域常驻只显示图标，通过 Hover Tooltip 和 ARIA Label 提供名称。当前内容映射暂时为：城市→City、经济→Finance、政策→Policy、军事→Military、宫殿→Governance；户籍、商贸、治理等旧内容后续在五个一级域内部重新整理。

Top Shell 两层采用轻微重叠，第二层不再单独绘制顶部亮边，避免浏览器缩放 / DPR 下出现白色接缝。

Control Tray 在 Normal Gameplay、Management Space 和 Building Workspace 中保留；进入 Tool / Building Placement 后隐藏，只保留第一层状态栏。

### Gameplay Launcher 统一规则

Gameplay 中“点一下打开、再点一下关闭”的 Surface Launcher 逻辑集中到 `GameplayUiState` / reducer，不由各组件自行维护互相独立的业务布尔状态。

Surface Launcher 当前包括：

- 城市 / 经济 / 政策 / 军事 / 宫殿；
- Camera / Weather；
- Main Dock 中会打开 Workspace 的“建筑”；
- Information Views Palette。

规则：

- 同入口再次点击 → 关闭自己的 Surface；
- 同组其它入口 → 切换到目标 Surface；
- 关闭按钮 / Esc / 再次点击入口最终修改同一份状态。

不要把这条规则错误套到所有 Button：时间速度、Main Dock 的设计 / 蓝图、Settings Tab、Building Placement 模式属于 Exclusive Selector；Grid Snap / Grid Visible 属于 Toggle Setting；Undo / Redo / 完成 / 取消属于 One-shot Action。

### Main Dock

Main Dock 当前已经从旧的单排分类重构为 **模式选择器 + 当前模式分类带**。

左侧模式：

`设计 / 蓝图`

设计模式分类：

`道路 / 桥梁 / 建筑 / 台基 / 城墙 / 围墙 / 装饰 / 树木`

蓝图模式分类：

`全部 / 民居 / 商业 / 工坊 / 管理 / 科学 / 信仰 / 军事 / 宫殿`

状态原则：

- `dockMode` 默认是 `design`；
- `dockCategory` 默认是 `null`，**没有默认选中的分类**；
- 切换设计 / 蓝图只切内容集合，同时清空 `dockCategory`；
- 不分别记住两个模式上一次选中的分类；
- 只有玩家明确点击某一分类，它才进入 Selected；
- 关闭 Building Workspace 后“建筑”恢复未选中；
- 再次点击当前“建筑”会关闭 Workspace 并清空分类。

当前只有设计模式“建筑”正式接入 Building Workspace；其它设计分类与 Blueprint Workspace 后续逐步接入，不为了占位而复制空面板。

Main Dock 视觉继续维持约 `940 × 76px`；左侧模式区约 `96px`，右侧分类按当前数量平均分配，图标约 `21px`。Main Dock 是普通 Gameplay 的主建造入口，进入具体 Tool 后由 Tool Bottom Dock 接管主控职责。

### World Utility Toolbar

右下角是稳定的 **World Utility Toolbar / 世界工具栏**，不是某个 Tool 的临时快速条。

当前包含：

- 地图解锁；
- 区域编辑；
- 地形编辑；
- 配色工具；
- 网格吸附；
- 网格显示；
- 范围复制；
- 范围移动；
- 撤销；
- 重做。

规则：

- Normal Gameplay / Workspace / Tool 中保留；
- Management / Pause 中隐藏；
- 只放跨分类、跨工具仍可能使用的世界级辅助能力；
- 不放完成、取消、确认放置等当前任务流程动作；
- 不放道路 / 建筑 / 园林等主建造分类；
- 网格吸附、网格显示使用 `GameplayUiState` 的同一份全局状态，进入 Building Placement 不重置；
- Operation Hints 仍是独立模块，位于工具栏上方，只显示输入说明，不与工具栏合并。

Gameplay 外围 HUD 统一使用 `16px` 上 / 左 / 右 / 下安全边距；几何与视觉 Token 集中由 `src/gameplay/gameplay-hud-layout.css` 管理。

### Normal Gameplay

显示：

- Gameplay Top Shell 两层；
- World Utility Toolbar；
- Main Dock；
- 轻量 OperationHints。

### Management Space

复杂城市系统进入**中央大型阻挡式 Management Space**。

一级管理分类已经收束到 Top Shell Control Tray，因此 Management Surface 内部**不再重复一级 Tab**。

规则：

- 世界停止直接交互；
- 背景城市仍可见，但压暗并轻微模糊；
- Top Shell 两层保留；
- 通过顶部五个管理域切换当前 Management View；
- 再次点击当前同一个一级管理图标关闭 Management Space；
- 隐藏 World Utility Toolbar、Main Dock、OperationHints、Right Edge Flyout；
- Esc / 关闭按钮回 Normal Gameplay；
- Finance 当前作为复杂页面样例，包含指标、收支趋势、收入构成、税赋设置和财政判断。

### Right Edge Flyout

正式 Gameplay 入口：

- Camera；
- Weather Control。

规则：

- 从 Top Shell Control Tray 右侧打开；
- Camera / Weather 互斥；
- 再次点击当前同一个入口关闭；
- Flyout 使用和其它 HUD 相同的 `16px` 顶部 / 右侧安全边距，不贴屏幕边缘，也不再留旧 `top:72px` 的大空白；
- Normal Gameplay 与 Building Workspace 都可以使用；
- Workspace 与轻量 Flyout 可以同时存在，互不顺带关闭；
- 进入 Management / Tool / Pause 时关闭 Flyout。

需要较宽统计、多级 Tab、趋势图或大量管理参数的功能应进入 Management / Workspace，不继续扩宽 Flyout。

此前 `gameplay-context-unified.css` 曾在多个组件 CSS 之后重复覆盖几何。当前该 Override 层已经删除：Right Edge Flyout 由 `right-edge-flyout.css` 自己维护，Building Placement 由自己的目录 CSS 维护。后续继续坚持“一个组件只有一个明确的几何 / 视觉所有者”。

### Information Views

属于“观察城市”，不是“管理城市”。

当前：

`默认 / 地价 / 人口 / 商业 / 道路 / 治安 / 水利`

入口位于 Top Shell Control Tray 最左侧图层图标。Palette 从顶部导航下方展开；再次点击图层入口收起；选择图层后也自动收起，主要变化发生在世界地图。

`mapPanelOpen` 已进入 `GameplayUiState`，不再由 `GameplayHUD` 自己维护局部 state。

地图数据效果当前仍是原型热力渐变，后续应逐步贴合真实街区、建筑、道路和服务覆盖。

## Workspace Browser 当前基准

统一结构：

`Primary Rail + Context Filter + Content Grid`

### Primary Rail

- 一级分类，图标 + 简短文字；
- `全部建筑` 与其它分类完全同样样式；
- 每组显示 5 个分类；
- 左侧竖向刻度切换分类组；
- 鼠标在 Rail 上滚轮可整组切换；
- 切换可见组不自动选择分类。

### Context Filter

- 顶部纯文字；
- 与 Primary Rail 是正交筛选维度；
- 切换一级分类不能偷偷重置顶部筛选。

建筑当前示例：

`全部 / 庑殿 / 歇山 / 悬山 / 硬山 / 攒尖 / 卷棚 / 其他`

### Content Grid

- 建筑当前固定 `3 列 × 2 行 = 6 项 / 组`；
- Card 使用左侧矩形预览 + 右侧名称 / 一条属性；
- 文字是主识别信息；
- 主内容底部使用 `· · ━ · ·` 无页码分页；
- Content Grid 上滚轮整组翻页；
- 不使用无限长建筑列表。

进入 Building Workspace 后：

- Top Shell 两层全部保留；
- Camera / Weather 继续可用；
- World Utility Toolbar 保留；
- Main Dock 保留，并保持 `设计 / 建筑` 为当前显式上下文；
- Workspace 占据底部 Dock 上方的浏览空间；
- 再次点击 Main Dock 的“建筑”关闭 Workspace，并清空 Main Dock 分类选中；
- Workspace 自己的关闭按钮和 Esc 也回到相同的未选中状态。

进入具体 Building Placement Tool 后，Control Tray / Main Dock 隐藏，Tool 获得更强的输入上下文。

## Settings 当前正式基准

正式规则：`Documentation/设置界面规范.md`

### 布局

- 全屏 Settings Space；
- 顶部分类：`显示 / 图形 / 音频 / 操作 / 游戏`；
- 中间单列 ScrollView；
- 不使用双栏设置 Card；
- 普通 Section 不使用金色左边线；
- Footer 只保留 `恢复当前分类默认值`。

### 控件

Slider：

- 可点轨道、连续拖动；
- 支持方向键 / Shift / Home / End；
- 实时数值；
- 不用滚轮改值。

Select：

- 自定义深墨 Dropdown；
- 支持外部关闭、Esc、上下键、Enter；
- 不使用浏览器原生 Select 外观。

Toggle：

- 真正可点击；
- Off 中性灰；
- On 暖金；
- 有 Hover / Pressed / Focus / Disabled。

Binding：

- `操作 + 主要按键 + 次要按键 + 恢复`；
- 支持监听、Esc 取消、Delete 清除、冲突提示；
- 最终 Unity 使用 Input System Rebinding。

### Settings 保存策略

**普通设置：即时生效 + 即时保存。**

因此普通 Settings 状态下：

```text
Esc / 返回
→ 直接退出
```

不再存在未保存 Draft，也没有常驻 `取消 / 应用`。

**可回滚显示设置：临时应用 + Safe Confirmation。**

当前包括：

- 显示模式；
- 显示器；
- 分辨率；
- 刷新率；
- HDR；
- UI Scale。

流程：

```text
Change
→ Temporary Apply
→ 15 秒 Safe Confirmation
→ Keep / Rollback
```

- `保留设置`：提交；
- `恢复原设置`：恢复；
- Esc：恢复；
- 超时：恢复。

### UI Scale

UI Scale 是 Select，不是 Slider：

`80% / 90% / 100% / 110% / 125% / 150%`

Safe Confirmation Layer 必须独立于正在测试的 UI Scale，最终 Unity 应使用固定 Safe System Overlay。

### Esc 优先级

子层如果已经处理并 `preventDefault` Esc，父级 PauseLayer 不得继续消费。

已专门修正 Pause → Settings 的这一问题。

## BuildingPlacement 当前基准

- 一个主 ToolOverlay；
- Terrain Summary 是轻量状态带；
- Position / Massing / Roof 用局部 Tone 区分；
- 中央 Tool Dock：`平 / 填 / 高 │ 位 / 层 / 顶 / 面 │ 完成 / 取消`；
- Tool Dock 是当前建筑放置任务的主控，当前约 `66px` 高；模式按钮约 `48 × 48px`，“完成”按钮宽约 `90px+`，视觉权重高于右下 World Utility；
- 地形模式 / 调整对象是 Exclusive Selector，Web 原型通过 `aria-pressed` 暴露 selected state，Unity 对应显式 class / state；
- 网格吸附 / 网格显示 / 撤销 / 重做已迁移到全局 World Utility Toolbar；
- OperationHints 在右下 World Utility Toolbar 上方；
- Tool 状态只保留 Top Shell 的 Persistent Status Row；
- Control Tray、Main Dock、Information Views 隐藏；
- World Utility Toolbar 保留；
- 进入 Tool 时关闭 Camera / Weather；
- 完成 / 取消 Building Placement 后返回 Building Workspace；
- Building Placement 所有视觉现在集中在 `src/tools/building-placement/building-placement.css`，不再依赖 Gameplay 级 Override CSS。

原 Unity 包仍是功能语义参考，不照搬旧视觉。

## Gameplay Esc 当前基准

Gameplay 局部 Surface 的 Escape 顺序已经集中到 `GameplayScreen`，不再让 Management / Flyout / Workspace 各自竞争同一层级的全局 `keydown`。

当前顺序：

1. Dialog / Safe Confirmation 由全局 DialogSystem capture-phase 优先处理；
2. Camera / Weather Flyout；
3. Information View Palette；
4. Tool；
5. Workspace；
6. Management；
7. 非默认 Map View；
8. 无局部 Surface 时进入 Pause Menu。

Workspace Search 等更局部的输入控件允许先消费自己的第一次 Esc。

Pause 内部继续：Pause Save / Settings → Pause Menu → 恢复游戏。

2. 设计统一的 Blueprint Workspace，并让 `全部 / 民居 / 商业 / 工坊 / 管理 / 科学 / 信仰 / 军事 / 宫殿` 只作为同一内容域的筛选分类；
3. 开始把五个一级管理域内部的信息架构做实，优先解决“城市 / 经济 / 宫殿”如何吸收旧户籍、商贸、治理内容；
4. 继续删除已经退出运行路径的旧 CityManagementRail / QuickControls / command-utility 兼容代码，保持一个组件一个样式所有者；
5. 为 Camera / Weather / Workspace / Management 补 Gamepad Focus 进入与关闭后的焦点恢复规则。

## 不要回退

不要重新加入：

- 左侧独立 City Management Rail；
- 右上独立 Quick Controls 浮块；
- Top Control Tray 常驻文字标签；
- Management Surface 内重复一级管理 Tab；
- 把财政 / 政策 / 军务等复杂系统塞回 Right Edge Flyout；
- Building Workspace 打开时隐藏整个 Top Control Tray；
- 打开 Building Workspace 时顺带关闭 Camera / Weather；
- 同一个 Surface Launcher 重复点击却无法关闭自己；
- Main Dock 默认强制选中某个分类；
- 分别记住设计 / 蓝图上一次分类并在切回时自动恢复 Selected；
- 在 Building Placement 内重新复制网格吸附 / 网格显示 / Undo / Redo；
- 把完成 / 取消 / 确认等任务流程按钮塞入 World Utility Toolbar；
- 常驻说明小字；
- 01 / 02 / 03 / 04 装饰编号；
- 无意义右箭头；
- 英文气氛眉题；
- 参数 / 内容层层 Card；
- 粗金边、卷轴、木纹、云纹等仿古装饰；
- `全部建筑` 特殊入口；
- Workspace 数字页码；
- 无限长建筑滚动列表；
- Settings 双栏 Card；
- Settings 常驻 `取消 / 应用`；
- UI Scale Slider；
