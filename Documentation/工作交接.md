接手先读取远端最新 main，再读取当前规范和源码，不使用聊天中的旧 SHA 覆盖正在推进的代码。

正式定位已调整：wanhu-ui-prototype 不是“浏览器增强版 UI”。Web 是最终 Unity 6000.6.2f1 UI 的布局、美术与交互参考，正式截图应尽量能由 Unity 6.6 等价复现。Web 与 Unity 可以使用不同技术实现，但不长期保留 Unity 无法复现的正式 Web-only 美术层。


## 当前工作：W0——Visual Parity 工作流重构

当前先暂停继续扩大 UI 美术改造范围，先把修改拆成可独立施工、可独立审查、可串行集成的模块。

W0 规则：

- Visual Parity / 全局视觉修改使用模块分支 + Draft PR，不再让多个执行者同时直推 main；
- 一个 Feature PR 只能属于一个模块，建议 2–5 个 Runtime 文件，最多 1 个专项 Review 脚本，Runtime 硬上限 6 个；
- `scripts/ui-review-modules.mjs` 是模块与 Review Group 映射权威；
- `scripts/check-pr-scope.mjs` 读取 PR changed files，阻止跨模块 PR、未分类 Runtime 文件、Feature + Toolchain 混合；
- `test-tool-usability.mjs` 只检查长期结构/功能不变量，不再通过固定文件 SHA 表达“本轮不允许修改”的临时范围；
- PR 只跑对应 Targeted Review；main 才运行 Core / HUD / Dialog / Readability / Tools / Selection 六组全量回归，并通过最终 Gate 汇总；
- 模块可以并行施工，但只允许串行合入 main：前一个 PR 合入后 main 全量回归通过，才合下一个。

当前已有的 Map View / City Wall / Menu-Loading Draft PR 用作工作流验证样本；W0 稳定后重新按模块边界整理，跨模块 PR 不直接合并。

工具链复现性 W0.2 已收口：依赖版本由 GitHub Actions 的 Node 22 环境先按原 `npm install` 真实解析，再固定到 `package.json` 并提交 lockfile v3；Build 与 UI Review 的应用依赖安装统一改为 `npm ci`，`package-lock.json` 也纳入 UI Review 触发路径。后续依赖升级必须作为独立 Toolchain PR 更新 manifest + lockfile，不与 Feature / Visual Parity 模块混合。

先读 `项目概览.md`、`UI Toolkit视觉总规范.md`、`Wanhu 烟墨熟铜视觉材质规范.md` 和 `UI设计原则.md`；再读 `UI Toolkit落地规范.md`、`Unity 6.6视觉能力与回退规范.md`、Typography / Icon / Motion / 空间规范，以及当前任务的组件代码。

## 必须保留的用户决策

材质方案与建筑配色方案保持现有文字/颜色参数列表，缺少缩略图不是欠缺。库存和管理页暂缓优化，包括资源图标；不要顺手重做。

正式身份是低饱和烟墨表面、暖纸浅字与少量有语义的熟铜。轻 HUD 可保留自身略冷的配方，工作面板保证稳定阅读，Dialog / Pause Panel 不恢复颗粒。不能使用单张旧色卡或聊天中未经测量的面积比例做全局换肤。

目标为 Unity 6.6 + URP + UI Toolkit；Web 仍是构图与交互原型。原生效果需实际 Player 验证，自研共享 Blur 是必要时回退，不用旧版本能力限制新设计，也不凭支持某能力宣称已实测。

## 已完成的共享空间与控件

Main Dock 为 880×84，设计/蓝图使用上下双行 Mode Rail，每行约 68×30、18px 图标在左、11px 字在右；Category 为 24px 图标在上、11px 字在下，设计八类、蓝图九类。Mode 不画状态线，Category 顶部短线保留。

Secondary Action Bar 使用唯一共享 Primitive：总高 84、按钮 76×64、24px 图标与下方 11px 标签。Terrain / Color / Selection / Placement 不再各造一套中下栏。右下 Utility 保持纯图标。

普通 World / Catalog 的 Main Dock 和双行 Utility 同高 84、bottom=16；Workspace 与 Operation Hints 使用 112px Bottom HUD Safe Offset。真实 Placement 中下主栏仅保留模式与流程动作，右下按对象 Action / Toggle-History-Danger 两行组织；第二行可见图标数多于第一行，宽度随内容收缩且第二行右对齐。Terrain / Color / Selection 不机械套用该数量约束。

Top Control Tray 固定 400×38，2 / 5 / 1 三组处于单行；Geometry 唯一 Owner 为 `src/gameplay/gameplay-top-shell.css`。迁移 Tooltip 时不能再误删按钮 Reset 或 Grid。Surface 与状态材质由 `wanhu-surface-system.css` 持有。

Numeric Parameter 外层 Label + Field，内部 Stepper / Slider / ValueButton 由 `ui-control-system.css` 持有 Standard / Compact 密度。数字仍由按钮进入共享 Dialog；Toggle 只有普通 Track + Thumb；滚动区域统一消费 `ui-scroll-region`，Feature 不私有重画 Scrollbar。

## Catalog、收藏与 Hover

Design / MaterialPreset / BuildingScheme / Blueprint 共享 Catalog 外壳。Design 为 4×2 紧凑 Action 条目；方案为文字/颜色参数 Compact 条目；Blueprint 为 4×1、4:3 Media Card。

MaterialPreset / BuildingScheme / Blueprint 的全部来源都有常驻 `···`，默认提供收藏/取消收藏；编辑删除按资源能力限制。Media 来源在左上、菜单在右上；Compact 来源跟随信息行、菜单右侧居中；收藏星在名称后，左 Rail 有收藏快捷入口。不要从旧记录恢复“仅我的蓝图显示菜单”。BuildingScheme 不虚构编辑/删除能力。

Rail Selected 为熟铜竖线；Rail 当前页为 Paper White 3×14 竖线，Content 当前页为 14×3 横线；其他页为灰点，单页保留 Marker。目录不恢复已删除搜索或常驻详情栏。

`src/ui/hover/` 已统一 Tooltip 与 Rich Hover。Catalog 详情在当前条目上方并水平居中，约 12px Gap，Safe Edge / Clamp；不跟鼠标漂移。默认 Tooltip 320ms、Card 460ms、关闭 90ms；Focus、热切换、Esc 与 Modal 清理由框架负责。普通 UI < Hover < Notification < Modal；Hover 忽略 Pointer，不塞按钮。

`workspace-edge` 只保留为未来特殊布局能力，当前 Catalog 不自行启用。旧 AssetInspector Runtime 已退役，不从旧文件名推断它仍是当前详情入口。

## Selection 与 Blueprint 边界

Building Selection 是 Gameplay Selection，不是新 Tool；UI State 仅 kind + entityId。中下为移动/配色 Toggle/关闭，配色打开 Selection 内 BuildingSchemeWorkspace；移动复用 Building Placement new / move。右下聚焦/Undo/Redo/移除，移除必须共享 Danger Confirm。正式实体生命周期交给游戏 Command，不由 UI 直接销毁。

Blueprint 已完成新建 → 摄影 → Editor → 我的蓝图，以及用户蓝图编辑、删除、重拍流程。摄影复用标准 Tool 空间；Web 只验证 4:3 Frame / Safe Distance，不实现世界拖动、滚轮缩放或真实 Camera。Preview 不拥有对象内容，删除定义不影响已放置对象。真实 Blueprint Placement 尚未接入，不扩大本轮范围。

Editor 与普通 Dialog 已统一 Modal 材质：高不透明近黑 Backdrop，烟墨 Panel，无颗粒、无额外 Blur。Feature 只持有大小、内容和业务，不重新定义背景/Shadow。

## 状态、资源与交付

空间优先级、ToolOrigin 和 Esc 消费由现有 UI State / Controller 负责。Operation Hints 除 Pause 外保持单一持久 Host，按 Context 重绑；Feature 不通过自己的 tool/selection 条件删除 Host。Motion 退出开始就停止输入，业务不等待动画，隐藏时重绑，Width / Height 不插值。

SVG 是图标 Source Master，64×64 PNG 是 Runtime，字体仍有离线打包与 Unity Font Asset / fallback 待验证。旧根样式和若干局部字号/前景仍有技术债，不能宣称所有属性已完全收敛。

Visual Parity / 全局视觉修改默认走模块 Draft PR；Feature PR 定向审查，main 串行集成后跑全量回归。不强制 Vercel。局部组件 Review 可以辅助迭代，但重要视觉变化仍需实际打开完整关键图；用户交付直接展示关键截图。纯文档改动不为了绿色状态重复跑视觉矩阵。构建、下载、审图、Unity Player 验证分别报告，不互相替代。
