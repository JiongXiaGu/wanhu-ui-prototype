# 工作交接

这是新对话、新 AI 或新开发者接手《万户天工》UI Prototype 时的首要入口。

## 项目定位

本仓库是《万户天工》的 **UI 美术、构图、信息架构与交互验证原型**。

最终运行时 UI 仍由 **Unity UI Toolkit** 实现：

- UXML：稳定结构；
- USS：布局、视觉状态、Transition；
- C#：状态、事件、数据绑定、输入；
- Sprite / Texture / RenderTexture：视觉资产；
- Painter2D / Mesh：必要自定义绘制；
- URP：场景级视觉能力。

网页不是最终 Web 产品，不要为了浏览器实现方便而设计 Unity 难以维护的核心结构。

正式落地约束：`Documentation/UI Toolkit落地规范.md`

Surface / Control 视觉规则：`Documentation/UI Surface与Control视觉规范.md`

迁移审查：`Documentation/代码审查/2026-09-15-UI Toolkit迁移可行性审查.md`

最新视觉系统审查：`Documentation/代码审查/2026-09-16-Surface与Control视觉系统审查.md`

## 项目入口

- GitHub：`JiongXiaGu/wanhu-ui-prototype`
- Vercel：`https://wanhu-ui-prototype.vercel.app/`
- 技术栈：Vite + React + TypeScript + Playwright + GitHub Actions + Vercel
- 设计基准：1920×1080

Blur 的正式方向是 **共享 URP Blur Service / Fullscreen Pass**。Web 的 `backdrop-filter` 只验证视觉。Unity 中不要给每个 VisualElement 建独立 Blur 或 RenderTexture 链；Gameplay 玻璃面板和 Pause / Settings / Archive / Management 等重空间都应按使用场景共享统一的场景弱化能力。

## 当前视觉原则

- 信息做减法，层级做加法；
- 世界画面优先；
- 黛墨 / 玉青半透明 Surface；
- Gameplay Surface 使用 `Ambient / Context / Work / Blocking` 四档固定透明度层级；
- Surface 自己承担基础明度与色调，Blur 只补环境感；
- 昼夜使用同一套 Surface Tier，不创建独立 Night Theme；
- 夜景下不能让 UI 跟世界一起黑下去；
- 浅纸主文字；
- 暖金只用于 Selected / Focus / On / Primary；
- 常用圆角语法：`8 / 10 / 14 / 18px`；
- 解释性小字优先进入 Tooltip / Inspector；
- 如果界面单调，优先补真实内容、Tone、状态反馈与动效，不堆装饰。

共享视觉代码：

- `src/ui/ui-visual-system.css`：通用 Glass Surface / Segmented / Full-screen Action；
- `src/gameplay/gameplay-hud-layout.css`：Gameplay Geometry + Surface / Blur Token；
- `src/gameplay/bottom-command-system.css`：Bottom Command L / M / S 外壳。

## Gameplay 当前空间基准

正式规则：`Documentation/UI空间与状态架构.md`

最新交互审查：`Documentation/代码审查/2026-09-16-Gameplay UI交互逻辑审查.md`

Gameplay 主空间优先级：

`Pause > Tool > Workspace > Management > Gameplay`

屏幕稳定槽位：

- 左上：Compass HUD；
- 顶部中央：Top Shell；
- 右上：System Menu + 未来 Notifications / Objectives；
- 左下：Context Surface / Tool Parameter Panel；
- 中下：Main Dock / Workspace / Placement Action Bar；
- 右下：Operation Hints + World Utility Toolbar。

外围 HUD 默认使用 `16px` Safe Edge，同级 Surface 常用 `12px` 间距。

### Gameplay Top Shell

第一层 **Persistent Status Row**：

- 左：天气状态 + 季节 / 时间；
- 中：钱粮 / 人口 / 木材 / 石料，资源几何中心必须对齐屏幕中心；
- 右：纯图标模拟时间控制：暂停 / 正常 / 加速 / 高速。

天气状态只显示当前天气，不作为控制入口。`speed` 支持 `0 / 1 / 2 / 4`，其中 `0` 是模拟暂停，不等于 Pause Menu。

第二层紧凑 **Control Tray** 当前约 `400 × 38px`：

`Camera / Weather │ 城市 / 经济 / 政策 / 军事 / 宫殿 │ Information Views`

语义是：左侧场景观察，中间城市管理，右侧数据观察。Menu 已从 Top Shell 移除。

Top Shell 两层轻微重叠约 2px，第二层不单独绘制顶部亮边，避免浏览器缩放 / DPR 下出现白色接缝。

Control Tray 在 Normal Gameplay、Workspace、Management 中保留；Tool 中隐藏，只保留 Persistent Status Row。

### 左上 Compass HUD

左上不保留常驻小地图，只保留低存在感指南针。

当前基线：

- 约 `76 × 76px`；
- 16px 左 / 上 Safe Edge；
- 中文 `东 / 南 / 西 / 北`；
- `北` 暖金强调，`南` 次级强调；
- 只使用方向环、刻度、南北轴和指针，不做真实风水罗盘 / 八卦纹样；
- Building / Road 等 Tool 中可加强方向识别，但不改变尺寸和位置；
- `pointer-events:none`。

正式 Unity 应绑定真实 Camera Heading。

Normal Gameplay / Workspace / Tool 中保留；Management / Pause 中隐藏。

### 右上 System / Notification Zone

Pause Menu 使用独立低存在感 System Menu Button：

- 约 `46 × 46px`；
- 16px 右 / 上 Safe Edge；
- 半透明深墨 Surface；
- 默认较弱，Hover 才明显提亮。

右上其它空间留给未来 Notification / Pending Event / Objective，不再给 Camera / Weather 占用。

### Context Surface

Camera / Weather 使用左下共享 Context Surface：

- 左 / 下 16px；
- Camera 宽约 360px；
- Weather 宽约 400px；
- 高度内容驱动，最大 `720px`（1080p 约 2/3）；
- 超高只滚动 Body；
- 使用 `Context` Surface Tier，让世界画面比 Tool 参数面板更明显地透入；
- 不做纯黑不透明面板。

交互：

- Camera / Weather 彼此互斥；
- 再次点击当前入口关闭；
- 打开 Camera / Weather 关闭 Design Workspace 并清 Main Dock 分类；
- 打开 Design Workspace 关闭 Camera / Weather；
- Tool / Management / Pause 中关闭 Context Surface；
- Esc 优先关闭 Context Surface。

未来 Selection Inspector 优先落在同一左下槽位，推荐“世界轻浮签 + 左下详细 Inspector”。Selection Inspector 与 Workspace 的共存方式等真实对象选择系统实现时再验证。

### Gameplay Launcher 统一规则

Surface Launcher 状态集中到 `GameplayUiState` / reducer：

- 城市 / 经济 / 政策 / 军事 / 宫殿；
- Camera / Weather；
- Main Dock 设计模式八个分类；
- Information Views Palette。

规则：

- 同入口再次点击 → 关闭自己的 Surface；
- 同组其它入口 → 切换目标 Surface；
- 关闭按钮 / Esc / 再次点击入口最终修改同一份状态。

不要错误套到所有 Button：时间速度、Main Dock 设计 / 蓝图、Placement Mode、Settings Tab 属于 Exclusive Selector；Grid Snap / Grid Visible 属于 Toggle；Asset Card、Undo / Redo、Quick Action、完成 / 取消属于 One-shot Action。

## Bottom Command Visual System

正式规则：`Documentation/Bottom Command Visual System设计规范.md`

Gameplay 底部三个 Toolbar 属于同一视觉家族：

- Main Dock = **L**：76px；
- Placement Action Bar = **M**：68px，46×46 Control；
- World Utility = **S**：56px，42×42 Control。

共享 Tint / Border / 14px Radius / Hover / Active / Divider / Tooltip；L / M / S 可以使用不同固定透明度 Tier 与 Shadow Tier，但不得演变成三套材质。

当前映射：Main Dock = 较轻 Work；Placement = 稳定 Work；World Utility = Ambient。

底部横向 Command 的 Selected / On 状态线统一朝上。Main Dock 左侧 `设计 / 蓝图` 是竖向一级 Selector，保留左侧短金线。

### Main Dock

Main Dock = **模式选择器 + 当前模式分类带**。

左侧模式：`设计 / 蓝图`

设计：`道路 / 桥梁 / 建筑 / 台基 / 城墙 / 围墙 / 装饰 / 树木`

蓝图：`全部 / 民居 / 商业 / 工坊 / 管理 / 科学 / 信仰 / 军事 / 宫殿`

状态：

- `dockMode=design`；
- `dockCategory=null` 默认无分类 Selected；
- 切换设计 / 蓝图清空分类；
- 不记忆两模式上一次分类；
- 只有玩家明确点击分类才 Selected；
- 设计八类全部进入同一个 Design Workspace；
- 再次点击当前分类、关闭或 Esc 都关闭 Workspace 并清分类；
- 已打开 Workspace 时点击另一设计分类，直接替换 Definition。

Blueprint Workspace 尚未实现。

### World Utility Toolbar

当前：

- 地图解锁；
- 区域编辑；
- 地形编辑；
- 配色工具；
- 网格吸附；
- 网格显示；
- 范围复制；
- 范围移动；
- 撤销；
- 重做。

规则：

- Normal Gameplay / Workspace / Tool 中保留；
- Management / Pause 中隐藏；
- 只放跨分类 / 跨工具世界级能力；
- 不放完成 / 取消和建造分类；
- Grid 状态进入 Tool 不重置；
- Operation Hints 位于其上方约 12px。

## Design Workspace

正式规则：`Documentation/Design Workspace设计规范.md`

八个设计入口共享配置驱动 Workspace：

`Header + Primary Rail + Context Filter + Search + 4×2 Content Grid + Pager`

Primary Rail：

- 约 146px；
- 第一项统一显示 `所有`；
- 每组最多 7 项；
- 常规标签约最多 6 个汉字；
- 超出后 Rail 分页 / 滚轮切组。

Content：

- 8项 / 页；
- Workspace 约 1240×370；
- Card 约 255×100；
- Preview 64×64，1:1；
- 名称约 14.2px / 600，最多两行；
- 属性约 10.5px；
- Card 是 Action Button，不是 Toggle。

Workspace Surface 分层：

- Header：Context Tier，允许更多世界画面透入；
- Body：Work Tier，保证 Rail / Filter / Asset Grid 的阅读稳定性；
- 不对整个 Workspace 设置 `opacity`，文字与控件保持固定对比度。

Asset Inspector：

- Children 决定自然尺寸；
- 240–380 宽 / 90–320 高约束；
- 首次 Hover 约 280ms，相邻 Item 已打开时立即换内容；
- Keyboard / Gamepad Focus 立即显示；
- `pointer-events:none`；
- 更深墨青 Surface + 清晰细边 + 较强阴影。

## Placement Tool

正式规则：`Documentation/Placement Tool设计规范.md`

稳定空间职责：

- 左侧 Tool Parameter Panel：详细参数；
- 中下 Placement Action Bar：Mode / Quick Action / 完成取消；
- 右下 World Utility：全局辅助工具。

### Building Placement

Action Bar：

- Terrain Mode：平衡挖填 / 只填不挖 / 手动标高；
- Adjustment Mode：位置 / 楼身 / 屋顶 / 立面（立面当前 Disabled）；
- Quick Action：逆时针旋转 / 顺时针旋转 / 镜像；
- Commit：完成 / 取消。

左参数面板的 Segmented Control 使用共享 Visual System：外壳 10px、Option 8px、Hover 可见、Active 暖金 Tone，必须明显像可点击控件。

完成 / 取消后回 `设计 → 建筑` Workspace。

### Road Placement

Action Bar：

- 智能曲线 / 曲线 / 直线；
- Quick Action：反转道路方向；
- 完成 / 取消。

左参数面板负责道路宽度、相对标高、曲线平滑等。

完成 / 取消后回 `设计 → 道路` Workspace。

后续 Bridge / City Wall / Platform 等优先复用同一 M 档 Placement Action Bar，不重新设计 Toolbar 外壳。

## Shared Surface / Control Visual System

正式规则：`Documentation/UI Surface与Control视觉规范.md`

### Gameplay Glass Surface

固定四档：

- Ambient：约 `.66–.74`，常驻低干扰辅助 HUD；
- Context：约 `.76–.82`，Camera / Weather、Control Tray、Workspace Header；
- Work：约 `.82–.88`，Top Status、Main Dock、Workspace Body、Tool Parameter、Placement；
- Blocking：约 `.92–.94`，Management / Pause / Settings / Archive 等重空间。

规则：

- 只调 Surface Tint / Alpha，不调整个组件 `opacity`；
- Text / Icon / Border 保持固定对比；
- Blur 是环境点缀，不是可读性前提；
- 昼夜使用同一套 Tier，不根据夜景动态追加一套 Alpha。

### Segmented Control

用于 2–5 项局部互斥 Mode，例如：

- 放置方式；
- Camera 经营 / 规划 / 摄影；
- Weather 跟随世界 / 场景模拟；
- New Game 游戏模式。

当前视觉：10px 外壳、8px Option、可辨认的 Surface / Border、明确 Hover、暖金 Active。

### Full-screen Footer Actions

Settings / New Game / Load / Save 共用：

- `global-space-footer`；
- `global-space-primary`；
- `global-space-secondary`；
- Utility Action。

Primary / Secondary Action 使用 10px Radius，Utility 通常 8px；Footer 使用轻透明玉青 Surface + Blur。不要再在单页恢复旧 `1px / 2px` Button Radius。

## Management / Information Views

复杂财政、政策、军务等进入中央 Management Space：

- 世界压暗 / 轻模糊后可见；
- Top Shell 两层保留；
- 顶部五管理域直接切换；
- Management 内不重复一级 Tab；
- Compass / Main Dock / World Utility / Context / Operation Hints 隐藏；
- 再次点击当前入口、关闭或 Esc 回 Normal Gameplay。

Information Views 属于观察城市：

`默认 / 地价 / 人口 / 商业 / 道路 / 治安 / 水利`

入口在 Control Tray 最右，Palette 轻量展开；具体信息主要表现到世界地图。

## Gameplay Esc 当前基准

1. Dialog / Safe Confirmation；
2. Camera / Weather Context Surface；
3. Information View Palette；
4. Tool；
5. Workspace；
6. Management；
7. 非默认 Map View；
8. 无局部 Surface 时进入 Pause Menu。

Workspace Search 等更局部输入控件可先消费自己的第一次 Esc。

Pause 内：Pause Save / Settings → Pause Menu → 恢复游戏。

## Settings 当前正式基准

正式规则：`Documentation/设置界面规范.md`

布局：

- 全屏 Settings；
- 顶部分类 `显示 / 图形 / 音频 / 操作 / 游戏`；
- 中间单列 ScrollView；
- Footer：恢复当前分类默认值 + 返回；
- 不使用双栏 Settings Card。

保存策略：

- 普通设置：即时生效 + 即时保存；
- 显示模式 / 显示器 / 分辨率 / 刷新率 / HDR / UI Scale：Temporary Apply + 15秒 Safe Confirmation；
- UI Scale 是 Select：`80 / 90 / 100 / 110 / 125 / 150%`。

Binding：

- 操作 + 主要按键 + 次要按键 + 恢复；
- Listening、Esc 取消、Delete 清除、冲突提示；
- 最终 Unity 使用 New Input System Rebinding。
