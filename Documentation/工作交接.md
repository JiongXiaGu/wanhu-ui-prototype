# 工作交接

这是新对话、新 AI 或新开发者接手《万户天工》UI Prototype 时的首要入口。

## 项目定位

本仓库是《万户天工》的 **UI 美术、构图、信息架构与交互验证原型**。

最终运行时 UI 仍然由 **Unity UI Toolkit** 实现：

- UXML：稳定结构；
- USS：布局、视觉状态、Transition；
- C#：状态、事件、数据绑定、输入；
- Sprite / Texture / RenderTexture：视觉资产；
- Painter2D / Mesh：必要自定义绘制；
- URP：场景级视觉能力。

网页不是最终 Web 产品，不要为了浏览器实现方便而设计 Unity 难以维护的核心结构。

正式落地约束：`Documentation/UI Toolkit落地规范.md`

迁移审查：`Documentation/代码审查/2026-09-15-UI Toolkit迁移可行性审查.md`

## 项目入口

- GitHub：`JiongXiaGu/wanhu-ui-prototype`

- 设计基准：1920×1080
- 当前计划使用 URP 全屏 Blur Pass 处理 Pause / Settings / Archive / Management 等场景级背景弱化。

## 当前视觉原则

- 信息做减法，层级做加法；
- 世界画面优先；
- 黛墨 / 深青灰 Surface；
- 浅纸主文字；
- 暖金只用于 Selected / Focus / On / Primary；
- 低圆角、弱边界；
- 解释性小字默认进入 Tooltip；
- 如果界面单调，优先补真实内容、Tone、状态反馈与动效，不堆装饰。

## Gameplay 当前空间基准

正式规则：`Documentation/UI空间与状态架构.md`

Gameplay 内部空间优先级：

`Pause > Tool > Workspace > Management > Gameplay`

### Normal Gameplay

显示：

- Global HUD；
- Quick Controls；
- City Management Rail；
- Information Views；
- Utility Toolbar；
- Main Dock；
- 轻量 OperationHints。

### Management Space

财政、户籍、政策、商贸、治理、军务等复杂系统不再使用 Right Edge Flyout，而是进入一个**中央大型阻挡式 Management Space**。

当前内部 Tab：

`概况 / 户籍 / 财政 / 政策 / 商贸 / 治理 / 军务`

规则：

- 世界停止直接交互；
- 背景城市仍可见，但压暗并轻微模糊；
- Global HUD 保留并弱化；
- 隐藏 City Management Rail、Quick Controls、Utility Toolbar、Main Dock、OperationHints、Right Edge Flyout；
- Esc / 关闭按钮回 Normal Gameplay；
- Finance 当前作为复杂页面样例，包含指标、收支趋势、收入构成、税赋设置和财政判断。

### Right Edge Flyout

只用于轻量场景上下文工具，目前为：

- Camera；
- Weather。

需要较宽统计、多级 Tab、趋势图或大量管理参数的功能应进入 Management / Workspace，不继续扩宽 Flyout。

### Information Views

属于“观察城市”，不是“管理城市”。

当前：

`默认 / 地价 / 人口 / 商业 / 道路 / 治安 / 水利`

使用左侧轻量 Palette，选择后主要变化发生在世界地图。

地图数据效果当前仍是原型热力渐变，后续应逐步贴合真实街区、建筑、道路和服务覆盖。

## Workspace Browser 当前基准

统一结构：

`Primary Rail + Context Filter + Content Grid`

### Primary Rail

- 一级分类，图标 + 简短文字；
- `全部建筑` 与其它分类完全同样样式；
- 每组显示 5 个分类；
- 左侧竖向刻度切换分类组；
- 鼠标在 Rail 上滚轮可整组切换；
- 切换可见组不自动选择分类。

### Context Filter

- 顶部纯文字；
- 与 Primary Rail 是正交筛选维度；
- 切换一级分类不能偷偷重置顶部筛选。

建筑当前示例：

`全部 / 庑殿 / 歇山 / 悬山 / 硬山 / 攒尖 / 卷棚 / 其他`

### Content Grid

- 建筑当前固定 `3 列 × 2 行 = 6 项 / 组`；
- Card 使用左侧矩形预览 + 右侧名称 / 一条属性；
- 文字是主识别信息；
- 主内容底部使用 `· · ━ · ·` 无页码分页；
- Content Grid 上滚轮整组翻页；
- 不使用无限长建筑列表。

进入 Building Workspace 后：

- City Management Rail 隐藏；
- Utility Toolbar 隐藏；
- Main Dock 保留；
- Workspace 占据底部 Dock 上方的浏览空间。

## Settings 当前正式基准

正式规则：`Documentation/设置界面规范.md`

### 布局

- 全屏 Settings Space；
- 顶部分类：`显示 / 图形 / 音频 / 操作 / 游戏`；
- 中间单列 ScrollView；
- 不使用双栏设置 Card；
- 普通 Section 不使用金色左边线；
- Footer 只保留 `恢复当前分类默认值`。

### 控件

Slider：

- 可点轨道、连续拖动；
- 支持方向键 / Shift / Home / End；
- 实时数值；
- 不用滚轮改值。

Select：

- 自定义深墨 Dropdown；
- 支持外部关闭、Esc、上下键、Enter；
- 不使用浏览器原生 Select 外观。

Toggle：

- 真正可点击；
- Off 中性灰；
- On 暖金；
- 有 Hover / Pressed / Focus / Disabled。

Binding：

- `操作 + 主要按键 + 次要按键 + 恢复`；
- 支持监听、Esc 取消、Delete 清除、冲突提示；
- 最终 Unity 使用 Input System Rebinding。

### Settings 保存策略

**普通设置：即时生效 + 即时保存。**

因此普通 Settings 状态下：

```text
Esc / 返回
→ 直接退出
```

不再存在未保存 Draft，也没有常驻 `取消 / 应用`。

**可回滚显示设置：临时应用 + Safe Confirmation。**

当前包括：

- 显示模式；
- 显示器；
- 分辨率；
- 刷新率；
- HDR；
- UI Scale。

流程：

```text
Change
→ Temporary Apply
→ 15 秒 Safe Confirmation
→ Keep / Rollback
```

- `保留设置`：提交；
- `恢复原设置`：恢复；
- Esc：恢复；
- 超时：恢复。

### UI Scale

UI Scale 是 Select，不是 Slider：

`80% / 90% / 100% / 110% / 125% / 150%`

Safe Confirmation Layer 必须独立于正在测试的 UI Scale，最终 Unity 应使用固定 Safe System Overlay。

### Esc 优先级

子层如果已经处理并 `preventDefault` Esc，父级 PauseLayer 不得继续消费。

已专门修正 Pause → Settings 的这一问题。

## BuildingPlacement 当前基准

- 一个主 ToolOverlay；
- Terrain Summary 是轻量状态带；
- Position / Massing / Roof 用局部 Tone 区分；
- Dock：`平 / 填 / 高 │ 位 / 层 / 顶 / 面 │ 完成 / 取消`；
- Utility：网格吸附 / 网格显示 / 撤销 / 重做；
- OperationHints 在右下；
- Tool 状态中 City Management Rail、Main Dock、Utility Toolbar、Information Views 均隐藏；
- Camera / Weather 仍是独立 Right Edge Flyout。

原 Unity 包仍是功能语义参考，不照搬旧视觉。

## 下一步建议

Gameplay 主空间职责已经重新厘清，后续优先：

1. 继续深化 Management Space 各系统的真实信息架构，不要让所有页面只是同一模板换文字；
2. 将 Information Views 从原型渐变推进到更贴合街区 / 建筑 / 道路的可分析数据表现；
3. 继续验证 Management Space 与未来城市详情、选中对象详情之间的边界；
4. Archive / New Game 等尚未完全定型页面继续按现有视觉原则迭代；
5. 最后做 Visual Token / CSS Cleanup，减少后加载覆盖和职责重叠。

- `全部建筑` 特殊入口；
- Workspace 数字页码；
- 无限长建筑滚动列表；
- Settings 双栏 Card；
