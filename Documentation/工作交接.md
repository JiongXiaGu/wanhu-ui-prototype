# 工作交接

这是《万户天工》UI Prototype 的当前接手入口。先读取远端最新 main，再读取相关规范和实现，不使用聊天中的旧 SHA 覆盖代码。

## 本轮已经调整的基线

项目方已确认 Unity 升级到 **6.6**，目标为 URP + UI Toolkit。Web 仍是美术、构图、信息架构和交互原型，不是最终游戏客户端。

本轮保持布局和功能流程，升级了：

- Theme / Typography：Metadata 与紧凑标签 11px，普通操作与工具正文 12px，持续阅读 13px，分组 14px，面板 / Workspace 标题 16 / 18px。
- 阅读色：提高正文与辅助信息清晰度；小字号熟铜文字与熟铜填色分开。
- Surface：稳定 Context、Workspace 和全屏阅读背景，改为更中性的 Graphite；没有扩大面板，也没有提高模糊半径。
- Controls：中性 Hover、独立 Focus、固定命中区，Slider 拖动不再动画滑块尺寸；Select 菜单依靠自身 Tint，不叠加私有 Blur。
- Inventory / Management：提高比较数据与正文可读性；库存内部样式不再被 Management Skin 再次覆盖。
- Archive：在原组件文件中合并基础皮肤与后续覆盖，提高筛选、名称和日期的阅读层级，保留现有列表结构。
- Review：在真实页面增加字号、截断、Selected + Focus、Toggle、昼夜和 4K 逻辑画布检查。

这些是 Web 改动；尚未表示 Unity Font Asset、原生滤镜或 Player 性能完成验收。

## 不变的视觉与结构

正式身份仍为 **Smoked Graphite + Paper White + Aged Brass**，不是墨绿玻璃、仿古纹样或 SaaS Dashboard。世界承担主要色彩，面板保证稳定阅读；熟铜表达 Selected / On / Focus / Primary，不用于所有默认按钮。

Ambient / Context / Work / Blocking / Elevated 共用同一色相。Context 更轻不代表更透明；Header / Body 通过密度与明暗建立层级。Dialog / Pause Panel 不恢复颗粒磨砂，不因 6.6 支持而自动增加多层 Blur。

布局仍为 1920×1080 固定逻辑画布，外围 HUD 默认 16px Safe Edge，同级间隔约 12px。Camera 约 360px、Environment 约 400px，超高只滚动 Body。标题继续 Bare Icon + Title，不恢复图标底板和装饰梁线。

## 不变的状态与业务边界

空间优先级保持 `Pause > Tool > Workspace > Management > Gameplay`。左上 Compass、顶部状态与入口、右上系统区、左下 Context / Tool Parameter、中下 Workspace / Action Bar、右下唯一 Utility Host 不移动。

Top Metric Shortcut 只负责摘要与快捷打开，不建立第二套 Selected；Management 当前域由 Control Tray 表达。进入 Tool 后隐藏竞争的 Dock / Workspace / Control Tray，保留必要状态；Esc、关闭与 ToolOrigin 返回继续由现有 UI State 管理。

Main Dock / Placement Action Bar / Context Utility 保持 L / M / S 共用家族。Utility 先退出、在隐藏状态重绑，再进入；Width 不动画。

RuntimeParameterRow 外层只有 Label + Field。NumericSliderField 自己持有减号、Slider、加号、ValueButton。所有数字输入仍从按钮进入共享 Dialog，不恢复旧五列 ParameterRow 或常驻输入框。

配色工具仍是唯一 World Utility Color Tool Space，包含 Surface / Lighting / Scheme。Surface 默认 Metallic；Specular 项不可用时隐藏、可用时放在最后。颜色入口、HDR 编辑、复制粘贴、预设和建筑方案的状态边界不变；Workspace 分类与来源筛选独立，不恢复已删除的搜索和装饰文案。

地形、树木、道路、城墙主体、Gate、登城梯、高差楼梯继续复用 Shared Surface / Controls，但拥有独立业务 Controller。世界预览、真实地形修改、路径生成、碰撞与 Undo 不属于 UI Toolkit。

## 开发与验收

直接提交 main，不依赖 Vercel。局部组件可以快速截图，但重要修改仍需 Build + UI Review、下载 Artifact 和实际完整页面审图。

Build 执行 icons:check、audit:scale、audit:unity 和 build。UI Review 的基础矩阵由 capture-ui-review.mjs 提供；capture-typography-decision-review.mjs 扩展阅读、状态、昼夜与 4K，输出 readability-report.json。自动通过不代替人工审图，Web 通过不代替 Unity 运行时性能和字体测试。

接手后按改动范围检查完整页面；不是每次小改都扩张所有截图。全局 Token 或 Control 改动不能仅看一个目标页。
