# 工作交接

这是《万户天工》UI Prototype 的当前接手入口。先读取远端最新 main，再读取相关规范和实现，不使用聊天中的旧 SHA 覆盖代码。

## 当前阶段：工具辨识与局部布局

本轮在既有烟墨熟铜与可读性基线上调整工具辨识、详情避让、Settings 对齐和少量 HUD 比例，不重新换肤。正式规则见 `Documentation/工具辨识与局部布局.md`。

必须保留的用户决策：**材质方案和建筑配色方案继续使用现有文字列表，是有意设计，不增加缩略图、不改为视觉目录、不登记为欠缺。库存和管理页暂缓优化，包括资源图标。**

本轮主要变化：

- ToolActionBar 增加可选 icon-label 变体；地形五种模式、树木两种模式、配色三种模式显示短名称，其他调用点默认保持纯图标。
- 五个地形专用符号纳入同一 SVG Source → 64×64 PNG → UiIconId 管线；总量 109，包括原有 104 个通用来源与 5 个自定义来源。
- 即时编辑工具的“完成”以中性退出符号表达结束工具；配色原 Complete / Cancel 都只是 onClose，合并成一个真实的结束入口，不增加回退或提交机制。
- Asset Inspector 优先出现在整个 Workspace 上方，经过逻辑坐标转换与保护区域评分后定位；不跟随同一条目内的鼠标移动，关闭和目标卸载后不残留。
- Settings 普通表单列集中排列，Select / Slider / Toggle 共用字段起点；键位表保留独立结构和字段尺寸。
- 顶部资源快捷入口使用共享 18px 图标与颜色；右下辅助工具保留单一 Host，加强组间留白和焦点提示。

这些都是 Web 改动，不表示 Unity Player 原生效果、字体或性能已实测。新建游戏预览、建筑缩略图和帮助系统未纳入本轮。

## 已有视觉基线

项目方已确认 Unity 升级到 **6.6**，目标为 URP + UI Toolkit。Web 仍是美术、构图、信息架构和交互原型，不是最终游戏客户端。

上一轮保留布局与流程，完成了：

- Theme / Typography：Metadata 与紧凑标签 11px，普通操作与工具正文 12px，持续阅读 13px，分组 14px，面板 / Workspace 标题 16 / 18px。
- 阅读色：提高正文与辅助信息清晰度；小字号熟铜文字与熟铜填色分开。
- Surface：稳定 Context、Workspace 和全屏阅读背景，改为更中性的 Graphite；没有扩大面板，也没有提高模糊半径。
- Controls：中性 Hover、独立 Focus、固定命中区，Slider 拖动不再动画滑块尺寸；Select 菜单依靠自身 Tint，不叠加私有 Blur。
- Inventory / Management：既有阅读层级保持，本轮不再继续优化。
- Archive：已在原组件文件中合并基础皮肤与后续覆盖，保留现有列表结构。

## 不变的视觉与结构

正式身份仍为 **Smoked Graphite + Paper White + Aged Brass**，不是墨绿玻璃、仿古纹样或 SaaS Dashboard。世界承担主要色彩，面板保证稳定阅读；熟铜表达 Selected / On / Focus / Primary，不用于所有默认按钮。

Ambient / Context / Work / Blocking / Elevated 共用同一色相。Context 更轻不代表更透明；Header / Body 通过密度与明暗建立层级。Dialog / Pause Panel 不恢复颗粒磨砂，不因 6.6 支持而自动增加多层 Blur。

布局仍为 1920×1080 固定逻辑画布，外围 HUD 默认 16px Safe Edge，同级间隔约 12px。Camera 约 360px、Environment 约 400px，超高只滚动 Body。标题继续 Bare Icon + Title，不恢复图标底板和装饰梁线。

## 不变的状态与业务边界

空间优先级保持 `Pause > Tool > Workspace > Management > Gameplay`。左上 Compass、顶部状态与入口、右上系统区、左下 Context / Tool Parameter、中下 Workspace / Action Bar、右下唯一 Utility Host 不移动。

Top Metric Shortcut 只负责摘要与快捷打开，不建立第二套 Selected；Management 当前域由 Control Tray 表达。进入 Tool 后隐藏竞争的 Dock / Workspace / Control Tray，保留必要状态；Esc、关闭与 ToolOrigin 返回继续由现有 UI State 管理。

Main Dock / Placement Action Bar / Context Utility 保持 L / M / S 共用家族。Utility 先退出、在隐藏状态重绑，再进入；Width 不动画。

RuntimeParameterRow 外层只有 Label + Field。NumericSliderField 自己持有减号、Slider、加号、ValueButton。所有数字输入仍从按钮进入共享 Dialog，不恢复旧五列 ParameterRow 或常驻输入框。

配色工具仍是唯一 World Utility Color Tool Space，包含 Surface / Lighting / Scheme。Surface 默认 Metallic；Specular 项不可用时隐藏、可用时放在最后。颜色入口、HDR 编辑、复制粘贴、预设和建筑方案的状态边界不变；Workspace 分类与来源筛选独立，不恢复已删除的搜索和装饰文案。

地形、树木、道路、城墙主体、Gate、登城梯、高差楼梯继续复用 Shared Surface / Controls，但拥有独立业务 Controller。世界预览、真实地形修改、路径生成、碰撞与 Undo 不属于 UI Toolkit。

## 开发与验收

直接提交 main，不依赖 Vercel。局部组件可以快速截图，但重要修改仍需 Build + UI Review、下载 Artifact 和实际完整页面审图。

Build 执行 icons:check、audit:scale、audit:unity、test-tool-usability.mjs 和 build。新增单元检查包括纯几何、真实 PNG 解码和阶段范围保护；它不把所有业务模块永久冻结，后续用户明确批准新任务时应同步调整保护范围。

UI Review 的基础矩阵由 capture-ui-review.mjs 提供；capture-typography-decision-review.mjs 扩展阅读、状态、昼夜与 4K；capture-tool-usability-review.mjs 检查本轮工具、浮层、设置及 1440p / 4K。报告为 readability-report.json 与 tool-usability-report.json。

自动通过不代替人工审图，Web 通过不代替 Unity 运行时性能和字体测试。接手后按改动范围检查完整页面；不是每次小改都扩张所有截图。全局 Token 或 Control 改动不能仅看一个目标页。

## 历史说明

升级前的完整交接已原样保存在 `Documentation/历史/2026-09-20工作交接-Unity66升级前.md`，仅用于追溯过去决策。不要从历史快照恢复旧字号、旧版本能力限制或已经退役的组件。当前业务细节以相应正式领域文档与代码为准。


## 2026-09-22 Building Selection 收敛

Building Selection 底部对象操作只保留“移动 / 关闭”，不再提供“编辑建筑”。移动继续复用 Building Placement，正式状态为 `BuildingPlacementIntent = new | move`；Move 从 Selection 进入，退出后恢复原 entityId。旧 `building-edit` Runtime 组件已退役，历史开发记录仅保留演进背景，不代表当前契约。


## 2026-09-22 Building Selection 配色与移除

Building Selection 中下改为“移动 / 配色 / 关闭”。配色是 Selection 内 Toggle，直接复用 BuildingSchemeWorkspace；左侧 Inspector 同时显示配色方案和做旧程度。右下去掉配色快捷按钮，新增“移除建筑”，必须先经过共享 danger Dialog。Web Demo 的移除会隐藏对应建筑 Hit Area；正式 Unity 删除必须交给建筑 Command / 生命周期系统，不由 UI 直接 Destroy Entity。


## 2026-09-22 Shared Scrollbar / Parameter Density

Settings 的既有细滚动条已提升为共享 `ui-scroll-region`，LeftContextPanel Body 自动消费同一 Scrollbar；Feature 只持有 overflow / max-height。Numeric Slider 正式分 `standard / compact`：Settings、Building Selection / Appearance 使用 standard，Placement / Road 等高密度工具使用 compact。Slider Track / Thumb / Stepper / ValueButton 的内部尺寸继续只由 `ui-control-system.css` 持有。


## 2026-09-22 World Utility 双层布局

普通 Gameplay 的右下 World Utility 改为单一 Surface 内两行：第一行是地图解锁 / 区域 / 地形 / 配色四个世界入口；第二行是网格 / 范围复制移动 / Undo / Redo，并在最右新增“批量摧毁建筑”危险 Toggle。Workspace、Tool 与 Building Selection Utility 仍保持单行。批量摧毁 V1 只建立 UI Mode、Danger 状态、Operation Hints 与普通 Building Selection 互斥；真实范围框选和删除由后续 Unity World Controller / Command 负责。


## 2026-09-22 Bottom HUD Safe Line 校准

保留右下双层 World Utility，不再拆分功能。Main Dock 与双层 Utility 统一为 96px 高，并共同使用 `bottom=16px`，不再抬高中间菜单。Design Workspace 打开时右下仍保持双层；Workspace 和 Operation Hints 统一使用 `Bottom HUD Safe Offset = 16 + 96 + 12 = 124px`，从而与 Main Dock / Utility 同时共存。
