## Catalog、收藏与 Hover

Design / MaterialPreset / BuildingScheme / Blueprint 共享 Catalog 外壳。Design 为 4×2 紧凑 Action 条目；方案为文字/颜色参数 Compact 条目；Blueprint 为 4×1、4:3 Media Card。

MaterialPreset / BuildingScheme / Blueprint 的全部来源都有常驻 `···`，默认提供收藏/取消收藏；编辑删除按资源能力限制。Media 来源在左上、菜单在右上；Compact 来源跟随信息行、菜单右侧居中；收藏星在名称后，左 Rail 有收藏快捷入口。不要从旧记录恢复“仅我的蓝图显示菜单”。BuildingScheme 不虚构编辑/删除能力。

Rail Selected 为熟铜竖线；Rail 当前页为 Paper White 3×14 竖线，Content 当前页为 14×3 横线；其他页为灰点，单页保留 Marker。目录不恢复已删除搜索或常驻详情栏。

`src/ui/hover/` 已统一 Tooltip 与 Rich Hover。Catalog 详情在当前条目上方并水平居中，约 12px Gap，Safe Edge / Clamp；不跟鼠标漂移。默认 Tooltip 320ms、Card 460ms、关闭 90ms；Focus、热切换、Esc 与 Modal 清理由框架负责。普通 UI < Hover < Notification < Modal；Hover 忽略 Pointer，不塞按钮。

`workspace-edge` 只保留为未来特殊布局能力，当前 Catalog 不自行启用。旧 AssetInspector Runtime 已退役，不从旧文件名推断它仍是当前详情入口。

## Selection 与 Blueprint 边界

Building Selection 是 Gameplay Selection，不是新 Tool；UI State 仅 kind + entityId。中下为移动/配色 Toggle/关闭，配色打开 Selection 内 BuildingSchemeWorkspace；移动复用 Building Placement new / move。右下聚焦/Undo/Redo/移除，移除必须共享 Danger Confirm。正式实体生命周期交给游戏 Command，不由 UI 直接销毁。

Blueprint 已完成新建 → 摄影 → Editor → 我的蓝图，以及用户蓝图编辑、删除、重拍流程。摄影复用标准 Tool 空间；Web 只验证 4:3 Frame / Safe Distance，不实现世界拖动、滚轮缩放或真实 Camera。Preview 不拥有对象内容，删除定义不影响已放置对象。真实 Blueprint Placement 尚未接入，不扩大本轮范围。

Editor 与普通 Dialog 已统一 Modal 材质：高不透明近黑 Backdrop，烟墨 Panel，无颗粒、无额外 Blur。Feature 只持有大小、内容和业务，不重新定义背景/Shadow。

## 状态、资源与交付

空间优先级、ToolOrigin 和 Esc 消费由现有 UI State / Controller 负责。Operation Hints 除 Pause 外保持单一持久 Host，按 Context 重绑；Feature 不通过自己的 tool/selection 条件删除 Host。Motion 退出开始就停止输入，业务不等待动画，隐藏时重绑，Width / Height 不插值。

SVG 是图标 Source Master，64×64 PNG 是 Runtime，字体仍有离线打包与 Unity Font Asset / fallback 待验证。旧根样式和若干局部字号/前景仍有技术债，不能宣称所有属性已完全收敛。
