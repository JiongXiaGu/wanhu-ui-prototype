# 工作交接

这是新对话、新 AI 或新开发者接手《万户天工》UI Prototype 时的首要入口。

## 项目定位

本仓库是《万户天工》的 **UI 美术、构图、信息架构与交互验证原型**。最终运行时 UI 仍由 Unity UI Toolkit 实现：

- UXML：稳定结构；
- USS：布局、视觉状态、Transition；
- C#：状态、事件、数据绑定、输入；
- Sprite / Texture / RenderTexture：视觉资产；
- Painter2D / Mesh：必要自定义绘制；
- URP：场景级视觉能力。

网页不是最终 Web 产品。代码是当前具体实现的权威来源；正式文档记录稳定的设计目标、职责边界、状态规则与迁移约束。

## 当前视觉基线

当前正式材质身份是 **Smoked Graphite / 烟墨石质 + Paper White / 暖纸 + Aged Brass / 熟铜**。

- Design Workspace 当前视觉作为 Work Surface 锚点；
- 结构 Surface 使用中性或略暖 Graphite，不再把玉青 / 墨绿作为基础面板 Hue；
- 世界提供主要色彩，但 Surface 自身必须有足够稳定 Tint，不能因植被背景被染成绿色；
- Paper White 负责阅读；
- Aged Brass 只用于 Selected / Focus / On / Primary / Current；
- Cinnabar 只用于真正 Warning / Danger；
- Context 更轻是任务重量更轻，不机械等于显著降低 Alpha；
- Surface 按 Ambient / Context / Work / Blocking / Elevated 分层，但五档保持同一 Hue 家族；
- Blur 负责软化世界细节，不负责基础可读性；
- 昼夜使用同一 Palette，不维护独立 Night Theme；
- Header 使用 Bare Icon + Title，不使用图标底板、梁头或装饰短线；
- 特色来自材质重量、组件比例、状态与层级，不靠传统纹样。

Palette、材质关系与 Context / Workspace 美术母版见：

`Documentation/Wanhu 烟墨熟铜视觉材质规范.md`

## Gameplay 空间模型

优先级：

`Pause > Tool > Workspace > Management > Gameplay`

稳定槽位：

- 左上：Compass HUD；
- 顶部中央：Top Shell；
- 右上：System Menu + 未来 Notification / Objective；
- 左下：Context Surface / Tool Parameter / 未来 Selection Inspector；
- 中下：Main Dock / Workspace / Placement Action Bar；
- 右下：Operation Hints + Context Utility Toolbar；该槽位在 World / Building / Road Context 间切换。

外围 HUD 默认使用 `16px` Safe Edge，同级 Surface 常用约 `12px` 间距。

## Gameplay Top Shell

### Persistent Status Row

第一层承担持续状态与快捷信息。

左侧：

- 当前天气；
- 季节；
- 游戏时间。

中央固定四个 **Metric Shortcut**，全部只显示 **Icon + Number**：

- 人口 `8,426` → 打开 **城市**；
- 金钱 `24,680` → 打开 **经济**；
- 贸易值 `12,430` → 打开 **库存**；
- 军事值 `68` → 打开 **军事**。

关键规则：

> Top Metric Shortcut 只是快捷入口，不是第二套导航状态。

因此：

- 顶部四项没有 `is-active` / Selected；
- 点击只负责快速打开对应 Management；
- 当前 Management 的 Selected / Active 由第二层 Control Tray 表达；
- Hover Tooltip 用于解释含义与跳转目标；
- 中央四项保持几何居中，不因左右内容变化而偏移。

右侧是纯图标模拟时间控制：`0 / 1 / 2 / 4`。模拟暂停不等于 Pause Menu。

天气状态本身只表达世界状态，不承担 Weather Control 入口。

### Control Tray

第二层为真正的一级 Launcher：

`Camera / Weather │ 城市 / 经济 / 库存 / 政策 / 军事 │ Information Views`

语义：

- 左：场景观察与调整；
- 中：城市管理主导航；
- 右：世界数据观察。

规则：

- 常驻只显示图标；
- Hover Tooltip 提供名称；
- 当前管理域由这里显示 Selected；
- Control Tray 在 Gameplay / Workspace / Management 中保留；
- Tool 中隐藏，只保留 Persistent Status Row。

## Management

当前主导航五个一级域：

- 城市；
- 经济；
- 库存；
- 政策；
- 军事。

复杂系统进入中央 Blocking Management Space：

- 世界压暗 / 轻模糊后仍可见；
- Top Shell 保留；
- Compass、Main Dock、World Utility、Context、Operation Hints 隐藏；
- 再次点击当前主导航、Close 或 Esc 返回 Gameplay；
- Management 内不重复一级导航 Tab；
- Body 始终使用同一中性 Smoked Graphite / Paper 基线，不允许每个专题独立换整页 Theme；
- Header 使用共享 Topic Header Variant：`overview / civic / economy / resource / governance / defense`；
- Topic 色只允许进入 Header Tint、顶部细状态线、标题图标和主要图表 Accent；交互 Focus / Selected 继续服从共享状态语义；
- 城市概况 = Warm Stone，户籍民生 = Clay，财政 / 商贸 = Brass Economy，库存 = Muted Olive，政策 / 治理 = Slate，军务 = Muted Cinnabar；
- Management Panel 已脱离旧 Context Surface Token，不再消费旧黑灰 / 青绿材质；Root Material 由 Management 专属 Smoked Graphite Token 持有。

`ManagementView` 目前仍包含 `population / commerce / governance` 等较细内部视图类型，用于现有原型数据与后续组织；它们不是当前 Top Control Tray 的一级入口。

### Inventory

库存语义是：**查看城市与附近村庄的资源存储和供应关系**。

当前三个页面：

1. **总览**
   - 城市库存 + 周边村庄专项资源；
   - 总量 / 城市 / 村庄 / 日变化 / 状态；
   - 商货总值作为顶部“贸易值”的摘要来源。

2. **城市仓库**
   - 各仓库容量、占用、用途；
   - 日入库 / 日出库；
   - 每座仓库实际储存的资源与占比。

3. **周边村庄**
   - 一个村庄只表达一种专项资源；
   - 当前储量 / 日产量 / 距离 / 路线 / 目标城市仓库 / 运输状态。

## Context Surface

Camera / Weather 共用左下 Context Surface：

- 左 / 下 `16px`；
- Camera 约 `360px` 宽；
- Weather 约 `400px` 宽；
- 最大高度 `720px`；
- 超高只滚 Body；
- Context Surface 与 Design Workspace 当前互斥；
- Tool / Management / Pause 中关闭；
- Esc 优先关闭 Context Surface。

Header 统一使用 Bare Icon + Title。Environment 当前图标约 `19px`、标题约 `16px`；不要恢复 Icon Chip 或装饰梁线。

Context 的正式美术身份是“Workspace 同材质家族中的轻量仪器面板”：与 Workspace 同一中性 Smoked Graphite Hue，Header 略轻，Body 保证参数阅读；不得通过偏青 Tint + 过低 Alpha 重新做成墨绿色玻璃。

Camera / Environment / Road Placement / Building Placement 的完整左下窗口全部由 `LeftContextPanel` 自动附加 `gameplay-left-context-surface`。Root / Header / Body / Footer 材质只允许由 `wanhu-surface-system.css` 提供；不要重新引入 `legacyGameplayClass`、裸 `.gameplay-context-panel` Shell 或 Placement 专属 Surface 分支。

未来 Selection Inspector 优先复用同一左下槽位，并可与世界 Anchor Label 组成双层表达。

Left Context Numeric Parameter：

- Camera / Environment 的连续参数统一使用 `RuntimeParameterRow → NumericSliderField`；
- 外层 Row 只有 `Label + Field` 两列，不允许恢复旧的五列 Grid；
- Camera 使用约 360px、Environment 使用约 400px 的面板宽度，参数 Field 应填满 Label 右侧剩余空间；
- Context 页面只通过共享尺寸 Token 调整 Label / Stepper / Value 宽度，不复制 Slider 结构或材质；
- 已退役 RightEdgeFlyout 的旧 Runtime Slider CSS 不再属于运行时基线。

## Compass / 右上区

Compass：

- 约 `76×76px`；
- 中文东南西北；
- 北向熟铜强调；
- 不做真实风水罗盘复杂纹样；
- 不拦截世界输入；
- 正式 Unity 接 Camera Heading。

右上 System Menu：

- 低存在感；
- 点击打开 Pause；
- 与模拟时间暂停严格区分；
- 剩余区域留给 Notification / Pending Event / Objective。

## Main Dock / Bottom Command

Gameplay 底部三类 Toolbar 共用同一家族：

- Main Dock = L；
- Placement Action Bar = M；
- Context Utility = S。

它们共享材质、Hover / Active、Divider 与图标语言，但尺寸、Surface Tier 和 Shadow 可以不同。

Bottom Command 当前正式材质是与 Workspace / Left Context 同 Hue 的 **Smoked Graphite L / M / S 家族**：

- L Main Dock：较轻 Work，稳定但不抢世界；
- M Placement Action Bar：Focused Work，三者中最稳，作为当前 Tool 主控；
- S Context Utility：Ambient，最轻但保持可读；Gameplay / Workspace 显示 World Utility，Tool 显示 Tool-specific Utility；
- 三者 Root Material 统一由 `wanhu-surface-system.css` 提供，`gameplay-hud-layout.css` 只保留尺寸和屏幕几何；
- 熟铜只用于 Active / Toggle On / Placement Confirm；Quick Action 保持中性且不留下 Selected；
- 不允许恢复深青绿 / 墨绿的 Command Surface。

Contextual Bottom Utility：

- 右下只有一个稳定 Host，不常驻多份 Toolbar；
- Gameplay / Workspace：World Utility；
- Building Tool：Grid / Visible + 对齐道路 / 校准基底 + Undo / Redo；
- Road Tool：Grid / Visible + 拉直当前段 / 连接最近节点 + Undo / Redo；
- 进入 Tool 后地图解锁 / 区域 / 地形 / 配色 / 范围复制 / 范围移动退出；
- 切换动画固定为 100ms Fade+Down → Rebind → 140ms Fade+Up；
- Width 在 Hidden 阶段直接切换，不做 Layout Animation；
- 该模式映射 Unity UI Toolkit 的单一 Host + Definition Rebind。

Main Dock：

- 模式：`设计 / 蓝图`；
- 设计：`道路 / 桥梁 / 建筑 / 台基 / 城墙 / 围墙 / 装饰 / 树木`；
- 默认 `dockCategory=null`；
- 切模式清空分类；
- 不记忆两个模式上一次分类；
- 只有玩家明确点击分类才 Selected；
- 设计八类共用 Design Workspace；
- 当前分类再次点击 / Close / Esc 关闭 Workspace 并清分类。

Blueprint Workspace 尚未实现。

## Design Workspace

正式结构：

`Header + Primary Rail + Context Filter + 4×2 Content Grid + Pager`

稳定规则：

- 八个设计入口共享配置驱动 Workspace；
- Workspace 约 `1240×370`；
- Primary Rail 约 `146px`；
- 8 个资产 / 页；
- Preview 64×64；
- Asset Card 是 Action Button，不是 Toggle；
- Header 使用更轻的 Context 感，Body 稳定阅读；
- 当前壳体使用烟熏 Graphite Glass，不做黑色桌面应用窗口；
- Header 使用约 `18px` Bare Icon + `16px` Title；
- 不恢复梁头、图标 Chip、完整外框或 Web Tab 风格长下划线。

Asset Inspector：

- Children 决定自然尺寸；
- Hover 首次约 280ms；
- Focus 立即显示；
- `pointer-events:none`；
- 作为 Elevated Surface 保留比 Workspace 更清楚的边缘与阴影。

### 城墙主体营造 Tool

城墙体系采用四套独立业务 ToolOverlay，不做一个万能 CityWallPlacementTool：

```text
城墙主体      → city-wall-construction
城墙门洞      → city-wall-gate
登城梯        → city-wall-access-stair
高差楼梯      → city-wall-transition-stair
```

当前第一套 `city-wall-construction` 已从道路式绘制逻辑修正为真正的城墙营造：

- 主模式只有 **范围模式 / 定宽延伸**；
- 范围模式：拖矩形，一次生成四边厚墙，外侧自动为 Front / 城外正面，内侧自动为 Back / 城内背面；
- 定宽延伸：指定墙体厚度后连续延伸，默认正交吸附，可形成 L / U / 闭合轮廓；
- 定宽延伸的开放路径才允许“交换正反面”；
- 旧“北 / 东 / 南 / 西城外正面”与“智能折线 / 直线 / 曲线”全部退出；
- 左侧参数：墙高 / 墙体厚度 / 随地形或整体找平 / 自动挖填或仅填土；
- Range 显示宽 / 长 / 周长；Fixed Width 显示路径长度 / 节点 / 开放状态 / Front / Back；
- 右下 Utility：网格吸附 / 网格显示 / 墙顶线 / 节点显示 / Undo / Redo；
- 墙顶线与节点显示是 Visualization State，不进入 World Undo；
- Web Preview 必须画出有厚度的矩形或 L 形墙体，不能退回道路中心线表达；
- 两种模式最终统一生成 `CityWallPath`，Range 是 4 点闭合 Path，Fixed Width 是逐点路径。

完整规范：`Documentation/城墙主体放置工具设计规范.md`。

### 城墙门洞放置 Tool

第二套独立业务 ToolOverlay 已实现：`city-wall-gate`。

核心规则：

- 城门是独立建筑构件，即使场景没有城墙也能 Free Placement；
- 主模式：自由放置 / 城墙连接；
- 参数：洞口净宽 / 洞口净高 / 建筑纵深；
- Building Depth 不等于 Wall Thickness，连接城墙后也不自动覆盖；
- Free：玩家控制 Position / Rotation，并可独立 Flip Front / Back；
- Wall Connected：自动吸附墙体、自动对齐并继承 Facing，隐藏自由旋转；
- Wall Connected 仍允许 Facing Flip；
- Free Utility 与 Connected Utility 分开 Rebind；
- “吸附城墙”不是 Toggle，连接模式本身就强制执行墙体连接；
- 正式数据关系是 Gate Entity + Wall Connections，不以 Boolean 挖洞作为核心结构；
- Web Preview 显示独立城门体积、纵深、门洞净空、墙厚差异和两侧连接 Anchor；
- 左侧参数面板只保留洞口净宽 / 洞口净高 / 建筑纵深，不重复显示模式、Rotation、Front/Back、墙厚、墙高或连接状态；这些由场景与 Bottom Action Bar 表达。

完整规范：`Documentation/城墙门洞放置工具设计规范.md`。

### 登城梯放置 Tool

第三套独立业务 ToolOverlay 已实现：`city-wall-access-stair`。

当前第一版刻意保持简单：

- 坡度、踏步数量等可由世界系统内部计算，但不进入第一版放置 UI；

## 配色工具

Gameplay 右下 World Utility 的“配色工具”进入独立 `material-palette` Tool Space。

当前 Surface Mode 稳定规则：

- 顶部方案入口已去卡片化：方案 + 类型·方案名 + 进入箭头的单行导航；默认无完整边框/底色，不重复四色缩略；
- 点击左侧“方案”入口后，在 Material ToolActionBar 上方打开中央 `MaterialSchemeWorkspace`；左侧 Surface 参数保持挂载；
- 中央 Workspace 分为系统方案 / 我的方案；系统方案使用全部 / 木头 / 瓦片 / 墙面 Rail；
- Web Demo 当前放入 9 个演示预设以验证 2×3 Card Pool 与分页；这些不是最终美术库；
