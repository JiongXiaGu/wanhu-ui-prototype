## 仍需后续处理的边界

Workspace 前景、来源 Badge、收藏星、Rich Hover、部分 HUD 以及旧 ui-visual-system 仍有局部硬编码。部分是刻意信息色，部分属于技术债；本轮不批量改色，也不宣称全仓库完全 Token 化。

Hover 的 10.2 / 10.5 / 10.6px、Design Card 的 14.2 / 10.5px、Blueprint 名称 13.5px 等仍存在。复刻当前画面与全局 Typography 收敛是不同任务，不借文档整理自动改字。

旧 Edge / Character 选择器存在，不证明当前 DOM 一定消费它；残留 search 样式也不表示应恢复入口。旧 Asset Inspector / Glass / Edge / Character 文档保留追溯价值，但其中配方与能力必须对照当前 Consumer、材质规范和 6.6 专项，不能独立成为取色权威。

共享 Select 的 `.ui-select__menu button.is-selected.is-highlighted` 仍有 inset box-shadow。需结合真实鼠标/键盘行为判断它与“普通菜单 Hover 不叠选中边框”的关系；本轮未修改该实现或取消 Focus，不能宣称所有菜单已完全一致。
