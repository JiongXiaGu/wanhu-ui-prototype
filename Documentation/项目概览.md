# 《万户天工》UI Prototype 项目概览

本仓库用于验证《万户天工》的 UI 美术、构图、信息架构和交互。它不是最终游戏客户端，也不是独立 Web 产品；目标运行时为 Unity 6.6 + URP + UI Toolkit。

## 技术与边界

Web 使用 React / TypeScript / Vite，测试与截图使用 Playwright / GitHub Actions。普通图标运行时为 committed 64×64 PNG，SVG 与 Lucide 仅属于 Source 生产管线，不再依赖 Lucide React 运行时。

设计参考为 1920×1080 固定逻辑画布，浏览器整体等比缩放。正式 Unity 使用 UXML / USS / C# / New Input System 与对应资源、世界系统；不逐字翻译 DOM、CSS Grid 或浏览器 API。

默认直接提交 main，不依赖 Vercel 部署。Unity 6.6 原生滤镜优先验证，共享自定义 URP Blur 是必要时回退；Web 成功不代表 Player 字体、性能和效果通过。

## 视觉入口

从 [UI Toolkit 视觉总规范](<UI Toolkit视觉总规范.md>) 了解页面家族与当前差异，再读取 [烟墨熟铜视觉材质规范](<Wanhu 烟墨熟铜视觉材质规范.md>) 的真实 Token 与表面配方。

主工作区为低饱和烟墨灰，浅暖纸色承担阅读，熟铜承担状态。轻 HUD 保留略冷的烟灰配方，Context / Work 更中性，Blocking / Modal 更稳定。不是所有表面同一个 RGB，也不是 Alpha 阶梯。界面不使用仿古纹样、粗金框、卡片套盒或独立蓝绿页面皮肤。

## Gameplay 分区

左上 Compass、顶部 Top Shell、右上 System / Notification、左下 Context / Parameter、中下 Workspace / Dock / Action Bar、右下 Utility / Operation Hints 是稳定屏幕槽位。外围通常 16px Safe Edge，同级约 12px 间距。

Top Status 承载天气、季节/时间、四项 Icon + Number 摘要及模拟速度。人口、金钱、贸易值、军事值分别快捷打开城市、经济、库存、军事；这些摘要不建立第二份 Selected。Control Tray 提供 `Camera / Weather | 城市 / 经济 / 库存 / 政策 / 军事 | Information Views`，并表达真正导航状态。

Compass 使用中文方向和北向强调，不制作复杂风水罗盘。右上系统暂停与模拟时间暂停是不同操作。Information Views 是观察城市的地图表达，不是管理页面；现有默认、地价、人口、商业、道路、治安、水利选项维持自身流程。

## Context 与 Selection

Camera 约 360px、Environment 约 400px，左下最大高度约 720px，超高只滚 Body。Context 与 Catalog Workspace 当前互斥，避免两个主要操作面板争抢下半屏。

Building Selection 已接入同一 Gameplay 选中框架，不再写成未来占位。UI State 只持有 kind + entityId；经营与外观读数由 Presenter / ViewModel 提供。中下动作是移动、配色 Toggle、关闭；配色在 Selection 内打开 BuildingSchemeWorkspace，不进入顶层 Color Tool。移动复用 Building Placement 的 new / move Intent；移除必须经过共享危险确认。

## Workspace 与底部入口

Main Dock 固定 880×84。设计/蓝图是上下双行 Mode Rail，右侧分类保持图标上、标签下；Mode 无状态线，Category 使用顶部短线。切换 Mode 清空分类，不自动恢复旧分类。设计八类为道路、桥梁、建筑、台基、城墙、围墙、装饰、树木；蓝图九类为全部、民居、商业、工坊、管理、科学、信仰、军事、宫殿。

Design Workspace 约 1240×280，4×2 紧凑资产条目，64×64 Preview 辅助名称阅读；Card 为 Action，不保留点击后的假 Selected。材料与建筑配色方案保持文字/颜色参数列表，当前为 3×2、6 Slot、约 64px 高条目；正面保留名称、收藏、色条/色组、一级分类和来源，次级参数进入 Hover，不补缩略图。

Blueprint Workspace 约 1240×330，4×1 的 4:3 Media Card，来源左上、常驻菜单右上、底部只留名称与收藏星，占地/尺寸进入 Hover。Material / BuildingScheme / Blueprint 均有共享来源、收藏和菜单语言；菜单入口不因来源只读而消失，编辑/删除仍按能力限制。

Catalog Rich Hover 统一在条目上方居中。Rail 页标为白色竖线，Content 页标为白色横线，分类 Selected 则为熟铜，单页保留 Marker。当前已删除的搜索入口不因旧 CSS 或早期规范而恢复。

## Tool 与 Authoring

Building、Road、Terrain、Tree、城墙主体、城门、登城梯、高差楼梯、Color 等工具复用左参数、中下 Action Bar、右下 Utility / Hints 的空间语言，业务 Controller 各自独立。地形修改、路径生成、建造对象、碰撞和真实 Undo 不属于 UI Toolkit。

二级中下栏统一 84px、带字按钮 76×64、24px 图标与下方 11px 标签。常规 World / Catalog 的右下 Utility 保持双行；真实 Placement 按主对象 Action 与 Toggle / History / optional Danger 分两行，第二行可见项多于第一行。Terrain / Color / Selection 不机械套用 Placement 的数量规则。

Color Tool 包含 Surface / Lighting / Scheme。默认 Metallic；Specular 不可用时隐藏，可用时放最后；颜色按钮打开共享编辑器，RGB / HSV 只挂载一组通道。方案分类与来源筛选独立。

Blueprint 创建已具备 Workspace → Photography → Editor → 我的蓝图流程，支持用户定义编辑/删除与重新拍摄。摄影 Web 只验证 4:3 Frame / 安全距离，不模拟拖动世界和真实 Camera；Preview 不反推蓝图对象内容。真实 Blueprint Placement 仍未接入，不在文档整理中越界实现。

## Blocking / Global Space

Settings / Load / Save / New Game 共用全屏 Global Space 材质和 Header / Footer，但保留不同信息结构。New Game 继续地图与开局方案双栏；地图 Selected 用弱熟铜而不是完整金边，名称与种子由按钮进入共享输入 Dialog。

Pause 是独立阻塞空间，背景弱化和中央无颗粒 Panel 分开。通用 Dialog 与 Blueprint Editor 使用共享高不透明近黑 Backdrop 和烟墨 Modal Surface，不把 Pause 的几何套给小弹窗。

Management 使用统一 Blocking Body，专题 Accent 仅影响 Header / 数据。库存保留总览、城市仓库、周边村庄三页，表达存储与供应关系。库存/管理页及资源图标暂缓进一步优化，除非用户明确批准，不混入工具或文档任务。

## 状态、输入与维护

Gameplay 主空间优先级为 Pause > Tool > Workspace > Management > Gameplay；具体 Esc 消费顺序以 UI State / Overlay Controller 与空间规范为准，不靠 DOM 可见性猜测。Operation Hints 使用单一持久 Host，按上下文重绑，除 Pause 外不由各 Feature 随意隐藏。

Motion 让内容向各自锚点收起，业务状态立即生效，隐藏时重绑，禁止大型 Width / Height 动画。Theme、Surface、Controls、Shared Component、Feature 分别维护语义值、完整材质、控件内部、共享几何和业务布局。

`audit:unity`、`audit:scale`、图标校验和构建提供源码/工程线索；重要视觉修改还需实际完整页面截图审查。截图下载不等于已审图，Web 检查不等于 Unity 验证。现存局部样式债务见 `代码审查/2026-09-24-视觉语言与样式权威审查.md`，不宣称全仓库已完成样式收敛。
