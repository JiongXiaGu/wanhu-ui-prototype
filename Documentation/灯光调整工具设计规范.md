# 灯光调整工具设计规范

## 1. 定位

灯光调整是“配色工具”的第二个内部模式，用于直接选择场景中的 Light 并修改少量玩家可理解参数。

它不是：

- Workspace；
- 灯光方案库；
- 预设浏览器；
- 创意工坊资源页；
- 批量灯光编辑器。

正式边界固定为：

1. 选择场景灯光；
2. HDR 灯光颜色；
3. 亮度 Scale；
4. 范围 Scale。

进入工具后不显示中央 Workspace，也不增加独立 Bottom Dock。

## 2. 进入与退出

World Context Utility 只有一个入口：

```text
配色工具
```

进入配色工具后，底部 MaterialPaletteDock 固定提供三个内部模式：

```text
表面模式 | 灯光模式 | 方案模式
```

点击“灯光模式”：

- 顶层 Tool 仍然是 `material-palette`；
- `MaterialPaletteMode = lighting`；
- 同一个 MaterialPaletteDock 保持挂载；
- 左侧内容切换为 Light Adjustment Panel；
- 世界中显示可选择灯光 Handle；
- 不创建中央 Workspace。

退出配色工具：

- 点击任一子模式左侧 Panel Close；
- 或底部“完成配色 / 取消配色”；
- 或 Esc；
- 返回 Gameplay。

## 3. 场景选择

Web Prototype 通过少量 Scene Light Handle 模拟 Unity 中的 Light Picking。

状态：

```text
SelectedLightId = none
→ 左侧提示“选择一盏场景灯光”

点击 Light Handle
→ SelectedLightId = lightId
→ 同一个左侧 Panel Rebind
```

切换灯光不创建第二个面板，不关闭再打开 Panel。

Web Handle 只是 Prototype Adapter，不属于正式业务模型。

Unity：

- Pointer / Raycast 选择真实场景 Light Entity / Authoring Proxy；
- Selection Controller 更新 SelectedLightId；
- UI 绑定当前 LightAdjustmentModel。

## 4. 左侧参数

选中灯光后：

```text
灯光
城门灯笼 03

颜色        [HDR 色块 >]
亮度        - Slider +  1.00×
范围        - Slider +  1.00×
```

只保留三个玩家入口。

不在第一阶段加入：

- 阴影；
- 色温；
- Cookie；
- Volumetric；
- Spot Angle；
- 高级渲染参数；
- 灯光 Preset。

## 5. HDR 颜色

灯光参数页统一使用共享 `ColorParameterField` 作为进入颜色编辑器的入口，不再使用“小色块 + 外置 HDR + 箭头”的私有结构。

参数页：

```text
颜色   [ 当前颜色长条                         HDR  › ]
亮度   [ NumericSliderField........................ ]
范围   [ NumericSliderField........................ ]
```

稳定规则：

- `ColorParameterField` 与 `NumericSliderField` 共用同一个 `ui-parameter-row` 两列布局；
- ColorParameterField 整体占满 Slider 的 Control Column，起点与宽度一致；
- Control 本身保持中性烟墨，不允许整块铺满高亮颜色；
- 内部采用最直接的两段式：左侧长 Color Preview，右侧中性 Meta；
- Color Preview 高约 18px，占 Control 宽度约 68%–86%，用于清楚显示当前颜色但不主导整块面板；
- HDR 是普通可读文字，显示在右侧 Meta 内，字号不低于普通参数文字尺度；
- `hdr=false` 时不显示“SDR”，Meta 只保留 Chevron，颜色 Preview 自动变长；
- HDR 与 Chevron 不叠在亮色上，因此不需要复杂 Contrast Overlay；
- 颜色 Preview 只预览归一化 RGB，不根据 HDR Intensity 把 UI 本身做得刺眼。

点击颜色条后进入 HDR Color Editor。

灯光颜色页继续复用共享 `ColorEditorPage`：

- SV 面板；
- Hue；
- HEX；
- RGB / HSV；
- HDR Badge；
- HDR 强度。

Light Color Binding：

```text
Color
HDR Color Intensity
```

材质 Emission 与 Light Color 使用同一个共享编辑器结构，但业务 Adapter 不同。

正式 Unity 建议：

```text
ColorParameterField.uxml
SharedColorEditor.uxml
SharedColorEditor.uss
ColorEditorController
```

由 Binding Definition 决定：

- 是否 HDR；
- 是否 Alpha；
- Intensity Label；
- Intensity Range。

## 6. 亮度 Scale

UI 不直接暴露 Unity Light 的绝对 Intensity。

```text
FinalIntensity
= BaseIntensity
× HdrColorIntensity
× IntensityScale
```

第一阶段：

- Min = 0.00×；
- Max = 3.00×；
- Step = 0.05×；
- Default = 1.00×。

`0.00×` 允许灯光实际熄灭。

使用共享 `NumericSliderField`，精确值仍走共享 Number Dialog。

## 7. 范围 Scale

```text
FinalRange
= BaseRange
× RangeScale
```

第一阶段：

- Min = 0.25×；
- Max = 3.00×；
- Step = 0.05×；
- Default = 1.00×。

不允许 0，避免“灯存在但范围完全消失”的模糊状态。

同样使用共享 `NumericSliderField`。

## 8. 数据模型

推荐正式模型：

```text
SceneLightDefinition
├ LightId
├ BaseColor
├ BaseIntensity
└ BaseRange

SceneLightAdjustment
├ Color
├ HdrColorIntensity
├ IntensityScale
└ RangeScale
```

UI Controller：

```text
LightAdjustmentController
├ SelectedLightId
├ SelectedLightAdjustment
├ SelectLight(lightId)
├ SetColor(...)
├ SetHdrIntensity(...)
├ SetIntensityScale(...)
└ SetRangeScale(...)
```

Web Prototype 当前把少量 Light Draft 放在 Tool Adapter 内，只用于验证交互。

## 9. Unity UI Toolkit 映射

```text
LightAdjustmentPanel.uxml

LeftContextPanel
├ Header
│  ├ Light Icon
│  ├ Title
│  ├ Selected Light Name
│  └ Close
└ Body
   ├ ColorParameterField(HDR)
   ├ NumericSliderField(IntensityScale)
   └ NumericSliderField(RangeScale)
```

颜色页：

```text
LeftContextPanel
└ SharedColorEditor(HDR)
```

Tool 不需要：

- Workspace；
- Catalog；
- Pager；
- Bottom Action Dock。

## 10. UI Review

必须检查：

- World Utility 不存在独立“灯光调整”入口，只存在“配色工具”；
- 进入后没有中央 Workspace；
- 切换到灯光模式后 MaterialPaletteDock 必须继续存在；
- 未选择时左侧显示选择提示；
- Scene Light Handle 可选择；
- 选择后同一个 Panel Rebind；
- 参数仅为颜色 / 亮度 / 范围；
- 参数页 ColorParameterField 外层 Control 与 NumericSliderField Control Column 必须平齐；
- Color Preview 必须是长而克制的左侧预览段，不能退回整块纯色填充，也不能缩成难辨认的小色条；
- HDR 文字必须清楚可读，并位于同一个 ColorParameterField 的右侧 Meta 区；
- Color Editor 标记为 HDR；
- LightColor.Intensity Adapter 存在；
- IntensityScale / RangeScale 使用 NumericSliderField 实时更新；
- 切换另一盏灯不生成第二个 Panel；
- 退出后恢复 Gameplay World Utility。
