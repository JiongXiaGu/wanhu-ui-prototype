# 地形编辑工具设计规范

Terrain Edit 是直接修改世界地形的 **World Tool**，不是 Design Workspace 中的资产放置工具。

## 1. 入口与空间

入口：

```text
World Utility
└ 地形编辑
      ↓
Terrain Edit Tool Space
```

进入 Tool 后：

- Top Persistent Status Row 保留；
- Compass / System Menu 保留；
- Control Tray 收起；
- Main Dock / Workspace 收起；
- 左下显示 Terrain Context；
- 中下显示 ToolActionBar；
- 右下切换 Terrain Context Utility；
- Operation Hints 切换到当前 Terrain Mode。

Motion 继续使用现有 Tool Handoff Preset，不新增动画类型。

## 2. 状态

```ts
Tool = 'terrain-edit'

TerrainEditMode =
  | 'raise'
  | 'lower'
  | 'flatten'
  | 'smooth'
  | 'slope'
```

建筑放置原来的地形关系类型正式命名为 `BuildingTerrainMode`，不得与 TerrainEditMode 合并。

## 3. ToolOrigin

Terrain Edit 可以从 Gameplay，也可以在 Workspace 打开时通过 World Utility 进入。

Tool 进入时记录：

```text
gameplay
or
design-workspace(category)
```

完成 / Esc 退出后恢复 Origin。

不要根据 Terrain / Road / Building 类型硬编码返回页面。

## 4. 左侧 Terrain Context

复用 `LeftContextPanel`，不创建新的 Surface Shell。

Header：

- Mountain Bare Icon；
- 标题：地形编辑；
- Subtitle：塑形与标高。

### Brush

首轮固定圆形 Brush：

- 笔刷半径：4–80 m；
- 编辑强度：5–100%；
- 边缘衰减：0–100%。

全部消费 `RuntimeParameterRow → NumericSliderField`。

### 当前地形

显示轻量只读信息：

- 当前标高；
- 当前坡度；
- 保护已建区域状态。

## 5. 模式

### Raise / 抬高

连续 Brush，提高高度。

### Lower / 降低

连续 Brush，降低高度。

### Flatten / 整平

额外参数：

- 目标标高；
- 取样当前位置标高。

正式 Unity 支持 Alt + Click / Pick Height Action。

### Smooth / 平滑

平滑局部尖峰 / 凹坑。首轮不加入侵蚀 / 噪声 / 山脉生成。

### Slope / 坡面

两点式 World Operation：

1. 指定起点；
2. 指定终点；
3. 生成连续坡面。

Context 显示起点高度 / 终点高度 / 预估坡度。

## 6. ToolActionBar

Terrain 不复制 PlacementActionBar Shell，而是直接消费共享 `ToolActionBar`。

中央模式：

`抬高 / 降低 / 整平 / 平滑 / 坡面`

Terrain Commit 只有：

- 完成：退出地形编辑，保留已执行修改。

不提供“取消整个 Terrain Session”。

回退修改使用 Undo。

PlacementActionBar 已改成 ToolActionBar 的 Adapter，Building / Road 仍固定有完成 + 取消。

## 7. Terrain Context Utility

Terrain Tool 不使用完整 World Utility，也不强制保留 Grid Snap。

当前：

- Grid Visible；
- Contours / 等高线；
- Slope View / 坡度视图；
- Protect Built Area / 保护已建区域；
- Undo；
- Redo。

这些 Toggle 是 Tool View / Safety State，不使用一次性 Selected 语义。

## 8. Operation Hints

按 TerrainEditMode 切换。

例如 Raise：

- 左键：连续抬高；
- 拖动：连续编辑；
- 滚轮：调整 Brush Radius；
- Shift：临时降低强度；
- Ctrl+Z：Undo；
- Esc：退出 Tool。

Flatten 增加 Alt + 左键取样标高；Slope 改为起点 / 终点交互。

## 9. World Visualization

Web 原型中的 Brush Ring 只验证信息表达：

- Outer Ring：Radius；
- Inner Ring：Falloff；
- Cross：Sample Point；
- Label：Mode / Radius / Strength。

正式 Unity **不使用 UI Toolkit 实现真实 Brush Ring**。

推荐：

```text
TerrainBrushController
├ Raycast
├ Brush Params
├ Height Modification
├ Protection Query
├ Undo Command
└ TerrainBrushRenderer
   ├ Procedural Mesh / Decal
   ├ Falloff Ring
   ├ Invalid Area
   └ Optional World Label
```

UI Toolkit 只绑定参数与状态。

## 10. 已建区域保护

默认开启。

正式世界规则保护：

- 建筑基底；
- 道路；
- 城墙；
- 桥梁连接点；
- 其它声明 Terrain Protection 的世界对象。

Web Prototype 只验证 Toggle / 状态，不实现真实碰撞保护算法。

## 11. Unity UI Toolkit 映射

```text
TerrainToolController
├ TerrainToolState
├ TerrainBrushController        World / Terrain
└ TerrainToolUIController
   ├ LeftContextHost
   │  └ TerrainContext.uxml
   ├ ToolActionHost
   │  └ ToolActionBar.uxml
   └ UtilityToolbarHost
      └ Terrain Utility Definition
```

USS：

- Left Context 使用共享 Surface；
- ToolActionBar 使用 M 档 Bottom Command；
- Context Utility 使用 S 档；
- Motion 使用 Left / Bottom Preset。

## 12. 首轮非目标

Web Demo 不实现：

- 真实高度图编辑；
- TerrainData 写入；
- 侵蚀；
- 噪声地貌；
- 河流生成；
- Stamp Library；
- Terrain Texture Paint。

这些属于正式 Unity Terrain / World System，而不是 UI Prototype。
