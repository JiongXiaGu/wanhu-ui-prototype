# 设置界面规范

《万户天工》的设置界面最终用于 Unity UI Toolkit。Web Prototype 用于验证视觉、布局、信息结构、控件状态与交互手感，不是最终 Web 产品。

## 1. 总体结构

设置界面采用世界之上的 Blocking Settings Space。世界保留并统一压暗 / 轻模糊，中央承载稳定的 Smoked Graphite Settings Command Surface：

```text
World / Menu Backdrop
Shared Blocking Dim + Blur
Settings Command Surface
├ Header
├ Category Tabs
├ Single-column Scroll View
└ Footer Action Bar
Global Dialog Layer（按需）
```

顶部分类：

`显示 / 图形 / 音频 / 操作 / 游戏`

中间内容保持一列纵向滚动，不使用双栏 Card，不给每个 Section 套独立大面板。1920×1080 基准下 Settings Command Surface 约 1180×850 px、18px Radius，内容宽度约 900～930 px。不要恢复 edge-to-edge 近纯黑页面。

Header 只负责页面身份与标题，不放置孤立的左上角返回按钮。

Footer 使用统一的全屏页面动作栏：

```text
[返回]  [恢复当前分类默认值]                              （右侧空）
```

- 左侧：导航与次级动作；
- 右侧：页面主动作，Settings 当前为空；
- `Esc` 与底部“返回”保持同一导航语义；
- 不再常驻“取消 / 应用”按钮。

这个动作栏模式可供其它全屏页面复用，右侧可以按页面需要放置 `读取 / 上传 / 确认 / 开始` 等主动作。

## 2. Section 与设置行

每个分类由若干 Section 组成：

- 显示：显示输出 / 界面；
- 图形：图形质量 / 城市细节 / 光照与特效；
- 音频：音量 / 播放行为；
- 操作：鼠标与镜头 / 按键绑定；
- 游戏：存档 / 游戏体验 / 语言与菜单。

Section：

- 标题使用中性浅灰；
- 可带极弱横向分隔线；
- 普通 Section 不使用暖金左边线；
- 不常驻说明性副文案；
- 解释信息进入 Tooltip。

普通设置行：

```text
设置名称                              控件 / 当前值
```

规则：

- Label 左对齐；
- Control 右对齐；
- 同类 Control 尽量共享宽度；
- 默认背景透明；
- Hover 仅增加极弱 Tone；
- 行间只允许极弱分隔；
- Disabled 行降低对比度但仍保持可读。

## 3. 暖金使用

暖金只用于高价值状态：

- 当前 Category Tab；
- Slider Fill / Dragging / Focus；
- Toggle On；
- Select Open / Selected；
- Binding Listening；
- Primary Safety Action；
- 其它 Selected / Focus 状态。

不要把暖金用于普通 Section 装饰、静态文字或大面积背景。

## 4. Select

收起：

```text
显示模式                         无边框全屏  ˅
```

展开：

```text
                                 ┌──────────────┐
                                 │ 独占全屏     │
                                 │ 无边框全屏 ✓ │
                                 │ 窗口         │
                                 └──────────────┘
```

规则：

- 不使用浏览器原生 Select 视觉；
- 默认只保留轻量文字值与弱底线；
- Open / Focus 使用暖金；
- 当前项使用低饱和 Selected；
- 菜单使用不透底的深墨 Surface；
- 点击外部关闭；
- Esc 关闭；
- `↑ / ↓` 选择候选；
- Enter / Space 确认；
- 接近 ScrollView 底部时允许向上展开。

Unity 可映射到项目 `ChoicePickerField` 或共享 Dropdown 控件。

## 5. Slider

结构：

```text
设置名称          [−] ━━━━━━━●━━ [＋] [100%]
```

视觉：

- 连续数值统一消费共享 `NumericSliderField`；
- Track 低对比；
- Default Progress 使用中性 Paper / Smoke，不常驻满屏金线；
- Focus / Dragging 时 Progress 与 Focus Ring 才切换为熟铜；
- `− / +` 提供一步精调，Slider 提供连续调整，Value 独立显示；
- 视觉轨道可较细，但 Pointer Hit Area 必须明显更高。

交互：

- 点击轨道跳到对应值；
- Pointer 连续拖动；
- 拖动时增强 Thumb / Fill；
- `← / ↓` 递减一个 Step；
- `→ / ↑` 递增一个 Step；
- Shift + 方向键大步调整；
- Home / End 到最小 / 最大；
- 数值实时刷新；
- 默认不使用鼠标滚轮改值，避免与设置页纵向滚动冲突。

## 6. Toggle

- Off 使用中性灰；
- On 使用暖金；
- Hover 提高边界与底色亮度；
- Pressed 有短反馈；
- Focus 使用克制暖金；
- Disabled 时不可点击；
- 不额外常驻“开启 / 关闭”文本，除非语义确有必要。

## 7. Input Binding

按键绑定必须同时支持 **主要按键 + 次要按键**。

```text
操作名称             主要按键          次要按键          恢复
```

Unity 结构：

```text
InputBindingRow
├ Label
├ PrimaryBindingButton
├ SecondaryBindingButton
└ ResetButton
```

规则：

- 两个按键槽同尺寸、同权重；
- 次要槽为空显示 `+ 添加`；
- 行级恢复默认弱化，Hover / Focus 时出现；
- Listening 显示 `按下新的按键…`；
- Esc 取消监听；
- Delete / Backspace 清除当前槽；
- 冲突不静默覆盖，使用暖红就地提示；
- 最终 Unity 使用 Input System Rebinding。

当前折叠分组：

- 基础操作；
- 营造与道路；
- 时间控制；
- 镜头操作；
- 快捷栏。

默认仅展开“基础操作”。

## 8. Settings 应用策略

设置正式分成两类。

### 8.1 普通设置：即时生效 + 即时保存

普通设置修改后：

```text
Change
→ Apply Runtime
→ Save
```

不需要 Footer Apply，也不存在退出时的未保存 Draft。

典型内容：

- 音量；
- 灵敏度；
- VSync / 普通 Toggle；
- 常规图形质量；
- 游戏行为；
- 普通 Select；
- 按键重绑定。

因此正常 Settings 状态下：

```text
Esc / 返回
→ 直接退出
```

不弹“是否保存修改”。

### 8.2 可回滚显示设置：临时应用 + 安全确认

以下设置可能导致玩家无法正常看见或操作 UI，必须使用安全确认：

- 显示模式；
- 显示器；
- 分辨率；
- 屏幕刷新率；
- HDR 输出；
- **界面缩放**。

修改流程：

```text
Change
→ Temporary Apply
→ Safe Confirmation Layer
→ Keep / Rollback
```

安全确认默认倒计时 **15 秒**。

- `保留设置`：正式保存临时值；
- `恢复原设置`：立即恢复上一个安全快照；
- 倒计时归零：自动恢复；
- Esc：恢复旧设置；
- 安全确认未结束时，不允许继续修改下层 Settings。

## 9. 界面缩放

界面缩放是离散档位，不使用 Slider。

当前 Prototype：

`80% / 90% / 100% / 110% / 125% / 150%`

原因：

- UI Scale 会改变玩家可见范围和交互尺寸；
- 离散档位更容易测试 1080p / 1440p / 4K；
- 避免 107%、113% 等没有必要的细碎值；
- 便于最终 UI Toolkit 维护布局与回归测试。

未来可以根据分辨率 / DPI 给某个档位标记“推荐”，但不强制玩家使用。

## 10. Safe Confirmation Layer

安全确认属于系统级恢复能力，但视觉与 Modal Host 不再由 Settings 私有实现；Web Prototype 直接使用全局 `DialogSystem.timed` / `DialogFrame`，最终 Unity 放入独立 System Safe Overlay。

视觉结构：

```text
保留这些显示设置？
如果画面或界面显示异常，设置将在倒计时结束后自动恢复。

界面缩放                     100% → 125%

                              15

                恢复原设置        保留设置

                      [Esc] 恢复原设置
```

视觉：

- 世界 / Settings 进一步压暗；
- 约 420～480 px 深墨 Surface；
- 不使用警告红色；
- 倒计时可以稍大；
- 暖金只强调“保留设置”；
- “恢复原设置”使用中性浅纸色。

### Safe Layer 不受测试中的 UI Scale 影响

这是关键不变量。

最终 Unity 必须让安全确认层使用独立的固定 Safe Scale / System Overlay，而不是继承正在测试的 UI Scale。

否则玩家把 UI Scale 调到异常值后，连恢复按钮本身都可能变得不可操作。

推荐概念：

```text
SettingsRoot             ← 玩家 UI Scale
SystemSafeOverlay        ← 固定安全缩放
```

## 11. Previous Safe Snapshot

危险显示设置应用前必须保存旧快照：

```text
PreviousSafeSettings = CurrentSafeSettings
TemporaryApply(NewValues)
```

保留：

```text
CurrentSafeSettings = NewValues
Clear PreviousSafeSettings
```

恢复 / 超时：

```text
Restore(PreviousSafeSettings)
```

最终 Unity 不要依赖“Settings 页面仍然可见”才能恢复显示参数；Rollback 必须属于设置系统本身的能力。

## 12. Footer 动作栏与恢复当前分类默认值

Settings Footer 使用全屏页面动作栏结构：

```text
左侧： [返回] [恢复当前分类默认值]
右侧： （空）
```

规则：

- `返回` 是页面导航动作，视觉比“恢复默认”略强，但仍属于 Secondary；
- `恢复当前分类默认值` 是工具动作，保持较弱权重；
- Settings 不为了左右对称在右侧制造无意义按钮；
- `Esc` 等价于底部“返回”；
- Safe Confirmation 打开时，Esc 优先回滚，不触发页面返回。

普通分类恢复后立即生效并保存。

如果“显示”分类的恢复操作修改了任何可回滚显示设置，则：

```text
Temporary Restore Defaults
→ Safe Confirmation
→ Keep / Rollback
```

不要通过恢复默认值绕过安全确认。

其它全屏页面可复用相同动作栏：左侧放导航 / 次级动作，右侧放页面主动作，例如 `读取 / 上传 / 确认 / 开始`。

## 13. Disabled 与设置依赖

Disabled 必须是真正不可操作的状态。

示例：

- 超分辨率不是 DLSS 时禁用仅属于 DLSS 的帧生成；
- 关闭屏幕边缘滚动后禁用边缘滚动速度；
- 硬件不支持 HDR 时禁用 HDR；
- 硬件不支持某图形能力时禁用对应功能。

表现：

- 整行降低对比度；
- Label / Value / Track / Toggle 同步弱化；
- 条目不消失；
- Tooltip 可以解释不可用原因。

## 14. 配置内容基准

### 显示

- 显示模式；
- 显示器；
- 分辨率；
- 屏幕刷新率；
- HDR 输出；
- 垂直同步；
- 帧率限制；
- 界面缩放；
- 安全区域。

### 图形

- 综合质量；
- 渲染比例；
- 抗锯齿；
- 超分辨率；
- 帧生成；
- 低延迟模式；
- 建筑 / 居民 / 植被距离与质量；
- 阴影；
- 地形；
- 水体；
- 反射；
- AO；
- 体积雾；
- 云层与动态云影；
- Bloom；
- 景深；
- 动态模糊。

最终设置项必须与项目真实渲染功能保持一致，不为了“看起来丰富”保留不存在的功能。

### 音频

- 主音量；
- 音乐；
- 游戏音效；
- 环境声音；
- 界面声音；
- 失去焦点时静音；
- 界面提示音；
- 城市环境声；
- 平滑音乐切换。

### 操作

- 指针 / 滚轮灵敏度；
- 水平 / 垂直 / 滚轮反转；
- 键盘移动 / 旋转速度；
- 边缘滚动；
- 双槽按键绑定。

### 游戏

- 自动保存间隔 / 数量；
- 营造教程；
- 操作提示；
- 重要操作二次确认；
- 居民故事提示；
- 重要事件自动暂停；
- 界面语言；
- 主菜单镜头运动。

## 15. UI Toolkit 落地

推荐：

```text
SettingsRoot
├ Header
├ CategoryTabs
├ ScrollView
│  └ SettingsList
│     ├ Section
│     │  ├ SectionHeader
│     │  └ SettingRows
│     ├ InputBindingSection
│     └ ...
├ FooterActionBar
│  ├ LeftActions
│  │  ├ Back
│  │  └ RestoreCurrentCategory
│  └ RightActions
└ SystemSafeOverlay
```

实现原则：

- Flex Column / Flex Row；
- ScrollView；
- 共享 SettingRow；
- 共享 ChoicePicker / Slider / Toggle；
- 共享 InputBindingField；
- FooterActionBar 使用明确的左右职责，不依赖 Web 特有布局；
- C# 统一管理 Immediate Save 与 Safe Snapshot；
- Safe Confirmation Layer 独立于普通 UI Scale；
- 场景背景模糊统一由 URP 全屏 Blur Pass 提供。

## 16. 禁止回退

不要恢复：

- 双栏 Settings Card；
- 普通 Section 金边；
- 常驻说明小字；
- 每行完整边框；
- 无意义 Preview / Summary；
- 大面积暖金；
- 单一按键槽；
- 静态不可操作的 Slider / Select / Toggle；
- 常驻 `取消 / 应用` Footer；
- 左上角孤立返回按钮；
- UI Scale Slider；
- 危险显示设置无回滚直接永久保存；
- Safe Confirmation 跟随测试中的 UI Scale 一起缩放。


## 17. 2026-09-18 Visual System Consolidation

- Settings Root 只负责 Blocking Space，中央 Settings Command Surface 使用共享 Smoked Graphite Blocking Material；
- 世界背景继续可见，不再使用 edge-to-edge 近纯黑背景；
- 新增共享 `NumericSliderField = − / Slider / + / Value`，Runtime Tool 与 Settings 共用；
- Select / Toggle 直接使用共享 Field 外观，删除 `ui-select--settings / ui-slider--settings / ui-toggle--settings` 视觉分支；
- 按键绑定使用共享 `InputBindingField`；
- Safe Display Confirmation 进入全局 Dialog System；
- 熟铜只表达 Active / Focus / On / Primary，不让大量 Slider 默认显示为金线。
