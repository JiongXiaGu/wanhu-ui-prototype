# 城墙主体放置工具设计规范

`CityWallConstructionTool` 是城墙四套独立业务 ToolOverlay 中的第一套，只负责 **城墙主体营造**。

## 1. Tool 边界

城墙体系固定拆分：

```text
city-wall-construction
city-wall-gate
city-wall-access-stair
city-wall-transition-stair
```

四套 Tool 可以拥有不同 Mode、Workflow Step 与附加窗口。它们只共享 UI Primitive、Surface、Motion、Utility Host 与 History 接口。

## 2. 城墙不是道路

城墙主体不再使用“智能折线 / 直线 / 曲线”道路式模式。

正式两种输入方式：

```ts
CityWallConstructionMode =
  | 'range'
  | 'fixed-width'
```

- Range：拖出矩形范围，一次生成四边城墙；
- Fixed Width：指定墙体厚度后连续延伸，可形成 L / U / 闭合正交轮廓。

城墙轴线是否顺坡由 Terrain Relation 决定，不使用道路 Bézier 曲线表达城防形态。

## 3. Range Mode

玩家从 A 拖到 B 形成矩形：

```text
A ┌────────────────┐
  │      城内      │
  └────────────────┘ B
```

系统转成 4 个角点和闭合路径。

范围模式规则：

- 四边均为有厚度墙体；
- 矩形外部自动定义为 Front / 城外正面；
- 矩形内部自动定义为 Back / 城内背面；
- 不显示“交换正反面”；
- 四角 Handle 用于调整范围；
- 当前宽度 / 长度 / 周长作为只读结果显示；
- 第一版保持轴对齐矩形，不提前加入整体旋转。

## 4. Fixed Width Mode

玩家指定墙体厚度后连续营造：

```text
A ━━━━━━━━━━━ B
             ┃
             ┃
             C
```

默认正交吸附，可形成：

- 直段；
- L；
- U；
- 闭合矩形；
- 多段正交轮廓。

`Shift` 临时关闭正交吸附，为以后特殊斜墙保留输入能力，但不新增“曲线模式”。

当前开放路径允许：

```text
交换正反面
```

当路径最终闭合后，正式 Unity 可以根据 Polygon Winding 自动统一“外 = Front / 内 = Back”。

## 5. Front / Back

旧原型的“北 / 东 / 南 / 西城外正面”退出正式方案。

正反面改为相对墙段方向：

```text
Front = 城外正面
Back  = 城内背面
```

开放路径使用：

```ts
CityWallFacingSide = 'left' | 'right'
```

含义是 Front 位于路径方向的左侧或右侧。

转 90° 后 Facing 必须沿整条路径连续传播，不允许每个墙段单独重新指定。

这套数据随后会直接服务：

- 门洞朝向；
- 城门楼朝向；
- 登城梯默认城内侧吸附；
- 城垛 / 女墙 / 防御构件方向。

## 6. 左侧参数

两种模式共同保留：

- 墙高；
- 墙体厚度；
- 地形关系：随地形 / 整体找平；
- 基底处理：自动挖填 / 仅填土。

Range 额外显示：

- 当前宽度；
- 当前长度；
- 当前周长；
- “正面自动朝外”的只读说明。

Fixed Width 额外显示：

- 当前路径长度；
- 节点数；
- 开放 / 闭合状态；
- Front 所在侧；
- Back 所在侧。

## 7. Bottom Action Bar

正式：

```text
[范围模式] [定宽延伸]
              │
        [交换正反面]
              │
          [完成] [取消]
```

规则：

- Range 下不显示 Facing Flip；
- Fixed Width 下显示 Facing Flip；
- 不再出现智能折线 / 直线 / 曲线。

## 8. Context Utility

当前：

- 网格吸附；
- 网格显示；
- 墙顶线；
- 节点显示；
- Undo；
- Redo。

Wall Top Line / Node Display 只属于 Visualization State，不进入 World Command History。

## 9. Operation Hints

Range：

- 左键拖动：拉出矩形范围；
- 拖动四角：调整范围；
- Esc：取消营造。

Fixed Width：

- 左键：确定起点 / 添加转角；
- 拖动：按固定墙厚延伸；
- Shift：临时关闭正交吸附；
- 右键：结束当前路径；
- Esc：取消营造。

## 10. 数据结果统一

两种输入最终都生成同一种世界数据：

```text
CityWallPath
├ Points[]
├ Closed
├ WallThickness
├ WallHeight
├ Facing
└ TerrainAlignment
```

Range 只是快速生成 4 点闭合 Path；Fixed Width 则逐步追加 Points。

## 11. World Visualization

Web 只验证表达。

Range：

- 四条 Thick Wall Band；
- 四角 Handle；
- 很弱的城内 Fill；
- 四侧 Front 朝外提示。

Fixed Width：

- 明显有厚度的 L Shape；
- Inner / Outer Edge；
- Path Node；
- Front / Back 标记；
- Wall Top Line。

正式 Unity：

```text
CityWallWorldRenderer
├ RangeGhost
├ ThickWallSegments
├ CornerHandles
├ PathNodes
├ WallTopLine
├ FrontBackFacing
└ InvalidPlacement
```

真实 Mesh、Terrain Query、连接、土方和合法性检查全部属于 World Tool，不由 UI Toolkit 完成。

## 12. Visual Review

至少检查：

- 默认进入 Range；
- Range 预览是有厚度的四边矩形而不是中心线；
- Range 有四个向外 Front，且没有 Facing Flip；
- 旧智能折线 / 直线 / 曲线全部退出；
- Fixed Width 是明显有厚度的 L 形；
- Fixed Width 才出现“交换正反面”；
- Facing Flip 后状态从 Right 切换到 Left；
- 墙顶线 Toggle 会影响两种 Preview；
- Operation Hints 随两种 Mode Rebind；
- 完成后回到城墙 Workspace。
