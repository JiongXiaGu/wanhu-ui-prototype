# 城墙主体放置工具设计规范

`CityWallConstructionTool` 是城墙四套独立业务 ToolOverlay 中的第一套，只负责 **城墙主体路径营造**。

## 1. Tool 边界

城墙体系固定拆分：

```text
city-wall-construction
city-wall-gate
city-wall-access-stair
city-wall-transition-stair
```

四套 Tool 可以拥有不同 Mode、Workflow Step 与附加窗口。它们只共享 UI Primitive、Surface、Motion、Utility Host 与 History 接口。

## 2. UI 结构

```text
左下
CityWallConstructionOverlay
  → PlacementContextPanel

中下
CityWallConstructionDock
  → PlacementActionBar

右下
ContextUtilityToolbar
  → city-wall-construction Definition

世界
CityWall Path Preview
```

不恢复历史 `.tool-overlay` Shell。

## 3. 绘制模式

```ts
CityWallDrawMode =
  | 'smart-polyline'
  | 'straight'
  | 'curve'
```

- 智能折线：默认模式，连续放置节点并自动保持合理转角；
- 直线：起点到终点保持笔直；
- 曲线：用于山地、河岸和不规则边界。

绘制模式属于 Construction Controller，不属于 Workspace Asset。

## 4. 左侧参数

首轮保留：

- 墙高：6–24 m；
- 地形关系：随地形 / 整体找平；
- 基底处理：自动挖填 / 仅填土。

自动计算区：

- 墙体厚度；
- 马道净宽；
- 平均坡度。

墙体厚度等结构尺寸后续可来自当前 Wall System / Module 配置，不要求玩家手动输入所有几何参数。

## 5. 城外方向

城外方向属于路径语义，不是独立资产：

```ts
CityWallOutsideSide = 'left' | 'right'
```

Bottom Quick Action 提供“反转城外方向”。World Preview 通过弱方向标记表达当前侧。

## 6. Context Utility

当前：

- 网格吸附；
- 网格显示；
- 墙顶线；
- 节点显示；
- Undo；
- Redo。

其中：

- Grid Snap 会影响世界营造；
- Wall Top Line / Node Display 只影响 Visualization；
- Visualization Toggle 不进入 World Undo / Redo。

## 7. Operation Hints

三种 Draw Mode 独立 Rebind：

- 智能折线：左键放节点；
- 直线：左键确定起点 / 终点；
- 曲线：左键放控制点；
- 右键结束当前墙段；
- Esc 退出当前 Tool。

## 8. World Visualization

Web 只验证表达：

- Wall Segment Ghost；
- Path Node；
- Wall Top Line；
- Outside Direction。

正式 Unity：

```text
CityWallWorldRenderer
├ PathSegments
├ PreviewSegment
├ PathNodes
├ WallTopLine
├ OutsideFacing
└ InvalidPlacement
```

真实 Mesh、Terrain Query、连接、土方和合法性检查全部属于 World Tool，不由 UI Toolkit 完成。

## 9. Workspace 路由

City Wall Card 通过 `toolType` 进入对应 Tool。

当前：

```text
filters = wall
→ toolType = city-wall-construction
```

其余三类已经拥有独立 ToolType，但本阶段不进入未实现 Tool。

## 10. Visual Review

至少检查：

- 小倾斜角 → 城墙 → 标准墙段 能进入 Tool；
- 左侧参数完整且 NumericSliderField 无旧五列泄漏；
- 三种 Draw Mode 全部存在；
- 城外方向可反转；
- Utility 只显示城墙主体相关功能；
- 墙顶线 Toggle 会立即影响 World Preview；
- Operation Hints 跟随 Draw Mode Rebind；
- 完成后回到城墙 Workspace；
- 1920×1080 下左 / 中 / 右与 World Preview 不互相遮挡。
