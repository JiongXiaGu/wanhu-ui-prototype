# 工具辨识与局部布局

本规范记录《万户天工》工具与局部布局精修的职责和边界。配色、全局字号和屏幕空间沿用已确认的烟墨熟铜与 Unity 6.6 基线。

## 保留的设计

材质方案和建筑配色方案的文字列表是明确的设计选择，不是缺少缩略图的半成品。不得将它们改为视觉目录，不增加预览图、正方形卡片或材质样块，也不将这些内容登记为未来必须修复的欠缺。

库存和管理页暂不优化，包括资源图标、比较数据、选中详情、布局和业务操作。新建游戏地形预览、建筑缩略图重制、帮助系统与全局换肤不属于本轮范围。

## 工具模式

共享 ToolActionBar 的 ToolModeGroup 可选择 icon-only 或 icon-label，默认保持纯图标。只对地形五种模式、树木两种模式、配色三种模式展开短名称。完整 label 保留辅助技术与提示职责，shortLabel 只用于紧凑可见文字。业务数据仍由原 Controller / Reducer 持有，不从按钮外观推断当前模式。

模式按钮使用稳定 88px 宽、20px 图标和 12px 文字，沿用既有 46px 命中高度；不为追求小巧把已验证的点击区域压缩。模式组内尺寸一致，选中只改变状态，不改变布局。

通用辅助动作保持纯图标。建筑、道路和城墙等未明确需要展开文字的调用点保持原状。Selected 与 Focus 可以同时存在，状态线由真实子元素持有；Tooltip 同时响应 Hover 和键盘焦点。

即时编辑工具的完成是结束工具，不表示提交缓存修改。地形、树木、配色使用中性的退出符号与可见“完成”，提示明确结束工具。配色原本 Complete 和 Cancel 都调用 onClose，不存在回退，因此去掉重复且可能误导的 Cancel 入口；不新增提交、回退或确认弹窗。其他放置工具继续保持原有 Complete / Cancel 契约。

## 自定义地形图标

抬高、降低、整平、平滑、坡面统一地表视角与线宽。五个自定义来源由 scripts/icons/custom-icon-sources.mjs 持有，经已有生成器输出 Source SVG、64×64 白色透明 PNG、Manifest 和 UiIconId。

当前总量为 109：原有 104 个通用图标保持，新增 5 个自定义图标。自定义条目 origin 为 wanhu-authored，不归于 Lucide 来源。显示颜色仍由共享 Tint 决定，不烘焙底板、选中、阴影与焦点。

## Asset Inspector

详情仍是轻量不可交互浮层，不新增常驻详情栏和锁定功能。优先位于整个 Workspace 上方，而不是第二排条目的上方，避免遮住第一排目录。

定位先将浏览器坐标转换为宿主逻辑坐标，再由纯几何函数计算。保护当前目标、Workspace 全部区域和可见 HUD / 工具区域，候选经过屏幕边界修正后再评分；放不下时才选择其他外侧。空间实在不足时标记 constrained，不能宣称任意尺寸都绝无重叠。

同一条目内不跟随鼠标逐帧移动。目标、内容尺寸、滚动、缩放或 Workspace 动画结束后重新计算；目标卸载后隐藏旧浮层，离开空间时清理 Timer / Observer / Listener。DOM 测量只属于展示几何，不参与业务状态推断。

Unity 对应共享浮层定位器与 VisualElement worldBound / 面板坐标转换。纯几何规则可以移植；浏览器 Observer 与 Portal 不直接迁移。

## Settings

保持全屏页、现有分类、即时设置流程和按钮弹窗输入。普通表单内容宽 820px，标签列 220px、间隔 40px、字段列 380px；字段左侧对齐，右侧允许留白。

Select 与 Slider 从同一列起点开始；Toggle 保留 52px 命中宽度，不被推到远端，也不拉伸为长开关。行高仍为 56px，不增加每行图标或常驻说明。键位表继续使用自己的列与字段尺寸，不改为普通参数行。

不根据物理分辨率再套一份窄表单，Web 使用同一逻辑画布等比缩放。Unity 使用统一 PanelSettings；键位表、下拉展开、弹窗、禁用行和两种进入设置的路径都应实际验证。

## HUD

顶部四个指标仍只做快捷打开，几何居中且不增加第二套 Selected。Camera / Weather 从顶部第二层移出，因此 Top Navigation 只保留 Management 主域与 Information Views。

普通 Gameplay 底部采用三个岛，避免右下工具向上增长遮挡 Workspace：

- 左下 World Dock：相机 / 环境 │ 地图解锁 / 区域 / 地形 / 配色；
- 中下 Main Dock：设计 / 蓝图与建设分类；
- 右下 Utility：网格 / 范围复制移动 │ Undo / Redo │ 批量摧毁。

左下 World Dock 与右下 Utility 都使用 Small Bottom Command Surface，但 World Dock 是 World / Scene Launcher，Utility 是辅助与即时动作，两者职责不同。Camera / Weather 打开时 World Dock 保持，Context Surface 在其上方展开；Workspace、Selection、Tool 打开时 World Dock 隐藏。

批量摧毁仍位于右下最右危险分组，使用锈红 Danger Active；普通 Selected / Toggle 继续使用熟铜。右下恢复单行后 Operation Hints 回到正常 56px Utility 上方，不再为双层工具栏额外上移。

## 验收与样式所有权

修改在既有 ToolActionBar、AssetInspector、Settings 与 HUD 所有者内完成，不新增末尾美化覆盖层。Theme、Surface、NumericSliderField、方案目录和管理页不得为本轮同步改版。

Build 的 test-tool-usability.mjs 检查纯几何、五个 PNG/来源和本轮范围保护。保护的文件哈希是这次阶段边界，不是未来永远禁止更改；后续用户批准调整对应模块时，应同步更新或移除阶段保护。

capture-tool-usability-review.mjs 使用真实页面、点击、焦点和时间控件，检查模式宽度、槽位重叠、浮层避让、设置列对齐、键位、昼夜、1440p/4K。其结果不能替代原有 Build / UI Review，也不能代替实际打开完整截图检查美术。

Web 验收不等于 Unity Player 测试。本轮不声称原生滤镜、字体资产、手柄和目标设备性能已在 Unity 6.6 实测。
