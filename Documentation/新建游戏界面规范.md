# 新建游戏界面规范

New Game 是 Main Menu Flow 中的全屏 Global Space。它与 Settings / Load / Save 使用同一个 Smoked Graphite / Paper White / Aged Brass 母版，但保留自己的地图浏览与开局配置结构。

## 1. 空间结构

```text
Parent Main Menu World
↓
.wanhu-global-space
├ Global Header
├ New Game Body
│  ├ Map Browser
│  └ Map Detail / Start Plan
└ Global Footer
```

不要把 New Game 做成中央浮窗，也不要恢复独立深绿 / 黑色 Theme。

## 2. Global Material

Root 必须挂载 `.wanhu-global-space`。

以下全部由共享 Global Space System 持有：

- Root Smoked Graphite；
- Noise；
- Blur；
- Header；
- Footer；
- Paper Text；
- Brass / Cinnabar 状态语义；
- Global Primary / Secondary Button。

`new-game-space.css` 只负责 Geometry、地图浏览、详情区与开局方案。

## 3. 地图浏览

1920×1080 基线：

- Body 约 1480px；
- 左侧 Map Browser + 右侧约 410px Detail；
- 三列地图 Card；
- Card 约 216px 高；
- Radius 约 10px。

Map Card：

- Default：Neutral Global Item Surface；
- Hover：Neutral Graphite Lift；
- Selected：弱 Brass Tone + 左侧 2px 状态线；
- Focus：弱 Focus Edge；
- 不使用完整金边；
- 不把地图类别做成金色。

Random Map Badge 是 Neutral Metadata。

## 4. Detail / Start Plan

Detail 与 Map Browser 只使用 Shared Global Rule 分隔，不创建第二块大 Card。

层级：

```text
Map Type Metadata
Map Title
Description
Facts
Start Plan
```

Paper Primary 用于地图标题；Paper Secondary / Muted 用于事实与说明。

## 5. Controls

地图筛选：

- Default Neutral；
- Hover Neutral；
- Active Brass Text + 2px Short Line。

Game Mode / Map Size：

- 使用 Segmented Field 语言；
- Default / Hover Neutral；
- Active 才使用 Brass；
- 8px Radius；
- 不使用旧 2px Rectangle。

城市名称 / 随机种子：

- 页面只显示 Value Button；
- 点击进入 Shared Input Dialog；
- 随机按钮保持 Neutral Utility Action；
- 不恢复 Inline Text Input。

## 6. Footer

Footer 与 Settings / Load / Save 使用同一 Global Footer Material。

- 开始营造：Global Primary；
- 返回：Global Secondary；
- 页面 CSS 只控制位置 / 宽度，不重新定义颜色。

## 7. Unity UI Toolkit

推荐 UXML：

```text
NewGameSpace
├ GlobalHeader
├ Body
│  ├ MapBrowser
│  │  ├ FilterBar
│  │  └ MapGrid
│  └ Detail
│     ├ MapInfo
│     └ StartPlan
└ GlobalFooter
```

正式 USS：

- `GlobalSpace.uss`：Root / Header / Footer；
- `UIControls.uss`：Value Button / Segmented / Focus；
- `NewGame.uss`：两栏 Geometry、Map Card Layout。

## 8. Review 门槛

- Root / Header / Footer computed style 与 Settings 一致；
- 无独立 Root Green / Black Theme；
- Map Card Radius ≥ 8px；
- Selected 不使用完整金边；
- Random Badge 不使用 Brass 分类；
- 城市名称 / Seed 不存在 Inline Input；
- New Game / Random Map 两种状态均需真实截图 Review。
