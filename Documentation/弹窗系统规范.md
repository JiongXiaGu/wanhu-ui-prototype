# 弹窗系统规范

## 1. 目标

全屏菜单、Gameplay、Settings、Load、Save 等页面统一使用同一套弹窗与轻提示系统。

页面不得各自创建不同风格的确认框、改名框、局部确认条或 Toast。

正式原型结构：

- `DialogProvider`：保存当前 Modal 与 Toast 状态；
- `DialogHost`：统一渲染阻断式弹窗；
- `NotificationHost`：统一渲染非阻断式轻提示；
- `DialogFrame`：统一 Surface、Backdrop、标题、正文与动作区；
- `ConfirmDialog` / `InputDialog` / `TimedConfirmDialog`：少量语义变体。

最终 Unity UI Toolkit 应保留同样职责边界，统一挂在全局 Modal Layer，而不是每个页面自己维护独立弹窗层。

## 2. Confirm Dialog

适用于：

- 返回主菜单；
- 退出游戏；
- 覆盖存档；
- 删除存档；
- 删除存档组；
- 其它需要玩家明确确认的操作。

动作顺序固定：

`取消 / 安全动作` 在左，`确认 / 主动作` 在右。

普通确认使用暖金主按钮；不可恢复的数据删除使用 Danger 按钮。整个 Dialog Surface 不整体染红。

危险删除默认焦点放在取消按钮；Esc 永远取消，不能执行危险动作。

## 3. Input Dialog

所有名称编辑统一使用 Input Dialog，包括：

- 保存新存档；
- 重命名单个存档；
- 更改存档组名称；
- 后续城市、蓝图、方案等名称输入。

规则：

- 打开后自动聚焦；
- 修改已有名称时默认全选原值；
- 新建对象可以预填系统自动名称；
- Enter：确认；
- Esc：取消；
- 空名称时确认按钮 Disabled；
- 不再在 Card 内部临时把 Label 替换成 TextField。

## 4. Timed Confirmation

用于可能造成 UI / 显示不可操作的重要显示设置，例如：

- 分辨率；
- 显示模式；
- HDR；
- 刷新率；
- UI Scale。

语义：

`临时应用 → 倒计时 → 保留设置 / 自动恢复`

Timed Confirmation 与普通 Dialog 共享：

- Backdrop；
- Surface；
- 标题字号；
- Button Tone；
- 间距与动画。

其额外内容只有：设置变化摘要、倒计时与自动 Rollback。

Settings 当前安全显示确认仍保留原有回滚状态机，但视觉必须严格跟随统一 DialogFrame；最终 Unity 实现应放入全局 Modal Layer。

## 5. Toast / Notification

Toast 只用于告知已经发生的结果，不要求玩家决策，例如：

- 快速保存完成；
- 手动存档完成；
- 覆盖完成；
- 存档删除完成；
- 设置已恢复。

Toast：

- 不抢 Focus；
- 不阻断操作；
- 自动消失；
- 不替代需要确认的 Dialog。

## 6. 视觉语言

Dialog：

- 深墨绿色高不透明 Surface；
- 小圆角；
- 1 px 弱灰绿描边；
- 顶部极弱暖金高光；
- 背景压暗并轻微 Blur；
- 不使用卷轴、粗金框、英文 Eyebrow 等装饰。

按钮 Tone：

- Secondary：取消、恢复等安全动作；
- Primary：确认、保存、保留设置、返回主菜单；
- Danger：永久删除等不可逆数据操作。

动画保持 120–160 ms 的轻微淡入与 6–7 px 位移，不使用弹跳或大尺度缩放。

## 7. 当前迁移范围

已进入统一 `DialogHost`：

- 主菜单退出游戏确认；
- Gameplay 返回主菜单确认；
- 保存新存档命名；
- 更改存档组名称；
- 单个存档重命名；
- 覆盖存档确认；
- 删除单个存档；
- 删除存档组；
- Load / Save 操作后的 Toast。

Settings 的 15 秒安全显示确认暂时保留原有安全回滚状态机，但视觉已经对齐统一 Dialog；后续 Unity 正式实现统一进入全局 Modal Layer。

## 8. 代码约束

页面代码只负责业务动作，不负责 Modal 外观。

禁止新增：

- `xxx-confirm-layer`；
- `xxx-name-dialog`；
- Card 内部临时确认条；
- 页面私有 Toast 样式；
- 多套不同按钮顺序。

新增确认、输入或提示时，优先扩展统一 Dialog / Notification API，而不是在业务页面新增独立弹窗 DOM。
