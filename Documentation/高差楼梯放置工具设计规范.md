# 高差楼梯放置工具设计规范

`CityWallTransitionStairTool` 是城墙四套独立业务 ToolOverlay 中的第四套，第一版只负责 **自由放置独立高差楼梯**。

## 1. 第一版目标

逻辑与登城梯保持一致，避免提前自动化。

明确不做：

- 马道自动连接；
- 双端 Anchor；
- 自动高差；
- 自动长度；
- 目标坡度；
- 墙体查询；
- 自动对齐不同标高平台。

## 2. 玩家参数

左侧只保留三个玩家直接指定的尺寸：

```text
楼梯尺寸
楼梯宽度
楼梯高差
楼梯长度
```

推荐范围：

- Width：2–12 m；
- Height Delta：1–12 m；
- Length：3–24 m。

坡度由 Height Delta / Length 自然决定，但第一版不作为可编辑参数，也不常驻显示。

## 3. 放置方式

第一版只有一种 Free Placement，没有 Mode Selector。

操作：

- 鼠标移动：调整位置；
- 左转 / 右转：调整整体朝向；
- 交换上下端：改变 High / Low 方向；
- 完成 / 取消。

Bottom Action Bar：

```text
[左转] [右转] [交换上下端]
          │
      [完成] [取消]
```

## 4. World Preview

Web Preview 继续使用真正有踏步的 Stair Ghost，并额外画出上下两个平台端，强调“连接不同标高平台”的用途：

- Low Platform；
- High Platform；
- LOW / HIGH；
- 踏步；
- 宽度；
- 高差；
- 长度；
- 楼梯净空。

正式 Unity 由 `CityWallTransitionStairWorldRenderer` 绘制，不由 UI Toolkit 绘制真实楼梯。

## 5. Context Utility

第一版只保留：

- 网格吸附；
- 网格显示；
- 楼梯净空；
- Undo；
- Redo。

不新增“马道连接点”“墙顶挂点”等未启用功能。

## 6. 数据边界

第一版世界数据：

```text
CityWallTransitionStair
├ Width
├ HeightDelta
├ Length
├ Position
├ Rotation
└ Reversed
```

内部可计算坡度、踏步数量等，但不进入第一版放置 UI。

## 7. 与登城梯的关系

当前两者交互高度一致，但仍保持独立 Tool：

- 登城梯语义：地面 / 高处之间的登城构件；
- 高差楼梯语义：两个不同标高平台之间的过渡构件。

以后如果增加自动连接，高差楼梯很可能需要两端马道 Anchor；因此不与登城梯合并业务状态。

## 8. Visual Review

至少检查：

- Workspace 的“高差楼梯”Card 能进入 `city-wall-transition-stair`；
- 左侧只有 Width / Height Delta / Length；
- 不出现自动高差 / 目标坡度 / 马道连接；
- Bottom Action Bar 没有 Mode 按钮；
- 左转 / 右转 / 交换上下端均存在；
- World Preview 有明确踏步、High / Low 和两个平台端；
- Utility 只有 Grid / Clearance / History；
- Rotate + Reverse 能改变状态；
- 完成后返回城墙 Workspace。
