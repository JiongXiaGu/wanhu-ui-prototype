# 组件设计规范

## 1. 组件设计目标

组件不是为了网页复用而抽象，而是为了让游戏 UI 的视觉语言、状态表达和交互规则保持一致。

优先共享：

- 相同语义；
- 相同交互；
- 相同视觉状态；
- 相同生命周期。

不要为了减少文件数量，把语义不同的界面强行做成同一个万能组件。

## 2. Button

### Primary

用于当前界面最主要动作，例如：

- 应用设置；
- 载入存档；
- 开始游戏；
- 完成放置。

表现：

- 暖金作为 Focus / Selected / Primary 强调；
- 不使用高饱和大面积金色；
- 同屏原则上只有一个明显 Primary。

### Secondary

用于返回、取消、恢复默认、低优先级动作。

取消未提交工具操作不视为危险操作。

### Icon Cell

高频工具栏优先使用图标单元格，例如：

- 网格吸附；
- 网格显示；
- 撤销；
- 重做。

图标单元格必须有 Tooltip。

## 3. Segmented Control

用于互斥模式切换，例如：

- 平 / 填 / 高；
- 位 / 层 / 顶 / 面；
- 相机模式；
- 天气模式。

视觉规则：

- 不做厚重外框；
- Selected 使用暖金细线、文字或极弱暖金染色；
- 不同时使用粗边框 + 大面积金底 + 金色文字。

## 4. Parameter Row

参数行只显示完成当前操作必要的信息。

常见形式：

- Label + Select；
- Label + Toggle；
- Label + Value；
- Label + Keycap；
- Label + Slider。

不在每个参数下面常驻解释文字。

需要解释时使用共享 Tooltip。

## 5. Slider

Slider 不应被包在大型输入框内。

建议结构：

```text
参数名
────────────●────    100%
```

或在空间较紧时：

```text
参数名    ─────●──    100%
```

Value 是状态，不需要额外 Card。

## 6. Toggle

Toggle 用于明确的 On / Off 状态。

- 开关本体承担主要状态表达；
- 除非 On / Off 文本不可避免，否则不要同时显示“开启”文字和明显开关状态；
- Disabled 状态降低对比度。

## 7. Tooltip

Tooltip 是低频解释的统一承载方式。

规则：

- Hover 延迟约 400 ms；
- 统一深墨 Surface；
- 极弱边界；
- 第一行：功能或参数含义；
- 第二行可选：影响 / 快捷键；
- 不显示无意义标题；
- 不放交互控件；
- 不使用浏览器原生 Tooltip 作为最终实现。

所有 Icon-only 控件必须可通过 Tooltip 理解。

## 8. Keycap

Keycap 用于操作提示，不用于装饰。

表现：

- 小尺寸；
- 对比明确；
- 不做拟物键盘帽；
- 可与动作文字组合。

示例：

```text
[左键] 确认位置
[R]    旋转
[Esc]  取消
```

Unity 最终实现应由 Input System 实际绑定驱动显示。

## 9. Surface

Surface 是空间层级，不是 Card 装饰。

优先级：

1. 世界 / 背景；
2. 主空间 Surface；
3. 活动区域 Tone；
4. Selected / Focus。

能靠 2%～5% 明度差、留白或对齐组织时，不增加边框。

同屏避免多个同等重量的大黑面板。

## 10. Workspace Item

Workspace 中内容条目应更像“游戏内容目录”，而不是网页卡片。

长期目标：

- 真实建筑缩略图或 RenderTexture；
- 建筑名；
- 一条核心属性；
- Hover / Selected 状态。

避免：

- 每张条目完整 Card 边框；
- 多层标签；
- 相同占位图重复出现；
- 长说明文本。

## 11. Archive Item

Archive 的层级是：

`Game Group → Save Timeline → Save Preview`

### Game Group

Game Group 用城市截图、城市名、年代和最近保存时间建立识别。

### Save Timeline

同一 Game Group 内的 Save 按时间组织，支持自动存档与手动存档。

时间轴是信息结构，不应做成普通文件列表。

### Preview

Preview 只显示影响识别与决策的信息，例如：

- 城市截图；
- 城市名；
- 年代 / 季节；
- 保存时间；
- 游戏时长；
- 少量关键城市状态。

世界种子、版本等低频信息放到详情或 Tooltip。

## 12. Right Edge Flyout

Camera / Weather 使用同一个右侧 Flyout 视觉语言。

- 从屏幕右边缘出现；
- Header 简洁；
- 内部参数靠分组、留白和 Tone 组织；
- 不使用英文眉题和长说明；
- 不创建无意义 Summary Card。

## 13. Pause Menu

Pause Menu 是轻量全局命令列表。

只保留：

- 继续游戏；
- 保存游戏；
- 游戏设置；
- 返回主菜单。

不要增加：

- 01 / 02 / 03 / 04 编号；
- 右箭头；
- 每项副说明；
- 无意义品牌尾标。

## 14. 动效

动效用于强化状态变化，不用于展示技术效果。

推荐：

- Hover：约 100 ms；
- Tab Active：约 120～160 ms；
- Workspace / Flyout：约 160～220 ms；
- 参数模式切换：Fade + 2～5 px 位移；
- Archive Preview：轻量 Cross Fade。

避免大幅弹跳、Scale 过冲、强 Glow 和长时间缓动。
