# 树木放置工具设计规范

Tree Placement 是从“树木”Design Workspace 进入的正式 Tool Space，用于批量刷植被与单棵精确摆放。

## 1. 入口与空间

```text
Main Dock
  → 树木
  → Design Workspace 选择树种
  → Tree Placement Tool
```

进入后保留顶部状态、Compass 和 System Menu；左下是 Tree Context，中下复用 ToolActionBar，右下复用 Context Utility；不常驻 Operation Hints；完成 / Esc 按 ToolOrigin 返回树木 Workspace 或 Gameplay。

## 2. 模式

`TreePlacementMode = 'brush' | 'single'`。Brush 用于成片绿化，参数只保留半径、密度、大小随机。Single 同时承担新单棵放置与已有单棵编辑，支持移动、旋转、切换 Variant、删除和统一 Scale。

## 3. Species / Variant

一个 Tree Species 最多 8 个 Variant。Variant 只表示树形差异；Season / Growth Stage / LOD / Impostor / 健康状态不进入 Variant。

## 4. 左侧 Tree Context

复用 `LeftContextPanel`。Variant 使用两条 Flex Row 组成固定 4×2 按钮组。Brush 额外提供“随机混合 01–08”；Single 必须选择具体 Variant。

## 5. ToolActionBar

主模式只有 Brush / Single。Single Quick Action 为 Move / Rotate Left / Rotate Right / Delete。Commit 只有“完成树木放置”，回退修改使用 Undo。

## 6. Tree Context Utility

只保留避让建筑、避让道路、Undo、Redo。

## 7. World Visualization

Web 的 Brush Ring、Tree Marker、Selection Ring、Transform Gizmo 只验证表达；正式 Unity 由 World Renderer / Tool Controller 实现，不使用 UI Toolkit 绘制真实世界预览。

## 8. Unity UI Toolkit 映射

UI Toolkit 负责 Context / ActionBar / Utility 与状态绑定；C# 负责 Tool / Mode / Species / Variant、Input、World Query、History、Selection 与 ToolOrigin。

## 9. 首轮非目标

不加入多树种混刷、Variant 权重、Brush Noise/Falloff、生长、季节、健康、LOD/GPU 参数、XYZ 非等比缩放。

## 10. Visual Review

检查 Workspace → Tree Tool、8 Variant、Brush 参数宽度、Single Move/Rotate/Delete、Tree Utility、无 Operation Hints、完成返回 Tree Workspace，以及 1920×1080 下左中右不互相遮挡。
